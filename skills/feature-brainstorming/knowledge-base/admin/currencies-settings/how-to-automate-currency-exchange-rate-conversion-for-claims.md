# How to Automate Currency Exchange Rate Conversion for Claims

*This article explains how to automate currency exchange rate conversion for claims using the rates set in Settings > Currencies.*

This feature is particularly beneficial for employees with overseas expenses in various currencies, as the system automatically converts amounts to the office currency using the Currency Exchange Rates set in the Settings > Currencies page.


---


### New Updates: Foreign Exchange Rate API


This feature automatically updates and follows the foreign exchange rates from either **Bank Negara Malaysia (BNM)** or [Open Exchange Rates (OER)](https://openexchangerates.org/) once enabled.


**Bank Negara Malaysia (BNM)** provides exchange rates exclusively against the Malaysian Ringgit (MYR), making it especially useful for **Malaysian companies.**


**Open Exchange Rates (OER)** supports a wide range of exchange rates, covering a diverse array of currencies. This makes it an invaluable resource for companies operating in any country.


**To enable this feature:**


1. Contact our support team via **Live Chat or email (support@briohr.com)** to have this feature (OER/BNM) added to your account. **Please note that only one API can be enabled at a time.**
2. Enable **Auto Update Foreign Exchange** in Settings > Currencies.

### How to Set the Currency Exchange Rate:


1. Go to **Settings > Currencies**.
2. Click on the **Add Currency** button.
3. Select the **currencies **that you would like to pair (e.g., USD to MYR).
4. Enter the **conversion rate**, e.g., 1.00 USD equals how many MYR (e.g., 4).
5. Click on **Save** once done.

#### Employee View When Submitting a Claim Request for a Different Currency:


- When submitting a claim request in USD while the office currency is MYR, select USD in the **Total Amount** column and input the **USD **amount.
- The system will automatically convert this to **MYR **in the **Total Amount (office currency)** column.
