# How to Create a Work Schedule with Flexible Hours

*Learn how to set up flexible hours work schedules effectively. This guide covers step-by-step instructions for default pattern full week and custom.*

### Introduction


The **Work Schedule **feature in BrioHR allows employers to set up different work schedule patterns or employees, either weekly or for specific period of time. Work schedules can include **full days, half days, and rest days,** ensuring flexibility for various work arrangements.


By assigning schedules, you can ensure accurate rostering, manage clock-in/out times, and define leave application rules.


In this article, you will learn how to create a new work schedule and configure its **General Section**, including **Full Week** and **Custom **patterns.


If you are setting up offices first, check our guide: [How to Add, Edit, and Delete Offices in BrioHR](https://support.briohr.com/knowledge/add-edit-delete-offices-briohr?hsLang=en).


### Benefits of Using Work Schedules in BrioHR


- Define schedules for specific offices or individual employees.
- Support for half-day work patterns.
- Assign flexible hours or shift-based schedules.
- Control employee leave application rules based on rest days.

### Step-by-Step Guide: Creating a New Work Schedule


#### Step 1 - Log In to BrioHR


1. Login to your BrioHR Account > Go to **Settings.**


2. Navigate to **Schedules & Shifts.**


3. Under **Work Schedules**, click **+Create Schedule.**


#### Step 2 - General Section of Work Schedule


On the **Create New Work Schedule** page, you will see two main sections:


- **General**
- **Work Pattern Variation**


Start by completing the **General Section:**


1. **Schedule Name: **Give the schedule a recognizable name.
2. **Work Hours per Day (required):** Define the number of working hours per day (e.g., 8 hours)

  1. This impacts number of designated hours the employees need to work in a day to be consider as complete working day.
3. **Work on Public Holiday: **Tick the checkbox if employees under this schedule are required to work on public holidays.

  1. Choosing 'Work on Public Holiday' will **consider a public holiday as normal working day.** Any shift set on a public holiday won't follow overtime public holiday rate calculations.
  2. Employees can apply leave on a public holiday (as the system considers it as normal working day)
4. **Work Arrangement: **Choose one of the following:

  1. **Flexible Hours: **Work is calculated based on total daily/weekly hours, not fixed clock-in/out times.
  2. **Shift: **Employees follow defined shift schedules.
5. **Default Pattern: **Select either:

  1. **Full Week**
  2. **Custom**


**IMPORTANT:**


Once a schedule is created, you cannot change from **Flexible Hours to Shift** (or vice versa).


To modify, you must create a new work schedule.


---


#### Step 3 - Default Work Schedule Patterns


**3.1 Full Week Pattern**


- Based on a **7-day weekly cycle.**
- Options for each day:

  - **Full Day **= 8 hours
  - **Half Day **= 4 hours
  - **Rest Day** = Non-working day/weekend


**RULES:**


- If a day is marked as** Rest Day**, employees cannot apply for leave.
- If a day is set as **Half Day**, employees cannot apply for full-day leave

#### 3.2 Custom Week Pattern


Custom work pattern follows **recurring cycles **(e.g., work 4 days, rest 1 day, repeat)


1. Set for **Work For**: Define how many days employees will work before rest days.
2. Set a R**eference Date:** The schedule starts from this date and repeats onward.

  1. Example: If you choose 26 September 2025, the pattern starts on this date, including weekends and public holidays.


**IMPORTANT:**


Custom work patterns** do not **follow the standard 7-day week format. They follow calendar days instead.

#### Frequently Asked Questions (FAQs)


**Q1: Can I edit a work schedule arrangement after creating it?**


A: No, you cannot change the work arrangement (Flexible Hours vs. Shift). To do so, you must create a new work schedule.


**Q2: Can employees have different schedules within the same office?**


A: Yes, you can assign specific schedules to individual employees if needed. Refer to this article for [how to assign custom work schedule by employees](https://support.briohr.com/knowledge/how-to-assign-work-schedule-by-employee?hsLang=en).


**Q3: What happens if I select option "Work on Public Holiday"?**


A: If the "Work on Public Holiday" option is enabled, the system counts it as a working day.
