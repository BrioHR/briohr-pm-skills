# How to Create a Work Schedule with Shifts

*Learn how to create employee work schedules with shifts in BrioHR. This guide covers step-by-step instructions for Full Week and Custom patterns to simplify shift management.*

The **Schedule** feature is the latest addition by BrioHR. It allows employers to set up different work shift patterns either weekly or for a specific period of time.


### What Are Work Schedules with Shifts?


A **work schedule with shifts** consists of specific shifts with designated in/out times that employees must adhere to.


In this article, you will learn how to set up the **General** section of work schedule creation with the **Shifts** option. There are two types of default patterns you can configure in a work schedule: **Full Week** and **Custom**.


Creating various work schedules with shifts allows you to define them for specific offices or individuals. The shifts set up will directly impact the configuration in the **Time Attendance** module.


**NOTE:**

**Before creating a work schedule with shifts, ensure that work shifts have already been created. When setting up a work schedule with shifts, you will need to assign specific shifts to each day.

For instructions on creating work shifts, please refer to [[this guide](https://support.briohr.com/knowledge/how-to-create-new-work-shifts?hsLang=en)].**


### How to Create a New Work Schedule with Shifts


Login to BrioHR account


1. Go to **Settings**
2. Navigate to **Schedules & Shifts**
3. In the **Work Schedules** section, click on the **+Create Schedule** button.
4. You will be directed to the work schedule creation page, which contains two sections: **General** and **Work Pattern Variation**.
5. Go to the **General **section.


###


### General Section of Work Schedule Creation


1. **Schedule Name**: Enter the name for your schedule.
2. **Work Hours per day (compulsory)** : Set the number of hours employees are expected to work each day. This will impact the work pattern.
3. **Work on Public Holidays**: If employees are required to work on public holidays, check the box for **Work on Public Holidays**.
4. **Work Arrangement**: Choose between **Flexible Hours** or **Shift**:


  1. If you select **Shifts**, assign the shifts to be included in the work pattern.
5. **Split Shift Time**:

  1. Adjust this timing only if your team works past midnight.
  2. The default timing is split at 12:00 AM (midnight).
  3. Changing this ensures late-night shift timesheets are counted for the previous day, not the next.
6. For the default pattern, select either **Full Week** or **Custom**.


**NOTE:**


- **You can select the work arrangement only once. Once you choose Flexible Hours, you cannot switch to Shifts for the same schedule.**
- **To make changes, you will need to create a new work schedule.**


---


#### Default pattern: Full Week


This option allows you to define a recurring work pattern for a full 7-day week with a specified hours defined in **'Work hours per day'.**


- A day set as **Full Day** will equal 8 hours (full-day work hours).
- A day set as **Half Day** will equal 4 hours (half-day work hours).
- A **Rest Day** is considered a weekend or day off.


**NOTE:**


- **On weekdays marked as Half Day, employees cannot apply for full-day leave.**
- **Days marked as Rest Day will block leave applications.**

#### Default pattern: Custom


This option allows you to define specific work and rest days. The pattern will repeat based on the specified start and end dates


- **Work for**: Set the number of workdays per week.
- **Reference Date**: Specify the starting date for your work schedule pattern. This date serves as the anchor point for all recurring work cycles and shift patterns in the system.


**NOTE:**


- **Custom work patterns do not follow a fixed weekly sequence.**
- **If the Reference Date falls mid-month (e.g., October 15, 2024), the custom work pattern will begin from that date and include Saturdays, Sundays, and public holidays, based on calendar days**
