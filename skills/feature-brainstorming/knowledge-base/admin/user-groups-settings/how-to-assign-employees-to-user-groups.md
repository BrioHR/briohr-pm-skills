# How to Assign Employees to User Groups

*Step-by-step guide on how Admins can assign employees to User Groups in BrioHR to manage permissions and access levels.*

### Steps to Assign Employees to User Groups


1. **Log in to BrioHR** and click the **Settings** button (available only to Admin users).
2. Go to the **Users** tab.
3. **Search for the employee** you want to assign to a User Group and click **Edit** (green pencil icon).


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-03-2025-11-22-57-6600-AM.png?width=670&height=210&name=image-png-Sep-03-2025-11-22-57-6600-AM.png)


1. In the **User Group** field, select the desired group from the dropdown menu.
2. Click the **Green Checkmark** symbol to **Save**.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-03-2025-11-24-26-4170-AM.png?width=1900&height=696&name=image-png-Sep-03-2025-11-24-26-4170-AM.png)


The employee will now be part of the selected User Group and gain access according to its permissions.





### Why Assign Employees to User Groups?


- **Simplifies permission management** by grouping employees with similar access needs.
- **Enhances security** by limiting access only to relevant features.





### Frequently Asked Questions (FAQs)


**1. Can an employee belong to more than one User Group?**
No, each employee can only be assigned to one User Group at a time.


**2. What happens if I change an employee’s User Group?**
The employee’s access permissions will update immediately according to the new User Group.


**3. Who can assign employees to User Groups?**
Only Admin users with the correct permissions can assign or update User Groups in BrioHR.


**4. Do changes to User Groups affect existing employee data?**
No, updating a User Group only changes system access and permissions. Employee data remains intact.[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48163361617/original/ZZ2LsE6RT42h7Uvmd5Jrj2SUY8CePePAqg.png?1637809308)
