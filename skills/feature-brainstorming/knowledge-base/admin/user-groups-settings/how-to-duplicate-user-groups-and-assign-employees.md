# How to Duplicate User Groups and Assign Employees

*Learn how to duplicate User Groups in BrioHR and assign employees efficiently. A step-by-step guide for Admin users to manage permissions and access.*

Duplicating User Groups in BrioHR is a quick way to streamline employee access management. Instead of creating a new group from scratch, Admins can copy an existing User Group, adjust its settings, and assign employees accordingly.


This guide walks you through the process of duplicating a User Group and managing its permissions.


###


### Step 1: How To Duplicate The User Group


1.**   Log in to BrioHR** and click on the **Settings** button (available only to Admin users).

2.  Navigate to the **User Groups** tab.

3.  Find the User Group you want to duplicate and click the **Duplicate icon** next to it.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48162901824/original/1D92oGjHjA5qped2_xU1o-TZCnsLZq1t2A.png?1637727271)


4.  A **confirmation **pop-up window will appear. To proceed, rename the new User Group and click the **Duplicate** button. Click **Cancel** to abort the action.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48162902318/original/p6rqPvlXvcegDafZ_-cqOziVuuLJ0PkebA.png?1637727607)


5.  The duplicated User Group will appear in the **User Groups list**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48162903694/original/1ddRaH6No41kUlU-DEM7UHLzjsPEIoR3SA.png?1637728603)


###


### Step 2: Edit Permissions for the New User Group


After duplicating a User Group, you can customize its permissions:


1.  Click the **Edit (green pencil icon)** next to the duplicated User Group.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-03-2025-11-41-17-0353-AM.png?width=670&height=242&name=image-png-Sep-03-2025-11-41-17-0353-AM.png)


2.  In the **Edit User Group** pop-up window, enable, disable, or adjust the permission settings as needed.

3.  Click **Save** to confirm changes, or click **Cancel** to discard them.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-03-2025-11-44-18-0592-AM.png?width=670&height=628&name=image-png-Sep-03-2025-11-44-18-0592-AM.png)


The new User Group is now ready to use, and employees can be assigned to it.
