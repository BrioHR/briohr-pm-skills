# How to Enable Employee Permissions for MyGoals Page in BrioHR

*Learn how to enable employee permissions for the MyGoals page in BrioHR. This step-by-step guide explains how to grant access, manage objectives, and support performance tracking.*

The **MyGoals page** in BrioHR is designed to help employees track personal performance, manage objectives, review competencies, and participate in self-evaluations. By enabling access to MyGoals, HR admins ensure that employees can stay engaged with their performance goals and contribute actively to performance reviews.


####


### Why Employees Need Access to MyGoals


Without access to MyGoals, employees are unable to:


- View their personal performance page.
- Manage objectives and KPIs.
- Review competencies and track progress.
- Conduct self-appraisals.
- Leave comments in the **1-on-1 Feedback section**.


Enabling this access is essential for fostering accountability and continuous performance management.


####


### How to Enable Employee Access to MyGoals


1.   Login to BrioHR and click into **Settings > User Groups**





2.   At the **Employee User Group** and click on the **Edit** icon.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-06-05-43-4999-AM.png?width=1896&height=715&name=image-png-Sep-24-2025-06-05-43-4999-AM.png)


3.   Click into **Employee Modules Permission** (represents the Home page).


4.   Look for the **Performance Module** and toggle the button **ON**.


There are two additional permissions you can grant:


- **Allow to edit objective weightage** – allows employees modify their personal objective weightage.
- **Allow to edit objectives after manager has confirmed** – allows employees to edit or add new objectives even after their manager has completed the objectives confirmation task.


5.   Click **Save** to apply the updated permissions.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-06-07-46-8217-AM.png?width=855&height=808&name=image-png-Sep-24-2025-06-07-46-8217-AM.png)





### Frequently Asked Questions (FAQs)


**1. Who can enable access to the MyGoals page?**
Only the main account admin with access to **Settings** can edit User Group permissions.


**2. Can employees edit their objectives after the manager confirms them?**
Yes, but only if the **“Allow to edit objectives after manager has confirmed”** option is enabled in the User Group settings.


**3. Can objective weightage be edited by default?**
No, by default employees cannot edit objective weightage. Admins must enable this in User Group permissions.


**4. Where can employees find their MyGoals page?**
Employees can access it from the **Home page > MyGoals** section.
