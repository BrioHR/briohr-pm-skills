# How to Enable Employees to Cancel Their Future Leave Applications

*Learn how to configure User Group permissions in BrioHR to allow employees to cancel their own future leave applications. Step-by-step guide included.*

In BrioHR, admins can configure user group settings to allow employees to **cancel their own future leave applications**. This feature not only enhances efficiency but also provides employees with greater flexibility in managing their leave.


This guide explains how to enable the setting step by step.


### Steps to Enable Employees to Cancel Future Leave


1.    Login to BrioHR and click into **Settings > User Group**


2.   At the **Employee User Group**, click on the **Edit **icon.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-07-2025-12-06-04-1527-PM.png?width=670&height=259&name=image-png-Sep-07-2025-12-06-04-1527-PM.png)
[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48337375568/original/02PcvinECOdO0yEmPNTxArQDczmP92ugPQ.png?1716171414)


3.   Within the Employee User Group, go to **Employee Modules Permission**.


4.   In the **Leave Module** column, tick the checkbox **“Cancel their own leaves.”**


5.   Click **Save** to apply the changes.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-07-2025-12-09-28-3031-PM.png?width=670&height=635&name=image-png-Sep-07-2025-12-09-28-3031-PM.png)
[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48337375427/original/J1wJXmVKFJVH2DgzjVr4I7ir39Q_DAeKlw.png?1716171202)


**NOTE:**


BrioHR does not support setting a numerical day limit for advance leave cancellation (leave cancellation window). The only available controls are:


1. Allow/disallow employee(s) to cancel future-dated leave via User Group Permissions.
2. HR admin override (cancel) past-dated leave(s).





### Frequently Asked Questions (FAQs)


**1. Can I enable this permission for only certain employees?**
Yes, permissions are assigned at the **User Group level**. You can create or edit user groups to customize access.


**2. What happens if the setting is disabled?**
Employees will need to request HR/Admin to cancel their leave on their behalf.
