# How to Enable Employees to Edit Objectives After Manager Confirmation

*Learn how Admins can enable or disable employee access to edit objectives after manager confirmation in BrioHR. Step-by-step guide with FAQs included.*

In BrioHR, managers typically confirm employee objectives as part of the performance management process. By default, once confirmed, employees **cannot edit their objectives** unless Admins enable this setting.


This article provides a **step-by-step guide** to enable or disable the option that allows employees to edit their objectives even after manager confirmation.





### Steps to Enable Employees to Edit Their Objectives After Manager Confirmation


1.    Login to BrioHR and click into **Settings > User Group**


2.   At the **Employee User Group**, click on the **Edit **icon.





![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-07-2025-11-36-10-0836-AM.png?width=670&height=258&name=image-png-Sep-07-2025-11-36-10-0836-AM.png)

[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48210745072/original/Il7v202M4iSYwayYuRiegn9PC_nPtCf8ow.png?1648993433)





3.   Within the Employee User Group, go to **Employee Modules Permission**.


4.   In the **Performance Module** column, tick the checkbox **“Allow to edit objectives after manager has confirmed.”**


5.   Click **Save** to apply the changes.


**IMPORTANT :
****If this checkbox is not selected, employees will NOT be able to edit their own objectives weightage.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48210745402/original/IXBdhd3YTbFdmBDuNey0-snmS1-XhhE12g.png?1648993786)


**NOTE:
This configuration is applicable to any User Group. The example above is for the Employee User Group.**


###


### Frequently Asked Questions (FAQs)


**1. Can employees edit objectives after manager confirmation?**
No, employees can only edit objectives after confirmation **if** the Admin enables the **“Allow to edit objectives after manager has confirmed”** setting.


**2. Does this setting apply to all employees automatically?**
No, the setting applies to the **User Group** level. Only employees in the configured group will have this access.


**3. Can managers still override employee objectives after confirmation?**
Yes, managers and Admins with higher access rights can always make edits regardless of this setting.
