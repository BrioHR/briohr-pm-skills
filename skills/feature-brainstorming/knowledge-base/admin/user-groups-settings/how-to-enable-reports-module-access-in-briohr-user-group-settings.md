# How to Enable Reports Module Access in BrioHR User Group Settings

*Step-by-step guide for Admins on granting access to the Reports module in BrioHR. Learn how to enable, customize, and manage report permissions by user group.*

The **Reports module** in BrioHR provides valuable insights into employee and company data, from payroll history to expense claims. To maintain security and control, Admins can grant access to the Reports module by **user group**, ensuring only the right people can view and manage reports.


This guide explains how to enable Reports module access and customize report permissions for different user groups.


### Steps to Enable Reports Module Access


Log in to your BrioHR account.

1.   Navigate to **Settings > User Groups **at the top right of your screen.[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48156142305/original/IpOUZ9oYiilsHbJqchKKdiodgn9LojhCZg.png?1636355555)


2.  **Choose the user group** to which you want to grant Reports module access. Click on the **pencil icon** to edit and manage permissions.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-07-2025-09-07-27-2185-AM.png?width=1894&height=718&name=image-png-Sep-07-2025-09-07-27-2185-AM.png)
[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48156142387/original/HLBB7K_Yl8FHrZL2MDd1LbxF4UsnM5bakw.png?1636355595)


4.    Go to the **HR Modules Permission** category.


5.    Locate the **Reports Module** and switch the toggle button to **ON** to grant access.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48156142447/original/FoKvTvyfv-z-4O71bxPmQcMMge5C95LpuA.png?1636355610)6.    Within the Reports Module, there are **various report types available**. Customize access permissions for each report as needed.


- Example: Allow the Finance PIC to access only **Expense Claims reports** by enabling this report type exclusively.


7.    Click **Save **to apply changes.
