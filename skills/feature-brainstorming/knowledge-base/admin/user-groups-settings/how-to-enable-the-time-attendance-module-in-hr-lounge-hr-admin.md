# How to enable the Time Attendance Module in HR Lounge (HR/Admin)

*Learn how to enable and configure the Time Attendance Module in BrioHR for HR/Admin. Step-by-step guide to activate time tracking and reporting features.*

Enabling the **Time Attendance Module** in BrioHR allows HR and Admin users to manage employee attendance, view reports, and maintain accurate time records. This guide walks you through the exact steps to grant access via **User Group permissions**.





### Steps to Enable User Group Permission


1.    Login to BrioHR and click into **Settings > User Group**


2.   At the **Admin User Group**, click on the **Edit **icon.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-08-42-48-2333-AM.png?width=670&height=284&name=image-png-Sep-24-2025-08-42-48-2333-AM.png)


3.   Ensure permissions for **HR Modules Permission** is enabled.


    a. Go to **Pages Access**, check the box for **HR Lounge.**


![image](https://support.briohr.com/hs-fs/hubfs/undefined-Sep-24-2025-08-44-40-6644-AM.png?width=670&height=633&name=undefined-Sep-24-2025-08-44-40-6644-AM.png)





4.   Within the **HR Modules Permission** , search for the **Time Attendance Module**


5.   Ensure the **toggle button is enabled** for the Time Attendance Module


6.   Select the appropriate "**Allow dashboard access**" option:


    a. **Allowed for managed offices** – Grants access to a limited set of offices.


    b. **Allowed for all employees** – Grants access to all employees’ time attendance records.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-09-02-19-8403-AM.png?width=670&height=628&name=image-png-Sep-24-2025-09-02-19-8403-AM.png)


7.   Next, within the HR Modules Permission page, search for the **Reports Module**


8.  Ensure the access to the Report module has been enabled then tick the checkbox :


- **Allow access to time attendance timelog table report.**
- **Allow access to time attendance timesheet report.**
- **Allow access to time attendance roster report.**


9. Click **Save **to apply the changes**.**


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-25-2025-02-51-23-8010-AM.png?width=850&height=810&name=image-png-Sep-25-2025-02-51-23-8010-AM.png)
