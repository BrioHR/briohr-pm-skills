# Scope HR and Admin Access by Office and Team Level

*Give a staff member HR/admin access limited to one office (Office HR Manager + scoped User Group), control how far down managers can see their teams (Team Access), and know what change history BrioHR keeps.*

** Audience & Scope**

- Audience: HR Admin / Account Admin
- Module: Settings (Offices, User Groups)
- When to use this article: You want someone to have HR/admin-like access for only one office; a manager asks why they can/can't see ratings of indirect reports; you're looking for an audit trail of profile changes.


[](#hradmin-access-limited-to-one-office)**HR/admin access limited to one office**

1. Assign the employee as Office HR Manager for the selected office: Go to Settings > Offices > pencil icon > Office HR Manager.
2. In Settings > User Groups, edit or create a new user group for the employee's user group and scope the permissions (e.g. View/Modify Your Scope) accordingly.
3. If you are in the implementation phase, review the access design with your Implementation Manager.
4. Go to Settings > Users, and make sure the employee is assigned to the correct user group.


[](#control-how-far-managers-see-their-team-example-performance-ratings)**Control how far managers see their team (example: Performance ratings)**

1. Go to Settings > User Groups, locate the Manager user group, click the Edit (pencil) icon.
2. Open Manager Modules Permission, find the module (e.g. Performance).
3. Set the Team Access level: Direct Reports Only, 2 levels below, or Direct reports and all levels below, then Save.


- Example: if C manages B who manages A, C sees A's ratings only with "2 levels below" or wider; with "Direct Reports Only", C sees only B.


[](#what-change-history-does-briohr-keep)**What change history does BrioHR keep?**

- Changes to employment details (reporting manager, department, office, job title) are recorded in the employee's Profile > Job tab (Job History).
- There is no general audit trail showing who made a manual profile update or when. Only specific modules keep detailed action history: Profile Change Requests, User Group modifications, Leave approvals, etc.
