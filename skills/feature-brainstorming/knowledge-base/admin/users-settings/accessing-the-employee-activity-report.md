# Accessing the Employee Activity Report

*View employee account details, activation status, login activity, employment dates, and user status with brioHR’s new Employee Activity Report.*

**Audience & Scope**

Audience: HR Admin

Module: General Login Data

Country: Global

Pre-requisites: Access as the Admin of the account enabled.





Admins can now easily monitor user account and login activity with the new **Employee Activity Report** in brioHR.


This report provides a consolidated view of key user information, including account creation, activation, login activity, employment dates, and account status.





#### Enable Permission to Access the Report


Before users can access the **Employee Activity Report**, the relevant permission must be enabled for their user group.


1. Go to **Settings > User Groups**.
2. Select the relevant **User Group** and click **Edit**.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-14-2026-02-27-16-3662-AM.png?width=515&height=151&name=image-png-Aug-14-2026-02-27-16-3662-AM.png)
3. Navigate to **Pages Access** and scroll down to **Admin Settings**.
4. Enable **Allow to download employee activity report**.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-14-2026-02-21-29-1410-AM.png?width=594&height=377&name=image-png-Aug-14-2026-02-21-29-1410-AM.png)
5. Click **Save** to apply the changes.








#### Where to Access the Report


The **Employee Activity Report** is available to Admin users under:


**Settings > User > Employee Activity Report**


From the User page, admins can access the report to view the last login information of users within their brioHR account.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-14-2026-01-20-17-1983-AM.png?width=670&height=296&name=image-png-Aug-14-2026-01-20-17-1983-AM.png)


#### Information Available in the Report


The report includes the following information for each user:


- **Employee ID**
- **Employee Name**
- **Employee Email**
- **Office**
- **Created Date/Time** – The date and time the user account was created.
- **Join Date** – The employee's employment start date.
- **First Login Date/Time** – The date and time the user first logged in to brioHR.
- **Activated** – Indicates whether the user's account has been activated.
- **Most Recent Login** – The latest date and time the user logged in to brioHR.
- **Resigned Date** – The employee's resignation date, where applicable.
- **Active/Inactive** – Indicates the current status of the user account.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-14-2026-01-03-24-1332-AM.png?width=670&height=219&name=image-png-Aug-14-2026-01-03-24-1332-AM.png)


#### Supporting Billing Enquiries


The user's account billing period can be referenced based on the **Created Date to Resign Date**, where applicable. This report provides Account Admins a clearer reference when reviewing user accounts and addressing billing-related enquiries.





#### Easy Access to User Information


With the **Employee Activity Report**, admins have a convenient way to review user account details and login activity in one place. This helps support user access management, account monitoring, and billing-related checks.
