# How to Disconnect a User Session in BrioHR User Settings for Improved Security

*Learn how HR or Admin users can disconnect active user sessions in BrioHR to enhance security when employees forget to log out. Step-by-step guide included.*

In some cases, employees may log in to **BrioHR** using a public or shared device and forget to log out. By default, sessions in BrioHR remain active for **30 days**, which can pose a potential security risk.


To safeguard employee data, HR or System Admins can use the **Disconnect User Session** feature to log the employee out remotely.


**To disconnect a user session:**


1. Go to the **Settings**  > **Users** button (top right corner).
2. **Search for the employee** whose session you wish to disconnect.
3. Click on the [](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48095896259/original/jVy4ryqaNxkboM9pnVNMDSxepyxtZXLbEg.png?1617204487)button to see extended options.
4. Select "**Disconnect User Session**."

### Frequently Asked Question


**1) How does the auto log-off or session timeout work in BrioHR? Since the “Disconnect User Session” feature is enabled, will BrioHR automatically log users out after being inactive? How long is the inactivity period before auto log-off?**


BrioHR does not log users out based on inactivity. Instead, the session duration depends on whether the **“Keep me logged in”** option is selected during login:


- **If “Keep me logged in” is selected:** The user stays logged in for **30 days**.
- **If “Keep me logged in” is not selected:** The session lasts for **1 day**.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-08-2025-04-03-08-0461-AM.png?width=1572&height=691&name=image-png-Dec-08-2025-04-03-08-0461-AM.png)


**Note:** These durations reset if the user:


- clears their browser cache,
- switches to a different browser, or
- uses incognito/private mode.


**Example:**


If “**Keep me logged in**” is checked and the user logs in today, they can continue using BrioHR on the same laptop and browser for the next **30 days** without needing to log in again. On **day 31**, they will be prompted to log in.
