# How to Reset an Employee's Password in BrioHR

*Learn how HR and admin users can reset an employee’s password in BrioHR. Step-by-step guide to resolve employee login issues quickly.*

At times, employees may forget their login credentials or face login issues in **BrioHR**. As an HR or Admin user, you can reset their password directly in the system. This ensures they regain access quickly without disrupting daily operations.


This guide provides a **step-by-step process to reset an employee’s password** in BrioHR, along with an alternative option if employees want to reset their own passwords.





#### Steps to Reset an Employee’s Password


1. Log in to your **BrioHR account.**
2. Go to **Settings > Users.**
3. Use the **Search column** to find the employee by name.
4. Under the **ACTIONS** column, click on the **“...” icon.**
5. Select **Reset password.**
6. Confirm the action by selecting **Yes** in the pop-up window.
7. An email containing the **newly generated password** will be automatically sent to the employee.
