# What is Transaction ID (Claim Unique ID)?

*This article explains what the Transaction ID (Claim Unique ID) is and how to use it to find specific claims.*

### What is Claim Unique ID?


Each claim report and request is assigned a unique Transaction ID, known as the Claim Unique ID, for identification purposes. This Transaction ID is automatically generated by the system, making it easier for you to locate and search for specific claims, especially when there are numerous requests on the page that may be difficult to distinguish individually.


#### How to Check the Transaction ID for a Claim Report


- Go to **Home > My Claims**.
- Hover the mouse over the claim report name.
