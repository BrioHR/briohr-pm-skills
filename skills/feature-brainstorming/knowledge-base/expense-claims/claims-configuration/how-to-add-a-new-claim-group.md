# How to Add a New Claim Group

*This article explains how to create a claim group, which is required before setting a custom approval workflow for specific claim types.*

**NOTE:**


**To set a custom approval workflow for specific claim types, you must first create a group for those claim types.**


To create a new claim group in BrioHR, follow these steps:


Login to your BrioHR account.


- Go to **HR Lounge.**
- Navigate to **Expense Claims.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48327318306/original/HvzPIFH8NCFsd_FbByksH-XNd0oXNubehw.png?1708054977)


You will be directed to the Expense Claims landing page (Claim Request).


- Go to **Claim Groups.**
- Click the "**+ Create Claim Group**" button to start creating a new claim group.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48327318357/original/EwxwI-ptsRLxruCn8Rt0EcwLzUK0LqoB-Q.png?1708055051)


- In the "Add Group" pop-up window, enter the following details:

  - **Group Name **(required): Enter a name for the group, e.g., "Business Trip."
  - **Claim Type**: Select the claim types from the dropdown menu, e.g., "Meals" and "Hotel."
- Click "**Save**" to complete the process.
