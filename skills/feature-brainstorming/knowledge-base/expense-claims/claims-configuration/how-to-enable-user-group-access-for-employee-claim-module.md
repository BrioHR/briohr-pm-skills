# How to enable user group access for Employee (Claim Module)

*This is a step-by-step guide on how to enable access to Claim Module for Employee Modules Permission*

Login to your BrioHR account:


1. At Home, go to **Settings** at the top right of your account.


2. Go to **User Groups**


3. **Choose which user group** you want to give the access to. Click on **pencil icon** to edit and manage permissions.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-20-2024-03-11-49-7405-AM.png?width=688&height=298&name=image-png-Aug-20-2024-03-11-49-7405-AM.png)


4. Navigate to permission category: **Employee Modules Permission.**


5. Find **Claim Module**. Turn ON the toggle button to give permission for this module.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-23-2024-07-23-02-8413-AM.png?width=688&height=394&name=image-png-Aug-23-2024-07-23-02-8413-AM.png)


6. Click on **Save** button to save the setting.
