# How to Grant Manager Access to the Claim Module in BrioHR

*If you need to give managers access to the Claim Module in BrioHR, this guide walks you through the necessary steps using User Group settings.*

Managers require access to their team's Expense Claims from the Team page in order to review and approve claim submissions from their direct reports. If this permission is disabled, they will not be able to view claim details or approve any submissions.


#### Step-by-Step Guide to Enable Manager Access to Claim Module


Login to your BrioHR account:


1. Go to **Settings** at the top right of your account.


2. Go to **User Groups**


3. **Choose the user group** you want to give the access to. Click on **pencil icon** to edit and manage permissions.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-16-2025-06-31-31-2080-AM.png?width=688&height=298&name=image-png-Jul-16-2025-06-31-31-2080-AM.png)


4. Navigate to the permission category: **Manager Modules Permission.**


5. Find **Claim Module **and turn** **ON the toggle button to give permission for this module.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-23-2024-06-40-09-2794-AM.png?width=688&height=391&name=image-png-Aug-23-2024-06-40-09-2794-AM.png)


6. Under **Team Access, **choose which employees you would like managers to have access to.


7. Click the  **Save** button to apply the changes.
