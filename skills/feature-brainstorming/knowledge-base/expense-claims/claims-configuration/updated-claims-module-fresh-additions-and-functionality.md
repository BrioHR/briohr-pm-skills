# Updated Claims Module: Fresh Additions and Functionality

*This article explains the Expense Claims module updates, including the Claims Policies feature and other enhancements to claim management.*

Discover the latest impactful enhancements to our Expense Claims module, including the introduction of the exciting new “Claims Policies” feature. This update is designed to improve your experience by simplifying the setup of different claim policies and enhancing the existing features, including “Claim Types, Claim Groups, and Settings.”


In this article, we will explore in depth the enhanced and additional features:


### Claim Types


Here, you can add new claim types, edit, delete, or disable existing ones. Additionally, you can modify basic configurations such as the title, description, account code, mandatory attachment rules, and custom fields. You can also set up payroll connections and enable or disable specific claim types.


For detailed instructions on adding new claim types, click [here](https://support.briohr.com/knowledge/how-to-add-new-claim-types?hsLang=en).


**NOTE:**


**When you create a new claim type, you can decide which claim policies it should be included in. Please note that new claim types will not be automatically included in existing claim policies.**


### Claim Groups


Here, you can add, edit, or delete claim groups. If you want to set a custom approval workflow for a group of claim types, you must first create a claim group.


For detailed instructions on adding a new claim group, click [here](https://support.briohr.com/knowledge/how-to-add-a-new-claim-group?hsLang=en).


**NOTE:**


**Only grouped claim types with defined approval workflows can be included within the same claim report.**


### Claim Policies (New Feature)


This feature allows you to add, edit, or delete claim policies. You can select which claim types and approval workflows should apply to each policy, set claim type limits (per transaction, month, or year), and assign claim policies to employees.


For detailed instructions on creating and managing claim policies, click [here](https://support.briohr.com/knowledge/how-to-create-and-manage-claim-policies?hsLang=en).


**NOTE:**


**Existing users of the claims module will be automatically assigned to the "Default Claim Policy."**


### 4. Settings


Here, you can select the cut-off date, validate transaction dates, assign claim assignees, and link payroll centers to payroll items using the “Send to Payroll” feature.


For detailed instructions on configuring claims settings, click [here](https://support.briohr.com/knowledge/how-to-configure-expense-claims-settings?hsLang=en).


**NOTE:**


**Remember to save your settings at the bottom of the page and enable access to the claims module in the HR Lounge for claim assignees.**
