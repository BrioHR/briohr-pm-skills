# How to Modify and Delete Fixed Remunerations in Payroll: FAQs

*This article explains what happens when you add, modify, or delete fixed remunerations from the Payroll Dashboard, in FAQ format.*

**Q1:**


**WHAT HAPPENS WHEN YOU ADD OR MODIFY FIXED REMUNERATIONS FROM THE PAYROLL DASHBOARD (RUN PAYROLL)?**


1.   **Fixed Remunerations Already Used in Past Payroll:**


**Fixed remunerations that have been used in previous payrolls cannot be modified directly from the Payroll Dashboard. The amount will be grayed out, and there will be no "Edit" or "Delete" option available.**


**However, you can force a modification from the employee's Profile > Compensation tab > Fixed Remunerations table.**


**NOTE:**


**Force-modifying fixed remunerations that have been used in past payrolls may create inconsistencies in payslips and payroll reports.**


Click [here](https://support.briohr.com/knowledge/how-to-view-and-modify-the-fixed-remunerations-table-in-an-employees-profile?hsLang=en)to learn how.

**2.   Newly Added Fixed Remunerations:**


**Fixed remunerations added directly from the Payroll Dashboard will not be reflected in the Fixed Remunerations table at the employee's Profile > Compensation tab.**


**To add a new fixed remuneration, you must create it from the Fixed Remuneration table in the employee's Profile > Compensation tab. It will then be automatically applied to the Payroll Dashboard when you "Run Payroll," based on the effective date you select.**


Click [here](https://support.briohr.com/knowledge/how-to-view-and-modify-the-fixed-remunerations-table-in-an-employees-profile?hsLang=en)to learn how.


**Q2:**


**WHAT HAPPENS WHEN YOU DELETE A FIXED REMUNERATION BEING USED IN PAYROLL FROM THE FIXED REMUNERATIONS TABLE (PROFILE > COMPENSATION TAB)?**


**1.   If the Effective Date of the Fixed Remuneration is After the Current Payroll Month:**


**The fixed remuneration will be deleted from BOTH the Fixed Remunerations table (Profile > Compensation tab) and the payroll for the current month (Payroll Dashboard > Run Payroll) for that employee.**


**Example:**


- Current payroll month: August 2022
- You have already run payroll for August 2022.
- The fixed remuneration's effective date is set to 1st August 2022.
- If deleted from Profile > Compensation tab > Fixed Remunerations table, the fixed remuneration will also be deleted from the August 2022 payroll for that employee.


**2.   If the Effective Date of the Fixed Remuneration is Before the Current Payroll Month:**


**The fixed remuneration will NOT be deleted from the Payroll Dashboard for that employee.**


**It will also NOT be deleted from the Fixed Remunerations table (Profile > Compensation tab).**


**Instead, the end date will be modified to one day before the last payslip in which the item was included.**


**Example:**


- Current payroll month: August 2022
- You have completed the July 2022 payroll and are now running payroll for August 2022.
- The fixed remuneration's effective date was set to 1st July 2022.
- The end date for the fixed remuneration will be modified to 31st July 2022 in the Profile > Compensation tab > Fixed Remunerations table.
- The fixed remuneration will not be deleted from the July 2022 payroll for that employee.
