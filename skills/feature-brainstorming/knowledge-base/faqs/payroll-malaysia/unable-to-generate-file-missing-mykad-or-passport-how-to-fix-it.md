# Unable to Generate File: Missing MyKad or Passport - How to Fix It

*This article explains how to fix the 'Unable to generate file' warning caused by a missing MyKad or passport number.*

You want to download a statutory text file (e.g., PCB text file) and encounter a warning message:


**Unable to generate the file: <Employee Name> is missing MyKad (for Malaysian)**


**Unable to generate the file: <Employee Name> is missing Passport (for Foreigner)**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48323805667/original/gkxNN0LtacE2QyL3zQ7yTBcHTdIQooYrag.png?1705476218)


#### Why Does This Happen?


This issue occurs because the employee (as stated in the warning message) is missing their Identity Documents, such as MyKad (for Malaysians) or Passport (for Non-Malaysians).


#### How to Resolve This Warning Message


To resolve this issue, please input the missing Identity Documents by following these steps:


1. Open the **employee's personal profile**.
2. Go to the **Identity Documents** section.
3. **For Malaysians**: Enter the MyKad number in the **[MyKad]** field.
4. For **Non-Malaysians**: Enter the Passport number in the **[Passport]** field.
