# IRAS Submission Failed: How to Resolve 'Organisation Type, Organisation ID, and Basis Year Must Be Valid and Not Blank' Errors

*This article explains how to resolve the IRAS submission error about organisation type, organisation ID, and basis year when verifying IR8A.*

If you are verifying your IR8A before submitting it to IRAS and encounter the error message displayed in a red banner, follow these steps to resolve the issue:


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48324336048/original/2qlYIxea3L0Lg40iybNvIWK-o0Cumd2c1w.png?1705893371)


---


### How to Resolve the Error Message:


Log in to BrioHR:


- Go to the **HR Lounge.**
- Navigate to **Payroll Settings**:
- Select "**Payroll**" and then "**Settings**."
- Locate the '**Company Information**' Section:


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48324338049/original/B6TcVC2kH7z36d4y6Cxfn6j1z_l_uoZ5iw.png?1705895028)


Ensure that the following details are accurately filled in:


**Company Sector:** Make sure this field is correctly filled.


**Organisation ID Type:** **Select the correct category**. If you are unsure, visit the [UEN official website](https://www.uen.gov.sg/ueninternet/faces/pages/uenSrch.jspx) to verify your company's **entity type**.


**Organisation ID Number: **Ensure the number of digits matches the correct 'Organisation ID Type'. Refer to the table below for guidance. For more details, check the [UEN official website](https://www.uen.gov.sg/ueninternet/faces/pages/admin/aboutUEN.jspx).


**CSN Number:** Confirm this number is entered correctly.


**Table 1: UEN Formats**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48324337942/original/CCfVshffMDSz_BzfsjVs7Q8Bj6BLq5lFhw.png?1705894918)


**Note for Organisation ID Number :**


- 9 digits : UEN - Business Registration number issued by ACRA
- 10 digits (yyyynnnnnX) : UEN - Local Company Registration number issued by ACRA
- 10 digits (TyyPQnnnnX) : All Other entities


**Save Your Changes:** After updating the information, be sure to save the changes.


**Retry Verification:** Return to the IRAS verification page and attempt the verification again.


---


### What About the 'Basis Year' Field?


**Answer:** This is a default message. You can ignore the 'Basis Year' field unless you are submitting an assessment for a year other than 2024 (e.g., 2023, 2022, or earlier).
