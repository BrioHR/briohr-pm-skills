# brioHR Web Browser vs Mobile App: Feature Comparison Guide

*Compare the features available on the brioHR Web Browser and Mobile App. Learn which tasks can be completed on each platform and understand the differences between full system access and on-the-go mobile actions.*

#### Audience & Scope


Audience: HR Admin / Manager / Employee


Country: Global





While both the brioHR Web Browser and Mobile App help you manage your HR tasks, they are designed for different purposes.


The **Web Browser** provides full access to all HR modules, settings, and configurations, making it ideal for administrators and in-depth management tasks.


The **Mobile App**, on the other hand, is built for convenience, offering essential features and quick actions that employees and managers can perform anytime, anywhere.


Use the comparison below to understand which actions are available on each platform.


| Modules | Web Browser | Mobile App | Highlights |
| --- | --- | --- | --- |
| Employee Management | - Add employees
- Perform bulk imports/exports
- Setup profile change requests
- Search & view employee profiles | - Search & view employee profiles
- Access Task list for pending actions to be performed | - HR users can also access employee's profile and assigned modules through the Employee Management page |
| Leave | - Configure leave types and policies
- Submit leave on behalf of employees
- Manage leave submissions | - Apply leave & request credit leave through mobile app
- Manage and track leave submissions
- Approve/reject leave submissions | - Users also receive leave balance reminders via mobile app |
| Expense Claims | - Configure claim policies
- Submit claims on behalf of employees
- Manage claim submissions | - Submit new claim through mobile app
- Manage and track claim submissions

- Run monthly payroll cycles

- Approve/reject overtime submissions | - HR users can transfer overtime hours by employees to be captured and processed via Payroll |
