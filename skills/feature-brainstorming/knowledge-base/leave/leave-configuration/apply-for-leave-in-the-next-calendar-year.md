# Apply for Leave in the Next Calendar Year

*This article explains why leave types for the next calendar year may not be available yet and when employees can apply.*

** Audience & Scope**

- **Audience:** HR Admin, Employee
- **Module:** Leaves
- **Country:** Global
- **Prerequisites:** For access before January: the user group permission "Allow access to following year" (Leave module)
- **Feature available on:** Both
- **When to use this article:** Employee tries to apply for leave dated in the next calendar year and sees "no leave type available for the selected year".


**What is happening**


If an employee tries to apply for leave dated in the **next calendar year** and sees "no leave type available for the selected year", this is expected — the leave policies for that year don't exist yet.


BrioHR **automatically creates next year's leave calendar for all client accounts during Q4**. No action is required on your side.


**Step-by-Step Instructions (allow access once the new calendar exists)**

1. Navigate to the employee's **user group** settings.
2. Open **Employee modules permission** > **Leave module**.
3. Tick **Allow access to following year**.
4. The employee can now apply for leave dates in the new year.


**Common Issues / FAQ**

- **Q:** When will next year's leave calendar be available?
**A:** BrioHR creates it automatically for all client accounts during Q4 and will update clients once the calendar for the upcoming year is released.
- **Q:** Do I need to set up next year's leave policies manually?
**A:** No — the creation is automatic for all accounts. No manual work is required.
