# How to Calculate Entitlement with the "Rounding" Option Enabled

*This article explains how leave entitlement is calculated when the Rounding option is enabled, with examples of the rounding rules.*

In the Leave module of our system, calculations are based on the settings chosen, and the "Rounding" option is a feature that affects how numbers are rounded. When this option is enabled, the system adjusts the values according to specific rounding rules.


Below are examples demonstrating how calculations are performed based on the selected rounding options:


#### Example 1:


**⇒ Entitlement amount: 12 days**


- If **None **is selected: **12 days** entitlement
- **If Round up to 0.5 days is selected: 12 days entitlement**
- If **Round down to 0.5 days** is selected: 12 days entitlement
- If **< 0.5 days, round down; if ≥ 0.5 days, round up is selected: 12 days** entitlement


#### Example 2:


**⇒ Entitlement amount: 12.23 days**


- If **None **is selected: **12.23 days** entitlement
- If Round up to 0.5 days is selected: 12.5 days entitlement
- If **Round down to 0.5 days** is selected: **12 days** entitlement
- If **< 0.5 days, round down; if ≥ 0.5 days, round up is selected: 12 days** entitlement


#### Example 3:


**⇒ Entitlement amount: 12.5 days**


- If **None **is selected: **12.5 days** entitlement
- **If Round up to 0.5 days is selected: 12.5 days entitlement**
- If **Round down to 0.5 days** is selected: **12 days** entitlement
- If **< 0.5 days, round down; if ≥ 0.5 days, round up is selected: 13 days** entitlement


#### Example 4:


**⇒ Entitlement amount: 12.68 days**


- If **None **is selected: **12.68 days** entitlement
- **If Round up to 0.5 days is selected: 13 days entitlement**
- If **Round down to 0.5 days** is selected: **12.5 days** entitlement
- If **< 0.5 days, round down; if ≥ 0.5 days**, **round up is selected: 13 days** entitlement
