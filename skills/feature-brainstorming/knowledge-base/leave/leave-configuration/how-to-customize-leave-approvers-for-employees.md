# How to Customize Leave Approvers for Employees

*This article explains how to customize leave approvers for specific employees whose approval workflow differs from the general configuration.*

In this article, we will illustrate the process of customizing leave approvers for employees.


For example, if you wish to **customize **a second approver level for specific employees or if certain employees' approval workflows do **not follow the general configuration**, this guide will help.


If you would like to know how to set up or edit a General Leave Approver, please refer to this article:


[How to Set or Edit the General Leave Approver](https://support.briohr.com/knowledge/how-to-set-or-edit-the-general-leave-approver-in-briohr?hsLang=en)


To make these adjustments, navigate to the leave custom configuration section. Refer to the article below for detailed instructions on accessing the custom configuration of the leave policy:


[How to Set Up Leave Configuration](https://support.briohr.com/knowledge/how-to-set-up-custom-leave-configuration-in-hr-lounge?hsLang=en)
