# How to Enable User Group Access for Employee Modules Permission (Leave)

*This guide provides instructions to enable access to leave modules for employees in BrioHR by configuring user group permissions. Follow these quick steps to set it up.*

### Steps to Enable User Group Access for Employee Modules Permission


1. **Navigate to Settings**: Log in to BrioHR and click the **Settings** icon in the top-right corner.
2. **Access User Groups**: Select **User Groups** from the left-hand panel.
3. **Edit the User Group**: Find the user group for employees and click the **pencil icon** to edit.
4. **Enable Employee Module Permissions**: Enable **Leave Modules** in the **Employee Modules Permission** section.
5. **Configure Specific Permissions**: Tick the relevant options for leave configurations.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-06-2024-04-23-30-4989-AM.png?width=688&height=538&name=image-png-Dec-06-2024-04-23-30-4989-AM.png)


By completing these steps, employees in the designated user group will have access to the leave module in BrioHR.
