# How to Manage Half-Day Leave for Employees

*This article explains how to enable or disable half-day leave booking in leave policies for your employees.*

Introducing the new Allow Booking Half-Day Leave Feature on BrioHR!


This new feature provides the option to enable or disable booking half-day leave in the system. Once enabled for the leave policies, employees can choose between full-day and half-day leaves. However, if this option is disabled, employees will only have the option to apply for full-day leaves.


### How to Manage Half-Day Leave Settings:


To view and manage the settings for this feature, follow these steps:


**Navigate to HR Lounge > Leave Policies > Find a leave type (eg, Annual) > Scroll down to Leave Advance Settings > Enable or Disable the Allow Booking Half-Day Leave option**


**By default, this option is enabled, but you can choose to disable it if needed.**

### Admin Leave Application Scenarios


#### Scenario 1: Half-Day Leave Enabled


- When an admin applies for leave on behalf of an employee, they can choose **Morning or Afternoon only**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48301226562/original/lHVTXSz2EVaxqaukD4cGmNJGfrS6GukdZA.png?1686628317)


#### Scenario 2: Half-Day Leave Disabled


- The **Morning and Afternoon** only options are **no longer available**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48301227211/original/R3HHY8YjDhrBw_qz4foMzoeyAUH8aRkxJQ.png?1686629264)


#### Scenario 3 - This option is only available to the Admin.


If there are any special arrangements for an employee on an application basis or if there are scenarios where the employee is allowed to apply for half-day leave, the Admin can apply for this leave on behalf of the employee through the system.


By clicking on "**Skip Validation**," the Admin bypasses all the rules set up for the employee's leave policy, **including the restriction on half-day leave booking**.


Therefore, even though the policy may be set to **disable **half-day leave bookings, the **Admin can click on "Skip Validation" and will have the option to select half-day leave (either Morning or Afternoon) for the employee when applying for the leave.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48301227334/original/YtEuJ_clP8ZxH61l5DQUdX167ELz6H03bA.png?1686629515)


#### Scenario 4: Post-Submission Changes (Enabling Half-Day Leave)


If the admin changes the setting to enable half-day leave after an employee has submitted a leave request, the employee can modify their request to select the half-day option.

#### Scenario 5: Post-Submission Changes (Disabling Half-Day Leave)


If the admin changes the setting to disable half-day leave after an employee has submitted a leave request, the employee can no longer select the half-day option upon modification.


Refer to the video for a clearer explanation of the scenario.

**NOTE:**


**If changes are made before an employee submits their leave, the half-day option will follow the current setting. If the setting changes afterward, the leave must be canceled and reapplied.**


**If the leave type includes multiple policies, changes must be made individually for each policy.**
