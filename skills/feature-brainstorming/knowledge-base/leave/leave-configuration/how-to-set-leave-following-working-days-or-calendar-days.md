# How to Set Leave Following Working Days or Calendar Days

*Learn how to configure leave settings to follow either working days or calendar days in BrioHR. Adjust the settings to control leave applications for weekends and holidays based on your company's policies.*

### Steps to Set Leave Based on Working Days or Calendar Days


1. Go to **HR Lounge** and navigate to the **Leave Module**.
2. Select the applicable **leave type** and **policy**.
3. In the **Leave Advanced Settings**, toggle the **"Use Working Days"** option:


  - **ON**: Only **working days** are deducted from the leave balance.

    - Employees can select a date range that includes weekends or public holidays, but non-working days are not counted.
    - **Example**: If working days are set to Monday to Friday, a leave request from Friday to the following Monday deducts only 2 days (the Friday and the Monday).


1. - **OFF**: Employees can apply for leave on **any calendar day**, including **weekends** and **public holidays**.
2. Save the changes to apply the updated settings.
