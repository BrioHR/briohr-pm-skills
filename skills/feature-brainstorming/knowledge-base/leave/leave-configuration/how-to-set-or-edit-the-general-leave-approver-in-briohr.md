# How to Set or Edit the General Leave Approver in BrioHR

*This article explains how to set or edit the general leave approver in a leave policy, applying to all employees assigned to it.*

To set a **general leave approver** for any leave type, you can configure it on the Leave Policy settings page.


The leave approver workflow setup **will apply to all employees assigned to this policy**.


**If you would like to customize the leave approver for a specific employee, please refer to this article:**

[[How to Customize Leave Approver for Employees?](https://support.briohr.com/knowledge/how-to-customize-leave-approvers-for-employees?hsLang=en)]

1.   Log in to your BrioHR account, then click on **HR Lounge > Employee Leave**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48304689670/original/X_oOZn5TeW5E0ehjXAnM3wdT3GEunofKWg.png?1689579114)


2.   Click on **Leave Policies > View Leave Details**.


(Select the leave type you want to set up or edit. For example, if you are setting up or editing the approver for Annual Leave, click on View Leave Details under Annual Leave.)


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48153495066/original/542n0tIrWEMZM3LtV3geBjamuIXjZw0dkA.png?1635742287)


3.   Select the policy type under **POLICY CONFIGURATIONS**.


4.   In the **APPROVAL **column, you can set or edit the **First Approver** and/or **Second Approver** to approve leave requests. The approver can be set according to:


- **Position                   ⇒  Equal to the line manager as stated in the employee's profile.**
- **Specific Employee ⇒  Select any employee as the approver.**
- **None:                       ⇒  No approver required.**


**NOTE:**


**If the 'Second Approver' field is enabled, the employee will require both first and second approvals for the leave to be approved. Approval will be done in sequence.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48153496683/original/3SSyRsVBXA1h3zGf6ADwbIr8v04-ffuM2w.png?1635743183)


5.   Click on **Save Settings** to complete the action.
