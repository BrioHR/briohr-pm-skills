# Efficient Employee Leave Management: View and Manage Bulk Leave Applications

*This article explains how to view and manage bulk leave applications and credit leave requests using the Leave Management filters.*

### Steps to View and Manage Leave Applications:


1.   At **HR Lounge**, click on "**Leave**."


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48238796000/original/IFXktbbUsMAoo3Txj_77t3chvs82vGpatw.png?1657868050)


2.   Click on "**Leave Management**" to view:


- **Leave overview**
- **Credit leave overview**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48238798262/original/rqBLpkquj6PjUCmskzdM9gVNw70QzN7gSQ.png?1657868758)


3.   Utilize the available filters to customize your search according to:


- **Year**
- **Employee Name**
- **Leave Status**
- **Leave/Credit Type**
- **Month **(for Leave overview only)
- **Department**
- **Office**
- **Expiry Date **(for Credit leave overview only)

**NOTE:**


**It is advisable to filter the Leave/Credit leave applications according to the same status before performing bulk actions.**


For example, if leave applications with two different statuses ("**Approved**" and "**Pending**") are selected simultaneously, the HR Admin will be restricted from clicking the "**Approve/Reject/Require** **info**" buttons. This restriction ensures that bulk actions are performed only on applications with the same status.
