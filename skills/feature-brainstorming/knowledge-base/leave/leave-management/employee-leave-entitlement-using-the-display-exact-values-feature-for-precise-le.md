# Employee Leave Entitlement: Using the 'Display Exact Values' Feature for Precise Leave Balances

*This article explains how the Display Exact Values feature shows precise accrued leave balances based on your rounding rules.*

The '**Display Exact Values**' feature simplifies the display of accrued leave balances by showing the exact values **based on the rounding rules** that have been set. It addresses the challenge of calculating and rounding up leave accruals and offers a more transparent and precise representation of an employee's available leave.


This feature applies to leave types that have the '**Rounding**' option enabled, whether to round the leave balance up or down. By clicking on the 'Display Exact Values' button, you can see the actual accrued leave value of the employee.
