# How to Enable Next Year's Employee Leave Applications  (Web & Mobile App)

*Learn how to enable employee leave application submissions for next year on both web and mobile platforms. Ensure access is properly set and updates are applied for smooth leave management.*

**Audience & Scope**


Audience: HR Admin


Module: Leave


Country: Global


Prerequisites: User group settings: Admin access to User Group Settings





As a HR Admin, you need to enable permission for employees to apply next year's leave in their respective User Groups before employees can start applying next year's leave date.


**NOTE:**


If you're an employee and looking for how to apply next year's leave from the web browser and mobile application, please see [this article](https://support.briohr.com/knowledge/how-to-apply-for-future-leave-in-advance?hsLang=en).


###


#### Step-by-Step: Enable Next Year's Leave Access


To enable employees to submit their next year's leave applications, the HR/Admin must follow these steps:


1.  Log in to your brioHR account using your registered credentials.


2. Navigate to **Settings **then click into **User Groups.**


3. Find the **user group** that you want to edit (e.g, Employee & Manager)


4. Click** pencil icon** to edit.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-19-2026-09-29-29-3592-AM.png?width=670&height=280&name=image-png-Jan-19-2026-09-29-29-3592-AM.png)


5. Open the category **'Employee Modules Permissions'**


6. Search for the **Leave Module.**


7. Select the checkbox** 'Allow access to following year'**


8. Click **Save**


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-19-2026-09-29-36-1373-AM.png?width=670&height=435&name=image-png-Jan-19-2026-09-29-36-1373-AM.png)


####


#### Verification and Submission:


Once this setting is enabled, employees will be able to submit their leave requests for next year using the system.


**IMPORTANT: **


When the employee applies the leave for next year, there is a banner to indicate that the Public Holidays has not been set up at the moment.


**Public Holidays for the following year is usually added in Quarter 4 of the current year. **


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-30-2026-02-15-23-7596-AM.png?width=670&height=557&name=image-png-Jul-30-2026-02-15-23-7596-AM.png)


#### Leave Application Process:


##### Web Browser:


After enabling access, employees can **select the next year **rom the dropdown menu on the leave application page.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-19-2026-09-31-56-6251-AM.png?width=670&height=322&name=image-png-Jan-19-2026-09-31-56-6251-AM.png)





##### Mobile App:


Once access is enabled, employees will be able to **select the next year **from the dropdown menu within the app.


![image](https://support.briohr.com/hs-fs/hubfs/undefined-Sep-25-2024-09-48-01-9906-AM.png?width=670&height=195&name=undefined-Sep-25-2024-09-48-01-9906-AM.png)


**NOTE:**


This process does not apply to Childcare Leave in Singapore due to Ministry of Manpower (MOM) restrictions.

For more information on Childcare Leave utilization, refer to this [article](https://www.mom.gov.sg/employment-practices/leave/childcare-leave).


#### What Happens if Access to Following Year Leave is Not Enabled?


If the **Allow access to the following year** option is not enabled, employees will not be able to submit leave requests for next year. Ensure that this setting is activated as shown in the steps above.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-19-2026-09-34-36-3554-AM.png?width=670&height=328&name=image-png-Jan-19-2026-09-34-36-3554-AM.png)
