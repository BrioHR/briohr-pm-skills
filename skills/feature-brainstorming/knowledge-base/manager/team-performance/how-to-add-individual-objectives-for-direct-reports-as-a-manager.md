# How to Add Individual Objectives for Direct Reports as a Manager

*This article explains how managers can add individual objectives on behalf of direct reports once the performance cycle has started.*

Managers can add individual objectives on behalf of their direct reports once the performance cycle has started. This can be done through the employee's personal performance page.


As a manager/appraiser, you can create direct connections between your objectives and those of your direct reports using the **Cascading Objectives feature**. [Click [here](https://support.briohr.com/knowledge/performance-objectives-cascading-goals-feature-for-improved-alignment?hsLang=en) to learn more about this feature.]


---


### Steps to Add Individual Objectives:


Log in to your BrioHR account.


1.    Go to the **Team** section.


2.    Click on **Team Performance**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48315443224/original/zaO-9T7bZjT9m3EG2AXLh7csf_Dh6EWt8w.png?1698381359)


3.    Open your direct report's Performance page by clicking on **See Details**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48315443278/original/XaiHfTDwxM-82JK7Ju9eiv2Ssrp2GbabwQ.png?1698381409)


4.    Navigate to the Objectives section and click on the **+ Add New Objective** button.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48315443308/original/KuJz70IQCulwNIPXwJ6nfLUVnNmaMiYZoQ.png?1698381472)


5.    A pop-up template will appear where you can enter a **new objective**. Fill in the fields provided.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48315443536/original/ZFVkiz1lvJYhGHAQLbYIPp-P0uYPpef4bg.png?1698381789)


---


#### Breakdown of Objective Fields:


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48315443545/original/M3cuK_3myYOYgyDics6Pk3G0_q00A2gQ5g.png?1698381799)


- **Objective Name:** Add a S.M.A.R.T. objective name.
- **This is a non-rated objective (optional)**: If selected, this objective will not be included in the appraisal form.
- **Target Date:** Set the expected completion date for this objective.
- **+ Add Description (optional)**: Include any additional details.
- **Weightage**: Define the weightage scale for this objective. A higher weightage percentage indicates greater importance in the performance assessment.
- **Contributor (optional)**: Assign another employee to assess/rate this objective (non-appraiser).
- **Category**: Choose from existing categories or type a new one.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48315445727/original/cmd3kPdpUTtsBrj7V2wWhlCBbWUHn0Kekw.png?1698384252)


**A.   Key Results:**


- **Measurable Types**: Select from Number, Percentage, or Currency.
- **Start Value**: The initial value to track progress.
- **Target Value**: The final target value that determines if this key result is achieved.
- **Target Date**: Set the date for achieving the key result.


**B.   Qualitative Goals:** List goals that emphasize measures of success rather than numerical or quantifiable metrics.


6.    Once you've filled in the necessary information, click on **Save**.


---


Return to the Objectives page to see the newly created individual objective for your direct report.
