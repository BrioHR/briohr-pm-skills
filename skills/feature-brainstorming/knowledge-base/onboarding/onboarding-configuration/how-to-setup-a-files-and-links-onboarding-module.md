# How to setup a Files & Links (Onboarding Module)

*This is a step-by-step guide on how to add any files or links you want to share with the new joiner such as the employee handbook, company intranet link & etc. in Onboarding Module*

Login to your BrioHR account:


1. At **HR Lounge**, click on **Onboarding (new)** menu.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-09-2025-08-42-17-0055-AM.png?width=688&height=365&name=image-png-Jan-09-2025-08-42-17-0055-AM.png)


2. At **Process** page, click on **See details button** to update the Onboarding Process.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-09-2025-09-46-52-2366-AM.png?width=688&height=206&name=image-png-Jan-09-2025-09-46-52-2366-AM.png)


3. Scroll down the page until you see **Files & Links** section.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-09-2025-09-50-07-9825-AM.png?width=688&height=399&name=image-png-Jan-09-2025-09-50-07-9825-AM.png)


4. Click on **+Add file / link button** to add new file or link that you want to share with the new joiner.


5. Click on arrow to expand the **File /Link 1** to update the setting.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-09-2025-09-56-44-9955-AM.png?width=688&height=462&name=image-png-Jan-09-2025-09-56-44-9955-AM.png)


6. Key in **Title** for the File / Link


7. Choose the **Type** for File / Link from the drop down selection.


i) If the selection is **URL Links**, you need to enter the **Web URL Links.**


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-09-2025-09-59-27-9770-AM.png?width=688&height=433&name=image-png-Jan-09-2025-09-59-27-9770-AM.png)


ii) If the selection is **Upload file**, please choose file to be upload.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-09-2025-10-00-51-6770-AM.png?width=688&height=494&name=image-png-Jan-09-2025-10-00-51-6770-AM.png)


8. Set the period for the file/link to be available to the new joiner either by month(s), week(s) or day(s) after or before join date.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-09-2025-10-05-00-0397-AM.png?width=688&height=534&name=image-png-Jan-09-2025-10-05-00-0397-AM.png)


9. If more file/link need to be added, click on **+Add file / link button **and repeat the same steps as above.


10. Click on **Save button** to save the setting.
