# Bank Muamalat Malaysia Berhad (MY): How to Generate Bank File for Payroll Payment

*This article explains how to generate and download payroll bank file in BrioHR for Bank Muamalat Malaysia Berhad (MY), to upload to the bank portal.*

**Audience & Scope**


Audience: HR Admin / Payroll Processor


Module: Payroll


Country: Malaysia





#### Step 1: Setting Up The Bank Account


1. In **HR Lounge**, navigate to the **Payroll module**.
2. Click on **Settings **and scroll down to the **Bank Account** column.
3. In the "**Bank Account**" field, select **Bank Muamalat Malaysia Berhad**


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-02-2026-01-23-59-0943-AM.png?width=670&height=280&name=image-png-Mar-02-2026-01-23-59-0943-AM.png)
**
**
4. Enter the required information in the fields provided (refer to the sample screenshot below)

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-02-2026-01-24-55-7825-AM.png?width=670&height=280&name=image-png-Mar-02-2026-01-24-55-7825-AM.png)
5. Click **Save at the bottom of the Settings page** to complete the setup.


** **


**NOTE**:

The function to '**Fill in employee Identity/Passport number**' is optional as some bank specifications require for this information to be filled in when the bank file is generated. Therefore, you may proceed to **enable** this function before the bank file is generated.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-02-2026-01-25-20-9203-AM.png?width=670&height=280&name=image-png-Mar-02-2026-01-25-20-9203-AM.png)





#### Step 2: Downloading The Bank File


1. In **HR Lounge**, navigate to the **Payroll module**.
2. In the **Payroll** **Dashboard**, click on the** payroll month** for which you want to process payments.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-02-2026-01-49-09-7922-AM.png?width=670&height=284&name=image-png-Mar-02-2026-01-49-09-7922-AM.png)
3. If your payroll month is still 'Ongoing', click the '**See details**' button for the payroll cycle you wish to pay out for.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-02-2026-02-02-51-0888-AM.png?width=540&height=466&name=image-png-Mar-02-2026-02-02-51-0888-AM.png)
4. If your payroll month is 'Completed' and has multiple cycles, select which **payroll cycle** you wish to pay out for.
5. Find the **Bank File** column and click the **Download** button (as shown in the sample screenshots below) to download the bank file.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-02-2026-01-34-25-6746-AM.png?width=670&height=264&name=image-png-Mar-02-2026-01-34-25-6746-AM.png)
6. In the "**Download bank file for Bank Muamalat Malaysia Berhad**" pop-up window:
7. Select the **employee(s)**.
8. Click **Download **to download the file.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-02-2026-01-35-31-6208-AM.png?width=670&height=262&name=image-png-Mar-02-2026-01-35-31-6208-AM.png)
9. Once you have downloaded the bank file for Payroll, proceed to **upload the file to the Bank's Portal for payment**.


**NOTE:**


**If any information is missing, you will be unable to generate the bank file, and a warning prompt will appear (as shown in the screenshot below).**


**To resolve this, input the missing information and then attempt to generate the bank file again.**

#### Common Issues/ FAQ


**1. The bank file that is uploaded shows an error message of invalid format**

Ensure that the correct file is being used to upload onto the correct portal. For example, if the bank file downloaded is being uploaded onto the Statutory portal, this error message will appear.


**2. The bank file uploaded states that there is incomplete information - missing Identity/Passport Number**


Ensure the toggle to Fill in the Identity/Passport Number has been enabled before the bank file is generated.
