# Find Default Overtime Payroll Items and Add to OT Multi-rates Table

*This article explains how to find the list of available payroll items for overtime in brioHR payroll. The OT item can be added to the OT multi-rates table to make it easier for admins and payroll managers to enter OT hours paid out with specific multipliers or amount.*

**Audience & Scope**


Audience: HR Admin & Payroll Manager


Module: Payroll


Country: Malaysia


Pre-requisites: HR Module Permission for Payroll Module & Module Settings





**Step-by-Step Instructions**


**PART 1: FIND DEFAULT OVERTIME PAYROLL ITEMS**


1. Go to **HR Lounge > Payroll > Settings > Payroll Items**


**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-37-51-7982-AM.png?width=670&height=361&name=image-png-May-26-2026-08-37-51-7982-AM.png)
**


2. Type 'Overtime' in the search bar. The default overtime items are those with the square icon.


**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-09-19-32-1963-AM.png?width=670&height=411&name=image-png-May-26-2026-09-19-32-1963-AM.png)
**


Currently, the system **default** Overtime payroll items available are:


- Hourly rates X **0.5**, **1**, **1.5**, **2**, **2.5**, **3**
- **Off day** (hourly rate X 1.5)
- **Normal day**, **rest day**, **public holiday** rate (according to the Employment Act)
- **Custom amount**





**IMPORTANT**:


Difference between Overtime Rest Day vs Off Day calculation:


- **R****est ****d****ay ****rate:**

  - less than half day worked → 0.5 × ORP
  - more than half day worked → 1.0 × ORP
  - Exceeding normal work hours → 2 × HRP per hour
- **Off d****ay ****rate:** 1.5 × HRP per hour





**NOTE:**


Default Payroll items cannot be edited. If you need an overtime payroll item with a specific setup, you will have to create a custom payroll item.


Refer to [this article](/knowledge/create-an-overtime-custom-payroll-item-and-add-it-to-the-overtime-multi-rates-table?hsLang=en) for more guidance.


These items can be added in the first stage of payroll processing (Adjust payroll)


- You can add items (as an addition) under a specific employee


Refer to this article on [Adding Overtime Hours for an Individual Employee](/knowledge/adding-overtime-hours-for-an-individual-employee?hsLang=en)


- You can add items in bulk by using the Overtime multi-rates table or Excel upload


Refer to this article on [How to Add Overtime Hours in Bulk to Payroll](/knowledge/how-to-add-overtime-hours-in-bulk-to-payroll?hsLang=en)


**PART 2: ADD OVERTIME ITEM IN MULTI-RATES TABLE**


1. Run payroll for any cycle


2. In the Adjust Payroll Stage, click the **Overtime** button to open the Overtime Multi Rates table


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-45-20-2322-AM.png?width=670&height=399&name=image-png-May-26-2026-08-45-20-2322-AM.png)


3. Click '**Set table columns**'


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-46-04-7581-AM.png?width=670&height=396&name=image-png-May-26-2026-08-46-04-7581-AM.png)


4. Click '**Change column selection**'


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-46-39-1542-AM.png?width=670&height=511&name=image-png-May-26-2026-08-46-39-1542-AM.png)


5. Tick the new Overtime item you just created, then click 'Selection done'.


**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-09-28-55-9086-AM.png?width=658&height=705&name=image-png-May-26-2026-09-28-55-9086-AM.png)
**


6. You can reorganize the placement of the OT items in the table by dragging the 3-line icon next to the item name


7. Click 'Save'


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-51-38-9512-AM.png?width=670&height=507&name=image-png-May-26-2026-08-51-38-9512-AM.png)


8. You should see the updated table. You can now enter in the Overtime hours/amount for the overtime items to be processed in the payroll cycle.
