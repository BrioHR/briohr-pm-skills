# How to calculate EPF contribution using KWSP Calculator

*Learn how to easily calculate both employer and employee EPF (Employees Provident Fund) contributions with the official KWSP calculator. This step-by-step guide helps you determine the exact amounts to be deducted, including any excess contributions.*

Follow these simple steps to calculate your EPF (Employees Provident Fund) contribution using the official KWSP (Kumpulan Wang Simpanan Pekerja) online calculator:


1. **Go to the KWSP Calculator Website**


  - Visit the official KWSP portal and access the[EPF calculator tool](https://secure.kwsp.gov.my/KWSP_files/contributionCalculator/index_en.html).
2. **Fill Up the Fields**


  - Complete all required fields, including salary and other necessary details in the form.
3. **Insert the Excess Contribution Rates** (if applicable)


  - If either the employer or employee is contributing more than the standard percentage, input the additional percentage or amount in the designated field.
4. **Click Calculate**


  - Once all fields are filled in, click the "Calculate" button to view the exact contribution amounts for both the employer and employee.


This guide helps you quickly calculate the correct EPF contributions based on the provided salary and additional contributions, if applicable.
