# How to Generate Bank Files for Payroll, PCB, EPF, SOCSO & EIS with RHB Bank Berhad

*This article explains how to set up an RHB Bank Berhad account and generate bank files for payroll, PCB, EPF, SOCSO, and EIS payments.*

### Step 1: Bank Account Setup


- In **HR Lounge**, navigate to the **Payroll **section.
- Click on **Settings**, scroll down to the **BANK ACCOUNT** column, and in the "**Bank Account**" field, select "**RHB Bank Berhad**."


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48326266514/original/CdNhfsgpBkeXslvsQFdzukVduJOFou4NAw.png?1707266866)


- Enter the required information in the fields (refer to the sample screenshot below) and click **Save at the bottom of the Settings page** to complete the setup.


**NOTE:**


**To successfully download the bank file(s) containing complete information, ensure that all fields are filled out as highlighted in the screenshot below.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48326266641/original/cCltqypjnUAMbq0O7gM4n-fP-s6K9dD8ZQ.png?1707267053)


### Step 2: Downloading The Bank File - Bank Portal Upload


- In **HR Lounge**, go to **Payroll**.
- On the **Payroll History** dashboard, select the **COMPLETED **payroll cycle you wish to process payments for.
- Scroll down to the **Bank File** column and, depending on your payroll cycle, click the **Download **button (refer to the sample screenshots below) to download the bank file.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48326266900/original/mJwaeKhvTQq9rjsv3SF1KYfJIq0MCdJ31w.png?1707267410)


- In the "**Generate Bank File for RHB Bank Berhad**" pop-up window:

  - Select the bank file type;
  - Choose the employee(s); and
  - Click **Generate **to download the file.


![ENKHEauDNlSEgfhJZiFahiU4nUX5hbqtcg.png?1707267576](https://support.briohr.com/hs-fs/hubfs/Imported%20images/ENKHEauDNlSEgfhJZiFahiU4nUX5hbqtcg.png%3F1707267576.png?width=500&height=377&name=ENKHEauDNlSEgfhJZiFahiU4nUX5hbqtcg.png%3F1707267576.png)


- After downloading the bank file for Payroll or EPF/SOCSO, **upload it to the bank's portal for payment**.


**NOTE:**


**If any information is missing, you will not be able to generate the bank file. A warning prompt will appear (refer to the screenshot below).**


**In this case, input the missing information and generate the bank file again.**


![mXLuhL-ofYsJof0retukYkiSUhcShjjWdQ.png?1707267631](https://support.briohr.com/hs-fs/hubfs/Imported%20images/mXLuhL-ofYsJof0retukYkiSUhcShjjWdQ.png%3F1707267631.png?width=283&height=249&name=mXLuhL-ofYsJof0retukYkiSUhcShjjWdQ.png%3F1707267631.png)


### Downloading The Text File - Statutory Portal Upload


- If you prefer to upload Statutory Text Files directly via the Statutory Portal, generate the text file from the Statutory Reporting category below.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48327505419/original/6cS5UDlI0ZEdCfEL_FpCzV4Mq3VVONxk0g.png?1708311914)


- Once the text files are downloaded from the system, **upload them directly to the Statutory Portals (e.g., KWSP, LHDN)**.


**NOTE:**


**Verify the files generated from the system. If you upload a file from the Statutory Reporting category while making payments via the Bank Portal, you will receive an error message indicating an incorrect format.**


**You can only successfully upload the files if they are downloaded from the correct category and uploaded to the appropriate portals.**
