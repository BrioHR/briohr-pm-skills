# How to Generate EPF Form A

*This article explains how to download the EPF text file from BrioHR or generate Form A manually through the KWSP portal.*

As BrioHR is an automated payroll system, users can easily download the **EPF Text File** directly from their BrioHR account by following these steps:


- Navigate to HR Lounge
- Go to Payroll
- Select the Payroll Month
- Click on Statutory Reporting
- Choose EPF
- Download the Text File


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48162421606/original/ZmD8ktQJMELvwVp-hMFMudsaHzcPlrPKsA.png?1637655919)


Alternatively, if you prefer not to download the EPF Text File and wish to **manually generate Form A through the KWSP i-Akaun portal** (for employers only), you can do so by clicking the link below:


[KWSP i-Akaun (Employer)](https://secure.kwsp.gov.my/employer/employer/login)


**NOTE:**


**After downloading Form A from the KWSP i-Akaun portal, you will need to manually complete the required details before submitting it directly to KWSP.**
