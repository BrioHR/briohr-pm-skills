# How to Add and Import Unpaid Leave to Payroll

*Learn how to efficiently add and import unpaid leave to payroll with our step-by-step guide. Discover manual and automated methods to ensure accurate payroll calculations.*

Managing unpaid leave efficiently in your payroll system is crucial for accurate compensation. Here are two methods you can use to add and import unpaid leave into your payroll:


### Method 1: Manually Add the Number of Unpaid Leave Days


- Enter the number of unpaid leave days in the designated text box.
- The system will automatically calculate the amount to be deducted from the payroll.


### Method 2: Import Unpaid Leave Days from Employee Records


- Import the number of unpaid leave days directly from the employee’s personal leave dashboard.
- Choose the date range for which you want to import leave data.
- The system will automatically update the payroll based on the selected date range.


**IMPORTANT: **
Unpaid leaves applied and approved through the Leave module does not automatically get deducted in payroll, the **Unpaid Leaves will need to be imported into the payroll cycle for the deduction to be captured**.
