# How to Set an Hourly Rate Salary for Employees

*This article explains how to set an hourly rate salary for employees who are paid based on hours worked.*

In this tutorial, we'll guide you through the process of setting an hourly rate for employees who are paid based on the number of hours they work. Follow these steps to successfully add and manage an hourly rate:


- Navigate to Employee Information
>> Go to the People section and type in the employee's name.
- Access the Employee's Profile
>> Click on the employee's name to open their personal profile.
- Open the Compensation Tab
>> Go to the Compensation tab to add the hourly rate.
- Locate the Salary Table
>> Find the Salary Table section within the Compensation tab.
- Add a New Salary Rate
>> Click on **+Add Salary** to create a new salary entry.
- Set the Effective Date and Rate
>> Choose an effective date for the new rate. **Select Hourly** as the rate type and enter the amount (rate).
- Save Your Changes
>> Click Save to apply the new hourly rate to the employee's profile.
