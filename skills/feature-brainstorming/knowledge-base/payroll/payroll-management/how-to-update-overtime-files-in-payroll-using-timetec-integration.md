# How to Update Overtime Files in Payroll Using TimeTec Integration

*This article explains how to download overtime reports from TimeTec and upload them into BrioHR payroll using the TimeTec integration.*

For companies utilizing the TimeTec integration, here's a step-by-step guide on how to upload overtime files into payroll.


**Step 1:** Download the Overtime Hours Report from TimeTec


**NOTE:**


**During the implementation process, BrioHR will notify TimeTec about the clients using this integration. This ensures that TimeTec can prepare the necessary report for the file upload.**


**Step 2:** Adjust the Report to Match BrioHR’s Template Header


Change the Template Header: The client must modify the template header to align with the BrioHR template header. You can find the [BrioHR Template Header](https://docs.google.com/spreadsheets/d/1r1nJEuamdWJCWp4HqDygqVwxAPapdBr9E2fahRJtoWg/edit?usp=sharing) link attached for your perusal.


a. After downloading the report from TimeTec, copy the data (**excluding the header**).


b. Paste the copied data into the BrioHR template provided.


c. Save the file, which will be used for the payroll upload.


**Step 3:** Upload the File to BrioHR Payroll


Follow these steps to upload the overtime file into BrioHR:


- Navigate to **HR Lounge > Payroll > Dashboard.**
- Select the relevant **Payroll Cycle.**
- Go to **Overtime > Import Overtime.**
- Choose the **file and upload the template with the BrioHR header**.
- Finally, **upload the Excel file.**
