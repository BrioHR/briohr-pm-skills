# Refresh a Payroll Cycle After Employee Profile Changes

*This article explains why profile changes don't appear in an already-created payroll cycle and how to refresh the cycle to pick them up.*

** Audience & Scope**

- **Audience:** HR Admin
- **Module:** Payroll
- **Country:** Global
- **Prerequisites:** Access to HR Lounge > Payroll
- **Feature available on:** Web
- **When to use this article:** HR Admin updated employee information (e.g. EPF number, bank details) but the statutory or bank files still report it as missing in an existing payroll cycle.


**What is happening**


Changes to an employee's profile made **after a payroll cycle was processed are not picked up automatically** by that cycle — statutory or bank files may report missing information even though the profile is up to date.


**Step-by-Step Instructions**

1. Navigate to **HR Lounge** > **Payroll** > **Ongoing monthly payroll**.
2. Reopen the cycle you want to reprocess.
3. In the **Adjust** stage, **search for the employee** whose profile you updated.
4. Follow the **Refresh** instruction that appears to include the recent profile changes.
5. If no Refresh instruction is shown, add a **redundant payroll item** and then **delete it** — this forces a refresh.
6. Check that the employee's payroll is processed correctly.
7. Generate the statutory / bank files again.


**Common Issues / FAQ**

- **Q:** I uploaded the EPF numbers but the bank file still says they are missing — why?
**A:** The information was updated after the payroll cycle was created, so the cycle didn't pick it up. Refresh the affected employee(s) as described above and regenerate the files.
- **Q:** Should I refresh the whole cycle?
**A:** Refresh only the employees whose information changed.
