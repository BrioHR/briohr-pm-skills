# Set Up a Recurring Fixed Remuneration Over Several Months

*This article explains how to pay an employee a fixed monthly amount over a defined period using Fixed Remunerations, including a different final instalment.*

** Audience & Scope**

- **Audience:** HR Admin
- **Module:** Payroll
- **Country:** Global
- **Prerequisites:** Access to employee profiles (Compensation tab)
- **Feature available on:** Web
- **When to use this article:** HR Admin wants to pay a fixed monthly amount (e.g. a device reimbursement) over a set number of months, possibly with a smaller last payment.


**Step-by-Step Instructions**

1. Open the **employee profile** > **Compensation** tab.
2. Under **Fixed remunerations**, add the pay item and the monthly **amount**.
3. Set the **start date** and **end date** (e.g. 24 months).
4. Each payroll cycle in the period automatically includes the item.


**Common Issues / FAQ**

- **Q:** The final instalment is different from the others — how do I set that up?
**A:** End the recurring item one month earlier and add a one-off item for the final month. Example:
1. Device reimbursement item — effective 1 Jan 2026 to 30 Nov 2027, RM150.
2. Device reimbursement item — effective 1 Dec 2027 to 31 Dec 2027, RM120.
