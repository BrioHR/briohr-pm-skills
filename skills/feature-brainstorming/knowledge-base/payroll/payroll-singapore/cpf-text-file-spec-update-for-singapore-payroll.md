# CPF Text File Spec Update for Singapore Payroll

*This article explains the CPF text file specification update after MOM stopped collecting the Foreign Worker Levy through CPF EZPay.*

Effective 26 September 2022, the Ministry of Manpower (MOM) will no longer collect the Foreign Worker Levy (FWL) and any FWL late payment interest through CPF EZPay. This change aligns with MOM’s strategy to consolidate levy payments directly under their management. Learn more about the available levy payment methods [here](https://www.mom.gov.sg/faq/work-pass-general/how-do-i-pay-my-foreign-workers-levy-if-my-giro-application-has-not-been-approved).


### Important Update for Employers Using CPF EZPay (FTP)


If you are submitting payments via CPF EZPay (FTP), please be aware of the updates to the FTP Specifications starting from 26 September 2022. It is crucial to ensure compliance with these changes, as any FTP submissions that include payment for FWL and/or FWL late payment interest after this date will be rejected.


At BrioHR, we have proactively updated our system to reflect these changes, ensuring seamless compliance for our users.


For more detailed information on the File Specifications, please refer to the following resources:


CPF EZPay File Specifications [here](https://www.cpf.gov.sg/content/dam/web/employer/making-cpf-contributions/documents/CPFEZPayFTPSpecifications.pdf).
