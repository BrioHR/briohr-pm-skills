# Manage Self-Help Group (SHG) Contributions with Custom Values (Payroll Singapore)

*Configure Self-Help Group (SHG) contributions for Singapore employees with default or custom values, giving HR greater flexibility during payroll processing.*

**Audience & Scope**


Audience: HR Admin, Payroll Manager


Module: Payroll


Country: Singapore


Prerequisites: Access to Employee Payroll details and Payroll Module in HR Lounge








Managing Self-Help Group (SHG) contributions is now more flexible for Singapore payroll centers. HR Admins can now configure each employee's SHG contribution individually and, where required, override the system-calculated contribution with a custom flat amount.


This enhancement is useful for organisations that need to accommodate special contribution arrangements while ensuring payroll calculations reflect the configured values.


#### Quick Recap : What are Self-Help Groups (SHGs)?


In Singapore, employees may contribute to one or more Self-Help Groups (SHGs) based on their racial or religious background. The supported SHG types are:


- **CDAC** (Chinese Development Assistance Council)
- **MBMF** (Mosque Building and Mendaki Fund)
- **SINDA** (Singapore Indian Development Association)
- **ECF** (Eurasian Community Fund)


With this enhancement, each SHG can now be configured independently for every employee.





#### What's New?


The **Statutory Contributions** section within the Employee Profile now allows HR users to:


- Configure each SHG type **individually** for each employee.
- Enable **multiple SHG** types for a single employee where applicable.
- Choose whether to use the **system-calculated contribution** or a **custom flat contribution amount** for each enabled SHG.





#### How to Configure SHG Contributions for Individual Employees


1. Navigate to **Employee Profile**
2. Scroll down to the **Payroll** tab, then click into the **Statutory Contributions** section
3. Click on the **Edit** button

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-17-2026-12-10-10-4309-AM.png?width=670&height=224&name=image-png-Jul-17-2026-12-10-10-4309-AM.png)
4. Select the relevant SHG type then click on the dropdown for the following options:

  - **Not related** *(Default)* – No SHG contribution will be calculated.
  - **Enabled** – The employee is affiliated with the selected SHG.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-17-2026-12-13-15-3464-AM.png?width=670&height=368&name=image-png-Jul-17-2026-12-13-15-3464-AM.png)
5. If **Enabled** is selected, choose the contribution type:

  - **Default** *(Default)* – Uses the standard system-calculated contribution.
  - **Custom value** – Allows you to specify a flat contribution amount.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-17-2026-12-11-38-7785-AM.png?width=670&height=371&name=image-png-Jul-17-2026-12-11-38-7785-AM.png)
6. If **Custom value** is selected, enter the required contribution amount

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-17-2026-03-16-22-5311-AM.png?width=670&height=441&name=image-png-Jul-17-2026-03-16-22-5311-AM.png)
7. Select the payroll cycle to have this contribution captured in

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-17-2026-03-17-21-8512-AM.png?width=625&height=420&name=image-png-Jul-17-2026-03-17-21-8512-AM.png)
8. Click **Save** to apply the changes

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-17-2026-03-18-12-1050-AM.png?width=670&height=446&name=image-png-Jul-17-2026-03-18-12-1050-AM.png)





**TIP**:


The Payroll Cycle is automatically captured as the Default assigned to the employee however, if you wish to change the payroll cycle that this contribution should be captured in, you will **first need to untick the current cycle**, then choose the relevant payroll cycle.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-17-2026-03-23-06-2547-AM.png?width=947&height=633&name=image-png-Jul-17-2026-03-23-06-2547-AM.png)


 **NOTE**:


When **Custom value** is selected:


- Enter a flat contribution amount for the selected SHG.
- The amount must:

  - Be **0.01 or greater**.
  - Support up to **2 decimal places**.
- The entered value will **completely replace** the system-calculated SHG contribution during payroll processing.


#### How This Affects Payroll


During payroll processing, the system will calculate SHG contributions based on each employee's configuration applied:


- **Default** uses the standard SHG calculation rules.
- **Custom value** overrides the calculated amount and deducts the specified flat contribution instead.
- **Example**:

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-17-2026-12-32-51-4347-AM.png?width=670&height=207&name=image-png-Jul-17-2026-12-32-51-4347-AM.png)


This gives HR administrators greater control when managing exceptional contribution scenarios while maintaining accurate payroll calculations.
