# How to Bulk Register Multiple New Employees in brioHR

*This article explains how to do bulk creation or bulk registration for multiple new employees through Excel upload.*

Registering new employees in brioHR can be done using two methods:


- Register Individually: Add new employees one by one by clicking on "**Add New Employee**." For more details, refer to [[this article](https://support.briohr.com/knowledge/how-to-register-or-add-a-new-employee-in-briohr?hsLang=en)].
- Register in Bulk: Register multiple new employees at once via **Bulk Download/Upload**.


Using **Method 2** can save time and streamline the registration process by allowing you to enter all relevant details in an Excel spreadsheet.


**NOTE:**


**After bulk registration, the system will not automatically send login activation emails to new employees. You must manually click "Send Activation Email" from Settings > Users.**


**If you wish to send login activation emails to newly uploaded employees, please refer to [this [guide 1](https://support.briohr.com/knowledge/how-to-send-or-re-send-activation-email-to-employees-a-guide-for-hr/admin?hsLang=en)] and [[guide 2](https://support.briohr.com/knowledge/first-time-login-via-activation-email-and-downloading-the-briohr-app?hsLang=en)].**


---


### Step 1: Download the Employee Details Template (Excel Format)


Log in to your brioHR account.


1.   Go to **HR Lounge **on the Navigation Bar and choose **Employee Management.**


2.   Click on the **Bulk Download/Upload** button.
![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-24-2025-06-44-19-3458-AM.png?width=670&height=335&name=image-png-May-24-2025-06-44-19-3458-AM.png)


3.   Choose "**Employee Details**" as the import category.
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-11-2026-07-33-43-0804-AM.png?width=670&height=323&name=image-png-Aug-11-2026-07-33-43-0804-AM.png)





4.   You will be directed to the Import Employee page. Please read the notes before proceeding with uploading the template:


**NOTE:**


- **The template you download will also contain data of all existing employees; you can either remove them or just add a new line.**
- **Deleting the existing employees from the template won't delete their profiles in the system.**


**WARNING:**


- **Please don't update/edit the employee's email address in this bulk template. **

  - **`Email address is the system's unique identifier`. **
  - **Updating the email address in the template will result in a duplicate profile being created as the system detects the "edited email address" as a new email address.**
- **To update the email address of an employee, you need to do it from Settings. For more details, please refer to this [[guide](https://support.briohr.com/knowledge/how-to-edit-an-employees-email-address-in-briohr-a-guide-for-hr-and-admin?hsLang=en)].**





5. Click on the bold "**Employee Details**" to download the Excel template. Fill in the template with the necessary details.
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-11-2026-07-36-32-0853-AM.png?width=670&height=334&name=image-png-Aug-11-2026-07-36-32-0853-AM.png)





**IMPORTANT:**


- **Do not change or add any column in the template.**
- **If you have new value for Job Title, Office Name, Department Name, Job Grade, and User Group, please add first in the Admin Setting. You can refer to this [[guide 1](https://support.briohr.com/knowledge/add-edit-delete-departments-briohr?hsLang=en)], [[guide 2](https://support.briohr.com/knowledge/add-edit-delete-offices-briohr?hsLang=en)], and [[guide 3](https://support.briohr.com/knowledge/how-to-add-edit-or-delete-job-titles?hsLang=en)]**

### Step 2: Upload the Employee Details Template


1.   Once you have completed the Excel template, click on the "**+ Browse File**s" button to upload the template.
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-11-2026-07-37-25-9216-AM.png?width=2281&height=1138&name=image-png-Aug-11-2026-07-37-25-9216-AM.png)





After uploading the template, you will see a review of the data you're about to import. The system shows the validation page as per the image below.


**a. If there are any errors in the file, they will be listed in the warning section with a remark on which line and which column is missing/wrong.****
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-11-2026-07-45-55-8257-AM.png?width=2254&height=670&name=image-png-Aug-11-2026-07-45-55-8257-AM.png)
**


**b. If there are new employees added in the file, the system will show 'New'.****
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-11-2026-07-46-27-9735-AM.png?width=2254&height=670&name=image-png-Aug-11-2026-07-46-27-9735-AM.png)
**


You can modify your template and reupload back by click on **Reupload** button.
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-11-2026-07-46-52-6443-AM.png?width=2254&height=670&name=image-png-Aug-11-2026-07-46-52-6443-AM.png)


- If no warning message appears, it means the file is good to go.


2. To continue saving and importing the data, click on the "**Save Import Data**" button.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-11-2026-07-48-08-6907-AM.png?width=2218&height=601&name=image-png-Aug-11-2026-07-48-08-6907-AM.png)

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-11-2026-07-48-44-9123-AM.png?width=433&height=353&name=image-png-Aug-11-2026-07-48-44-9123-AM.png)





**NOTE:**
**You can repeat the same steps to do a bulk import or update for other categories.**
