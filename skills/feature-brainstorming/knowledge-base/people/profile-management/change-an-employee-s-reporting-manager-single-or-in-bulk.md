# Change an Employee's Reporting Manager (Single or in Bulk)

*Update a reporting manager from the employee profile, use Bulk Import/Export for many employees, and check the user-group permission required — this changes the reporting line, not the performance appraiser.*

** Audience & Scope**

- Audience: HR Admin
- Module: Employee Profile, Employment Management
- When to use this article: You want to move an employee under a different manager; you need to change managers for many employees at once; you're unsure whether you have access to do it. (Changing the performance appraiser is a different action — see Related Articles.)


[](#change-one-or-a-few-reporting-managers)**Change one (or a few) reporting managers**

1. Use the top search bar to find the employee, open View profile.
2. Click Edit > Job details, click the Manager dropdown, choose the new manager, Save.


[](#change-managers-in-bulk)**Change managers in bulk**

1. Go to HR Lounge > Employment Management > Bulk Import / Export > Manager > download the Manager template in green.
2. The template identifies managers by email address — change the manager email on an employee's row to reassign them.
3. Upload the modified file.


[](#required-permission)**Required permission**

If you can't edit the field: Admin Settings (gear icon) > User Groups > modify your user group (pencil icon) > Profile Non-Sensitive Data > Employee general information > Change > tick "Modify every one's" > Save.


[](#record-a-promotion-new-job-title)**Record a promotion (new job title)**

1. First create the title: Settings > Job Titles > +Add Job Title, enter the title, save.
2. Then assign it: employee Profile > Job tab > + New Job Record under Job History, select the title, choose the correct effective date (after the join date, before any current/future job entries), save — the promotion appears in Job History.
