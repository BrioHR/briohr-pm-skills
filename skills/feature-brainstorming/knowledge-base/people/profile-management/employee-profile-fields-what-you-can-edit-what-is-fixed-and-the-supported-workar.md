# Employee Profile Fields: What You Can Edit, What Is Fixed, and the Supported Workarounds

*Which family-detail fields are editable, how to record information the profile has no field for (spouse gender, confirmation date) with custom fields, and how to export family details.*

**Family Details — what's editable**


For an employee's spouse and children, the editable fields are: Name, Mobile Phone, Email, Date of Birth, Nationality, and Documentation Information. A spouse's I/C number, for example, goes under Family Details > edit (pencil) icon > Documentation Information.


Gender for a spouse or child is NOT an available field. Workaround — create a custom field:


1. Go to **Settings > Personal Data > Personal Details**.
2. Click **+ Add**, enter the field name (e.g. "Spouse Gender").
3. Select Field Type: **Select**, and add the options.
4. Choose the applicable office(s) and **Save**.


**Confirmation date**


There is no default Confirmation Date field. Two supported ways to record it:


- **Custom field (recommended):** Settings > Personal Data > Personal Details > + Add — create "Confirmation Date" with the Date type (see [How to Add Custom Fields to Personal Details in BrioHR for Employee Profiles](https://support.briohr.com/knowledge/how-to-add-custom-fields-to-personal-details-in-briohr-for-employee-profiles?hsLang=en)).
- Alternatively, add it in the Notes/Description of the relevant Job History record — without editing the existing job details.


**Exporting family details**


The Report Builder has no fields or filters for spouse/dependent information. To export it: **HR Lounge > Employee Management > Bulk Import/Export >** select **Family Details** > download the Excel file — it contains the recorded family information for employees.
