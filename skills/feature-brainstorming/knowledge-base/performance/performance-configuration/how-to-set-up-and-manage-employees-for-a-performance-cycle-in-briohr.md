# How to Set Up and Manage Employees for a Performance Cycle in BrioHR

*Learn how to set up and manage employees in a performance cycle using BrioHR. Discover how to assign competency levels, appraisers, and include or exclude employees efficiently.*

### Introduction


Setting up and managing employees for a performance cycle is an essential step to ensure that all relevant employees are properly included in the evaluation process.


This setup allows HR administrators to assign **competency levels**, designate **appraisers**, and manage employee participation in each performance period.


In BrioHR, this can be done easily from the **Employees** page within the **Performance Management** module, where HR admins can include or exclude employees from the performance cycle as needed.


---


### Step-by-Step Guide: Setting Up and Managing Employees for a Performance Cycle


#### Step 1 - Log In to BrioHR Account


Log in to your BrioHR account using your registered credentials.


#### Step 2 - Access the Employees Page in the Performance Management Module.


1. On the main navigation bar, go to **HR Lounge** > **Performance Management**.


2. From the Performance Dashboard, click **Employees.**


3. On this page, you can perform multiple actions to manage employees effectively.


#### Step 2 - Manage Employee Settings in the Performance Cycle


- **Search for Employees:**
Use the search bar to find specific employees. You can also filter by **department**, **competency level,** appraiser, cycle, or **status **(Active/Inactive)
- **[Assign the Competency Level](/knowledge/assigning-competency-level-to-employees?hsLang=en): **
Assign the appropriate **competency level **that the employee will be appraised against during the performance review.
- **[Assign or Change Performance Appraiser](/knowledge/how-to-change-employees-performance-appraiser?hsLang=en):**
Set the appraiser for each employee. The appraiser can be a manager or another authorized person. Employees can also have **multiple appraisers** if needed.
- **[Include/Exclude From Cycle](/knowledge/how-to-remove-employees-from-an-ongoing-performance-cycle-in-briohr?hsLang=en): **
HR Admins can include or exclude employees from the **current** or **upcoming** performance cycle, depending on the organization's review requirements.

  - **Current Cycle: **Refers to the **active performance cycle** currently in progress.
  - **Next Cycle: **Refers to the **upcoming performance cycle** that has been set for the future.

### Best Practices for Managing Employees in a Performance Cycle


- Ensure that every employee is assigned an appropriate appraiser before the review period begins.
- Regularly update the competency levels to match evolving job expectations.
- Review inclusion lists for each cycle to avoid missing employees.

### Frequently Asked Questions (FAQs)


**1. Can an employee have more than one appraiser?**
Yes, BrioHR allows multiple appraisers to be assigned to a single employee for comprehensive feedback.


**2. What is the difference between the current and next cycle?**
The **current cycle** refers to the ongoing performance review period, while the **next cycle** refers to an upcoming, future appraisal period.


**3. Will my changes be saved automatically?**
Yes. All modifications on the **Employees** page—such as appraiser assignments or employee inclusion—are saved automatically.


**4. Can I exclude employees after the cycle has started?**
Yes, HR Admins can remove employees from an active performance cycle if necessary. If an employee is excluded, he won't be able to access his personal performance page anymore.
