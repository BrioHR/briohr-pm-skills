# Latest 360 Feedback Feature

*This article explains the updated 360 Feedback feature, including using participants' average rating as the competencies rating.*

We’ve updated the 360 Feedback feature in our Performance module with an exciting new capability!


With this update, the average rating provided by 360 feedback participants can now be used as the competencies rating in appraisals.


### A. Two Ways to Use 360 Feedback:


#### 1.  360 Feedback Enabled:


A set of general questions will be presented to feedback givers, who will provide their responses accordingly.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48273618601/original/ewed0T9UdDkoWKjGlbhr1jLjJH-3IsqREA.png?1672997878)


#### 2.  360 Feedback and Rate Competencies Enabled:


Feedback givers will be asked to both comment on and rate the employee’s competencies.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48273618879/original/wOcWTYcpZGv6Kt6WHVC1DLJ0cCODrRL-Fw.png?1672997941)


**NOTE:**


**This new feature applies only to the second method above, where both 360 Feedback and Rate Competencies are enabled.**


**Reminder: If Rate Competencies are not selected, you won’t be able to check the box that allows the average rating from 360 feedback givers to be used as the competencies rating in the appraisal.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48273619313/original/PR1oU92bbF87_6DgFGLSc0bUNnL69iSooQ.png?1672998052)


**NOTE:**


**Enabling this feature means that the 360 feedback will influence the overall rating in the appraisal.**


### B. Conditions for Using This Function:


- In **Step 4 – Determine the appraisal’s key milestones** and **Step 5 – Select your add-ons: 1-on-1 and 360 Feedback**, both must have the same **number of ratings** (e.g., 4 and 4). While the titles of each rating can differ, the number of ratings must match.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48274213511/original/MLh5fkQ2E8o7S--jwleFm_c-PcQGDsJqeQ.png?1673310518)

If the number of ratings differs (e.g., Appraisal Ratings have 4 ratings while Feedback Ratings have 5), the system will display an error when you click "Start Cycle" to launch the new cycle.

#### FAQ:


**1.   If Rate Competencies were not chosen for any 360 Feedback during an active cycle, can this option be added later?**


This function can be enabled during an active cycle, provided that at least one of the selected 360 feedbacks includes the Rate Competencies option. If none of the 360 feedbacks include Rate Competencies, this function cannot be edited or changed during an active cycle.


**2.   What happens if this function is applied after the Appraiser has submitted their appraisal?**


Once this function is applied, it will overwrite the Appraiser's ratings. The Appraiser will only be able to edit the comment section, not the ratings.


**3.   Where can I check which ratings were used in the appraisal?**


You can check this under HR Lounge > Reports > Performance 360 Feedback > Column (Ratings included in the Competency's Appraisal).


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48274214097/original/tofmndJchRkvzetH_aA6nOYKZvnld45x7Q.png?1673311124)


**4.   Situation: One of the feedback givers did not submit their ratings and comments, but the Manager/Appraiser has already submitted the appraisal. If the feedback giver attempts to submit their ratings and comments afterward, they will receive a warning that their input might not be included in the overall average rating.**


**Solution: **Reopen the appraisal; the system will automatically refresh the average calculations.


**5.   Situation: This feature was enabled at the start of the cycle but was disabled during the active cycle. How will this impact performance?**


**Solution:** For 360 feedbacks that have not yet been completed, the process will revert to the standard method of the Manager’s comment and rating. For employees whose average 360 ratings were initially used, those ratings will remain unless the appraisal is reopened, in which case it will also revert to the standard method of the Manager’s comment and rating.
