# How to Edit and Manage Competencies During an Ongoing Performance Cycle

*This article explains how to edit and manage competencies during an ongoing performance cycle, for current or future cycles.*

**When a performance cycle is active, you can still modify competencies. HR Admins can choose to apply these changes either to future and current cycles or only to the current cycle.**


To learn how to make these adjustments, follow the steps below:


### Managing Competencies


- Log in to **HR Lounge** and click on **Performance**.


![gSIAtgfm6sjshP5hOPWHcAyoWVOcTYRPAQ.png?1658740999](https://support.briohr.com/hs-fs/hubfs/Imported%20images/gSIAtgfm6sjshP5hOPWHcAyoWVOcTYRPAQ.png%3F1658740999.png?width=265&height=531&name=gSIAtgfm6sjshP5hOPWHcAyoWVOcTYRPAQ.png%3F1658740999.png)


- Select the **Competency **tab.


#### A.  How To Edit Existing Competencies Or Add New Competencies


The following steps illustrate how to edit a Core Competency. You can use the same procedure for:


- **Editing Department Competencies**
- **Editing Job Title Competencies**
- **Adding new Core Competencies**
- **Adding new Department Competencies**
- **Adding new Job Title Competencies**


1.   Hover over the competency you want to edit.


2.   Click on the **Edit **icon.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240737145/original/epakjIXXE3kBZYCE0BeidJKy4UK2AK9knA.png?1658742137)


3.   Update the competency by entering new information in the relevant fields (e.g., changing weightage or category).


4.   In the **Save Options** field, choose one of the following:


- **"DO NOT APPLY TO CURRENT CYCLE":** To apply changes **only to future cycles**. **(Not the current cycle)**
- **"APPLY TO CURRENT CYCLE":** To apply changes to** both current and future cycles.**


**NOTE:**


**Changes applied to the current cycle will affect ongoing appraisals.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240738130/original/nteSLKhcrn2Q3sgVFwC-hrL_Y1Th9HM76Q.png?1658742313)


5.   Click **Save **to finalize the modifications.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48240739187/original/qNoUv3LgWgfb1Z9hAP9zfJeVaJtykLVHQA.png?1658742501)


Once saved, you can hover over the updated competency to view the **updated date and time information.**

#### B.  How To Enable/Disable Department Or Job Title Competencies


The following steps demonstrate how to enable a Department Competency. You can use the same process for:


**Enabling Job Title Competencies**


**Disabling Department Competencies**


**Disabling Job Title Competencies**


1.   Click the **toggle **to enable the competency.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48241839804/original/0AdcIIKyQaXTLEefdlrTDkjD_SwurbApaQ.png?1659087022)


2.   In the "**Enable Competencies by Department**?" pop-up window, choose:


- "**Enable (without applying)**": To apply changes only to **future cycles**. (Not the current cycle)
- "**Enable (with applying)**": To apply changes to **both current and future cycles**.


**NOTE:**


**Changes applied to the current cycle will affect ongoing appraisals.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48241842095/original/ZEFkmt_j7Hal6MsooS-hXXivBRptqak8XA.png?1659087590)


**Successful Application Notification:**

If you change your mind and wish to disable the competency, click the **toggle**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48241843959/original/Fm-d-D8oHkbk5xXv23yNaVs7nMz2zrqfFA.png?1659087989)


In the "**Disable Competencies by Department?**" pop-up window, choose:


- **"Disable (without removing)"**: To apply changes **only to future cycles. (Not the current cycle)**
- **"Disable (with removing)"**: To apply changes to **both current and future cycles.**


**NOTE:**


**Changes applied to the current cycle will affect ongoing appraisals.**
