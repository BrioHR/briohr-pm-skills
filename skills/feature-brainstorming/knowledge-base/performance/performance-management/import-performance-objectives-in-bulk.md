# Import Performance Objectives in Bulk

*This article explains how to import performance objectives for many employees at once using the bulk import Excel template.*

** Audience & Scope**

- **Audience:** HR Admin
- **Module:** Performance Appraisal
- **Country:** Global
- **Prerequisites:** Access to HR Lounge > Employee Management; an open performance cycle
- **Feature available on:** Web
- **When to use this article:** HR Admin wants to import or upload performance objectives for many employees at once instead of keying them into every profile.


**Step-by-Step Instructions**

1. Navigate to **HR Lounge** > **Employee Management** > **Bulk import/export**.
2. Select **Performance objectives**.
3. Click **Download the template**.
4. Fill in the objectives in the Excel file. Use the date format **yyyy-mm-dd** (e.g. 2021-03-28).
5. **Upload** the file back — the system updates every employee from the file.


**Common Issues / FAQ**

- **Q:** Can I update or edit existing objectives with the import?
**A:** No — the import can only create new objectives.
- **Q:** Who will the imported objectives apply to?
**A:** You choose the scope in the template: **All** (all departments), **Department** (a specific department), or **Employee** (a specific employee).
- **Q:** Why can't I import objectives right now?
**A:** Objectives can only be imported while the current cycle is open. Imported objectives are applied to the current cycle with the status **PENDING**.
