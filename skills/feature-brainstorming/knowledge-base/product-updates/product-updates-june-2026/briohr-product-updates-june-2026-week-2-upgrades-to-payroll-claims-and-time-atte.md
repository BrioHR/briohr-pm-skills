# brioHR Product Updates - June 2026, Week 2 | Upgrades to Payroll, Claims, & Time Attendance + Indonesia PH Update!

*Discover brioHR’s June 2026 product updates, designed to improve your HR experience. Stay informed on the latest innovations from brioHR.*

### Payroll Module


### Global


**New Feature: Delete Latest Payroll Cycle **


You no longer need to contact support to delete payroll cycles! Clients now have the independence to delete the latest payroll cycle directly within the system. This update offers greater flexibility, minimizes turnaround times, and streamlines your payroll management.


💡 **Note:** By default, this permission is disabled. Please update your user group settings to grant access to authorized users.


Want to know more about how to delete a payroll cycle?


👉 [Follow this step-by-step guide](https://support.briohr.com/knowledge/delete-latest-payroll-cycle-in-current-payroll-month?utm_source=hs_email&utm_medium=email&_hsenc=p2ANqtz-8Oz66BDos2ZxO230ief1fqynOqQ4pN39CH17k0qB8UGEWkpszRvuIwYRD-nw3l-FIHrCLC&hsLang=en)


**Enhancement: Reopen Payroll Month **


We have enhanced the payroll module to allow reopening payroll month. Previously, only specific cycles could be reopened after a payroll month had been completed. This enhancement allows admins and payroll managers to reopen payroll for the latest month and add a new cycle more easily.


Want to know more about how to reopen a payroll month or a payroll cycle?

### Payroll Malaysia Update


**PERKESO SKBBK Update **


We have updated the SOCSO category options to include Category 1 & Category 2 with and without SKBBK. This update caters to special scenarios where employers want to choose to include or exclude SKBBK deductions for employees.


⚠️ Note: Please verify with PERKESO for confirmation on special scenarios to maintain compliance.

### Time Attendance Module


**API Integration: Export Timelog Report Data **


This integration allows users to export timelog report data directly from the Time Attendance module, enabling easier access to clock information for reporting, analysis, or integration with external systems.


What this means for you:


• Seamless export of time log data via API
• Easier integration with external reporting systems
• Improved flexibility in accessing time attendance information


This enhancement supports more efficient data workflows and better connectivity across your HR processes.

### Public Holiday Update


### Indonesia


**Islamic New Year (1 Muharram) now set to 16th June 2026**


Since the Islamic New Year public holiday now falls on the 16th of June instead of the 17th of June 2026, brioHR has automatically updated the public holiday list for offices located in Indonesia. The Islamic New Year (1 Muharram) is now set to be on:


📌 **16 June 2026**


⚠️ **Please Note:**


This public holiday is automatically updated for offices with the country selected as **Indonesia**.


Want to remove this public holiday from your calendar?


👉[Follow this step-by-step guide to disable the public holiday in your settings.](https://support.briohr.com/knowledge/public-holiday-update-for-islamic-new-year-1-muharram-2026-in-indonesia?utm_source=hs_email&utm_medium=email&_hsenc=p2ANqtz-8Oz66BDos2ZxO230ief1fqynOqQ4pN39CH17k0qB8UGEWkpszRvuIwYRD-nw3l-FIHrCLC&hsLang=en)
