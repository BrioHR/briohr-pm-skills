# brioHR Product Updates - June 2026, Week 4 | New Thai Language & Day Off option in schedules, + Enhancements to Payroll and Time Attendance modules.

*Discover brioHR’s June 2026 product updates, designed to improve your HR experience. Stay informed on the latest innovations from brioHR.*

### Global HR Update


**New Thai Language Now Available**


brioHR now supports **Thai** as a system language! Account admins can request to enable this feature for their account by contacting brioHR Support team.


Once enabled, each user can choose to switch their preferred language to Thai from their own **User Settings**. The language selection is applied individually and will not automatically update all user profiles.


👉 [Refer to this step-by-step guide to enable the Thai language](https://support.briohr.com/knowledge/thai-language-available-in-briohr?hsLang=en)





**New Schedule Enhancement: Day Off **


You can now include **Day Off ** when creating employee schedules in brioHR.


This enhancement supports more flexible roster planning, ensures employees are not able to apply for leave on their designated Day Off, and enables **Day Off overtime** to be processed seamlessly from Time Attendance Timesheets to Payroll when applicable.


👉 [Follow this step-by-step guide to include Day Off into your schedules](https://support.briohr.com/knowledge/create-schedules-with-day-off?hsLang=en)





### Payroll Singapore


**New Overtime (Day Off) Payroll Configuration **


We’ve enhanced Payroll with a new **Overtime (Day Off)** default payroll item, giving you greater flexibility in configuring overtime calculations.


Singapore payroll centers can now define and manage custom overtime multipliers across four OT categories:


- Normal workdays
- Rest days
- **Days off (newly added)**
- Public holidays


This allows you to easily apply different OT rates based on your company’s policy, ensuring more accurate and compliant payroll processing.


👉 [Follow this step-by-step guide to configure this setting](https://support.briohr.com/knowledge/payroll-singapore-add-overtime-for-day-off-with-customizable-multiplier?hsLang=en)





### Time Attendance


 Employee Overtime Approval (Post OT Request)


Employees can now conveniently **request overtime approval directly via the Time Attendance module** using the new Post OT submission feature.


To ensure this feature works as intended, please note the following:


- First enable **Post OT submission** for your attendance policy.
- It is available for employees using **Daily Overtime Calculation** only.
- Requests can only be submitted for **actual overtime worked on past dates**, up to the number of hours recorded, and while the timesheet is still **Open**.


👉 [Read more about the steps to enable this feature within the policy here](https://support.briohr.com/knowledge/enable-employee-to-submit-overtime-for-approval-as-hr-admin?hsLang=en)
👉 [Follow this step by step guide to request overtime as an employee here](https://support.briohr.com/knowledge/requesting-overtime-approval-post-ot-as-an-employee?hsLang=en)
