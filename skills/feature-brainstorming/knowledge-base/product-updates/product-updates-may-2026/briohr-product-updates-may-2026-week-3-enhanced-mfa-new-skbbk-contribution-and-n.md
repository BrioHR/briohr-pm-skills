# BrioHR Product Updates - May 2026, Week 3 | Enhanced MFA, New SKBBK Contribution & New Company Payroll Report API!

*Discover BrioHR’s May 2026 product updates, designed to improve your HR experience. Stay informed on the latest innovations from BrioHR.*

### Introduction


At BrioHR, we are committed to continuously enhancing the user experience. We listen to valuable feedback from our clients to deliver new features, improvements, and system enhancements.


This article provides a summary of all BrioHR product updates released on Week 3 of May 2026.


---


**Global HR Update**


Enhanced MFA: Remember Trusted Devices for 30 Days


We’re introducing an enhancement to Multi-Factor Authentication (MFA) that improves both security and user convenience with a new **“Remember this device for 30 days”** option.


With this update, users can choose to trust a verified browser or mobile device after completing OTP authentication. Once enabled, future logins from the same device will skip OTP verification for up to 30 days, streamlining the login experience while maintaining strong security controls.


👉 [Read more about the Enhanced Multi Factor Authentication here](https://support.briohr.com/knowledge/enhanced-mfa-remember-trusted-devices-for-30-days?hsLang=en)





Payroll Module


Global


New API Available: Company Payroll Report


A new API is now available in BrioHR — the **Company Payroll Report API**.


This new integration allows users to export company payroll data directly from the Payroll module, enabling easier access to payroll information for reporting, analysis, or integration with external systems.


👉 [Read more about the new Company Payroll API here](https://support.briohr.com/knowledge/export-company-payroll-report-data-via-api-integration?hsLang=en)





Payroll Malaysia


**PERKESO SKBBK Contribution Requirement Effective 1 June 2026**


PERKESO’s new SKBBK (Skim Kemalangan Bukan Bencana Kerja) scheme will take effect starting 1st June 2026, requiring employers to include additional SOCSO contributions for non-work-related accident coverage. To support this update, the payroll system will automatically calculate and include SKBBK contributions within existing SOCSO deductions, payroll reports, statutory files, and payslip calculations.


👉 [Read more about the new SKBBK Contribution here](https://support.briohr.com/knowledge/new-perkeso-skbbk-contribution-requirement-effective-1-june-2026?hsLang=en)





United Overseas Bank (Malaysia) Berhad - New Statutory Payment Files


We’re excited to introduce a new enhancement in BrioHR — you can now generate statutory payment files for **United Overseas Bank (Malaysia) Berhad (UOB)** directly from the Payroll module.


This enhancement now supports:


- EPF Payment Files
- Socso Payment Files
- EIS Payment Files


👉 [Read more on the guide to download Statutory Payment files here](https://support.briohr.com/knowledge/generating-payroll-statutory-payment-files-for-united-overseas-bank-malaysia-berhad?hsLang=en)





Time Attendance Module


Approval Date Added to Time Attendance Timesheet Report


Our enhanced Time Attendance Timesheet Report now includes a new field: **Approval Date**.


This field displays the latest timestamp when an Overtime entry was approved, providing clearer tracking of approval activity. In cases where a timesheet entry is updated (for example, from approved to rejected or vice versa), the system will always reflect the most recent status and its corresponding approval timestamp.


👉 [Read more about our Time Attendance reports here](https://support.briohr.com/knowledge/time-attendance-reports?hsLang=en)





**Employee Overtime Pre-Approval is Now Available on Mobile App!**


This new feature allows employees under eligible overtime policies to conveniently submit overtime requests directly from the mobile app using the new **“Request OT”** function available within their schedule.
