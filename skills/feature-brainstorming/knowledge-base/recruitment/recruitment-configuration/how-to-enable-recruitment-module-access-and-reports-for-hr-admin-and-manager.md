# How to Enable Recruitment Module Access & Reports for HR Admin & Manager

*Enabling access to the recruitment module and reports for HR Admin and Managers in BrioHR is a straightforward process. Follow the steps below to ensure the correct permissions are granted.*

### Enabling access for HR Admin:


1. Login to** BrioHR**
2. Go to** Settings**
3. Select the Relevant **User Group**
4. Enable **Recruitment Module**


  1. Assign necessary access
5. Enable **Recruitment Reports**

3. Select the Relevant **User Group**
4. Enable **Recruitment Module**
