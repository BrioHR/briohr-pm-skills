# Orion AI Job Description Setup: How to Enable, Configure, and Utilize AI

*This article explains how to enable and configure Orion AI to generate job descriptions in the Recruitment module.*

Orion AI, available within BrioHR, is a powerful AI tool that simplifies the process of creating job descriptions. It saves HR professionals time and ensures consistency across job postings.


---


### How to Enable Orion AI


To start using Orion, you must first enable the feature. For assistance, please contact our support team.


#### Setting Up and Using Orion AI


Once Orion is enabled, follow these steps to set it up and create job descriptions:


1. Log in to **BrioHR**:
2. Navigate to the **Recruitment **section.
3. Access the Recruitment **Dashboard**:

  1. Click "**+Add New Job**" to create a new job posting, or select an existing job to edit.


![image](https://support.briohr.com/hs-fs/hubfs/undefined-Apr-20-2026-04-58-16-1403-AM.png?width=670&height=324&name=undefined-Apr-20-2026-04-58-16-1403-AM.png)
4. Fill in the Job Title:

  1. Enter the job title in the designated field. Orion will automatically generate a job description prompt based on the title you provide.
5. **Click 'Write with AI' **to start chatting with Orion

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-20-2026-04-59-23-3871-AM.png?width=670&height=349&name=image-png-Apr-20-2026-04-59-23-3871-AM.png)
6. Use the Orion interface to prompt, review, and edit the AI-generated job description as needed. Once you're happy with the description, click '**Use this**' to add the description to the form.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-20-2026-05-04-29-0545-AM.png?width=670&height=437&name=image-png-Apr-20-2026-05-04-29-0545-AM.png)
7. Then, click '**Apply**' to confirm.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-20-2026-05-06-29-8166-AM.png?width=670&height=582&name=image-png-Apr-20-2026-05-06-29-8166-AM.png)
8. Fill in the rest of the new job form the job description should reflect accordingly.
