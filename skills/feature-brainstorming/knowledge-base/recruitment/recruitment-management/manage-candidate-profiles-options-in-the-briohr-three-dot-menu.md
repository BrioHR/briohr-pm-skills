# Manage Candidate Profiles: Options in the BrioHR Three-Dot Menu

*This guide explains the available options in the three-dot menu next to a candidate's name in BrioHR's Recruitment module. Learn how to access and utilize these options for effective candidate management.*

### Options in the Three-Dot Menu


The **three-dot menu** at the end of a candidate's name offers several actions that help manage candidate profiles seamlessly. Below are the options and their functionality:


1. **See Candidate Profile**


  - View the candidate's **details, job application history, hiring status, screening information, interview feedback, and current hiring stage.**
2. **Copy Profile URL**


  - Copy the candidate profile's **URL** to share it with other users.
  - Users can paste the URL into their browser to access the candidate's profile directly.
3. **Send Profile**


  - Select a user from the dropdown list to **send an email invitation** to view the candidate's profile.
  - Clicking the link in the email redirects the user to the candidate profile.
4. **Download Profile**


  - Click the **Download Profile** option to save the candidate's profile in **PDF format** for offline review or sharing.
5. **Reject Candidate**


  - End the hiring process for a candidate by clicking **Reject Candidate**.
  - This triggers a **rejection email** to the candidate if the email function is enabled in your system settings.
