# How to Download an Expense Claims Report

*This article explains how to download an Expense Claims Report, including the Per Day Allowance date fields and Claim Type filter.*

#### Latest Update:


1.   **Start Date, Start Time, End Date**, and **End Time** Added to **Fields & Filters**


- These fields are exclusive to the **Per Day Allowance **claim type, requiring you to fill in this information.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48336164575/original/H4IbZ1HptVULieF0vJW42Zqtw_TvrF80OA.png?1715134860)


2.   **Category **Renamed to **Claim Type**


- This field identifies the claim type submitted by the employee. You can use this filter to display specific claim types in the report.


3.   **Expense Category** Added to **Fields & Filters**


- This field identifies whether the claim request is for **Generic Expense, Mileage, Per Day Allowance, Cash Advance Request**, or **Cash Advance Settlement**. You can use this filter to display specific expense categories in the report.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48330704332/original/NktnPHghWodfXSwcaoiNbrWtYef_DJwtFw.png?1710755029)


4.   **Cash Advance Request** **ID **Added to **Fields & Filters**


- This field is exclusively for **Cash Advance Settlement**. The **Cash Advance Request ID** is used to match the **Claim Report Transaction ID** with the **cash advance request**, ensuring the settlement report is correctly linked to the corresponding **cash advance request**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48331616456/original/Ihgtpc1do0vQjc9JponmYGu79wg4nHT4GQ.png?1711435189)

In this tutorial, we'll demonstrate how to generate an expense claim report from the Reports module.


1. Go to **HR Lounge.**
2. Click the **Reports **button at the top right corner of the 'Employee List' table.
3. Search for **Expense Claims** and click **Create**.


**NOTE:**


**If you are looking for information on how to download an approved expense claim report, please refer [here](https://support.briohr.com/knowledge/how-to-download-an-approved-expense-claim-report?hsLang=en).**
