# Create and Download Ad-Hoc Performance Cycle Reports for Better Performance Management

*This article explains how to easily generate, customize, and export employee ad-hoc performance cycle reports*

**Audience & Scope**


Audience: HR Admin


Module: Analytics > Report Builder


Country: Global


Pre-requisites: Permission to view performance management reports


**Introduction**


There are 5 different reports for the performance management module that can be found under the Analytics > Report Builder:


1. Performance Management
2. Performance Objective
3. Performance 1-on-1 feedback
4. Performance 360 feedback
5. Performance Appraisal


All these reports can be generated for ad-hoc performance cycles.


**Step-by-Step Instructions**


1. On the main navigation bar, go to **Analytics > Report Builder.**


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-01-34-38-6614-PM.png?width=532&height=359&name=image-png-Feb-12-2026-01-34-38-6614-PM.png)
2. Click **'Create'** for the performance report you wish to generate.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-12-06-32-7011-PM.png?width=670&height=304&name=image-png-Feb-12-2026-12-06-32-7011-PM.png)
3. Click on **'****Ad Hoc Cycle'**
**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-12-08-29-6339-PM.png?width=670&height=371&name=image-png-Feb-12-2026-12-08-29-6339-PM.png)
**
4. Choose the specific fields to customize your report:

  1. Cycle Tag (available for all performance reports)
  2. Cycle Status (available for all performance reports)
  3. Cycle (available for all performance reports)
  4. Report Granuality (only for Performance Objective Report)

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-12-09-33-3552-PM.png?width=670&height=371&name=image-png-Feb-12-2026-12-09-33-3552-PM.png)
5. If needed, you may refine the report using the Fields and Filter. Click the "**Fields & Filters**" button to customize the items included in the report.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-01-45-56-7040-PM.png?width=614&height=182&name=image-png-Feb-12-2026-01-45-56-7040-PM.png)
6. Select which items you want to include in the report by ticking or unticking the checkboxes. Use the "**+ Add Filter**" option if necessary.
7. Click "**Apply Changes**" to save your selections.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-01-47-47-1644-PM.png?width=670&height=309&name=image-png-Feb-12-2026-01-47-47-1644-PM.png)
8. An overview of how your report will look will be displayed. Click "**Expand**" to view it in **fullscreen** if needed.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-01-49-05-8900-PM.png?width=670&height=275&name=image-png-Feb-12-2026-01-49-05-8900-PM.png)
9. Once you have your desired data and format, you may save the template for future use using the 'Save as' function. Click "**Save As**" to save your customized report format.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-01-50-08-3046-PM.png?width=670&height=305&name=image-png-Feb-12-2026-01-50-08-3046-PM.png)
10. A "Save Report as Template" pop-up will appear. Enter a name for your report.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-01-50-59-5878-PM.png?width=412&height=243&name=image-png-Feb-12-2026-01-50-59-5878-PM.png)
11. Click "**Save**."
12. The saved report will appear under the **Generated Reports** section. If you have multiple reports, click on the one you wish to display.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-01-53-05-7542-PM.png?width=670&height=186&name=image-png-Feb-12-2026-01-53-05-7542-PM.png)
13. Click "**Export Report**" to download the selected report. You can choose to download it in CSV or Excel format.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Feb-12-2026-01-54-50-0258-PM.png?width=670&height=227&name=image-png-Feb-12-2026-01-54-50-0258-PM.png)
14. The same steps can be applied to create other ad hoc performance cycle reports.





**Common Questions**


Q: Why can't I see any data?


A: You may not have the necessary permission to view the report. Please check with your company admin on your user group permission settings including office manager settings if needed.
