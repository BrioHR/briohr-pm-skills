# BrioHR Time And Attendance Device Integration Guide (TC10 Model)

*Learn how to integrate your Timetec TC10 device with BrioHR’s Time and Attendance module. Follow this step-by-step guide for installation, setup, and user enrollment to enable smooth on-site clock-in and clock-out.*

### Introduction


The **BrioHR Time and Attendance** module supports seamless integration with third-party biometric devices, specifically the **Timetec TC10** model.


This integration allows employees to **clock in and out on-site** using **fingerprint or facial recognition**, ensuring accurate and secure attendance tracking.


This article provides a complete overview and a **downloadable step-by-step guide** for first-time users to set up and connect their TC10 device with BrioHR.

### Section 2: Register Device System Admin


Create a **System Admin** within the device. This ensures that only **authorized personnel** can control or modify device settings.

If no admin is registered, unauthorized users may be able to access or change system configurations.


**IMPORTANT:**


1) Create **ONLY the System Admin** within the device.


2) Please **DO NOT add employees directly on the device** (except the System Admin). Employee data will be sync automatically from BrioHR after integration is activated.

### Section 3: Contact Support BrioHR


Next, before completing the setup, you **must inform** **BrioHR Support** of your readiness for device integration.

You can contact us via:


- **Email: **support@briohr.com
- **Live Chat:** Available in your BrioHR account (a dialogue icon at the bottom right corner)


Our support team will enable backend integration for your company account for the** first time.**


**NOTE**:


For Device Integration using the TimeTec TC10 device, there are two available configuration options that organizations may choose from based on their operational preferences:


**Solution 1: Default Mode**
Employees are required to select an action type on the device before performing their attendance transaction.


**How it works:**
Employees must first select either **Clock In** or **Clock Out** on the device interface before verifying their attendance using fingerprint or facial recognition.


**Example:**
An employee selects **Clock In** then provides their fingerprint or facial recognition scan before starting work and selects **Clock Out** then provides the same verification at the end of the workday.





**Solution 2: First_Last Mode**
Employees can perform attendance verifications directly without selecting an action type on the device.


**How it works:**
Employees simply verify their attendance using fingerprint or facial recognition, and the system will automatically determine and record the first transaction as **Clock In** and the last transaction as **Clock Out**.


**Example:**
An employee taps the device upon arrival and again before leaving, while the system automatically captures the corresponding Clock In and Clock Out records.


**Note:** If you'd also like employee break time tracked automatically (in addition to first/last punch), let brioHR know when confirming Solution 2. This add-on requires employees to be on a **Shift schedule** with a **break start period set up** for their shifts, and requires **Hybrid Attendance to be off** for your company.


See: [How to Link Timetec Device in BrioHR Time and Attendance Module](https://support.briohr.com/knowledge/link-timetec-device-in-briohr-time-attendance?hsLang=en) for full details.


**Please ensure that the preferred solution is shared with our BrioHR team when the Integration is performed. **


**CAUTION:**

**Do not** proceed to the next step until you receive confirmation from BrioHR.

### Section 4: Link Device in BrioHR Time and Attendance Web Portal


**IMPORTANT:**

Proceed only after BrioHR confirms successful backend integration.


1. The HR Admin must first enable** Device Integration **in the **Time and Attendance policy** settings.
2. Then, register the **device serial number** inside the Device Integration Log in the Time and Attendance module to connect it with your BrioHR account.
3. Once successfully connected, employee details such as** Employee ID, First Name** and **Last Name** will automatically sync to the TC10 device.


**Learn More:** [How to Link Timetec Device in BrioHR Time and Attendance Module](https://support.briohr.com/knowledge/link-timetec-device-in-briohr-time-attendance?hsLang=en)


---


### Section 5: User Enrollment via Device


After employees' data have been synced to the TC10 device, the **HR Admin**, or **Device System Admin** must enroll users' biometric data.


Each employee must perform:


- **Fingerprint registration**
- **Facial scanning**


**NOTE:

**This is a** one-time setup** for first-time users.


Once biometric data is recorded, employees can start clocking in and out using their **fingerprint or facial recognition** through the TC10 device.
