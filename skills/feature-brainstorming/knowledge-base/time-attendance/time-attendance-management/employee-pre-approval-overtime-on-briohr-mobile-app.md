# Employee Pre-Approval Overtime on BrioHR Mobile App

*Discover the latest Mobile App Version 2.1.0 enhancement featuring Employee Overtime Pre-Approval, enabling employees and managers to submit, review, and manage OT requests directly from the mobile app.*

#### Audience & Scope


Audience: Employee & Manager


Module: Time Attendance


Country: Global


Pre-requisite: Permission for Employee Pre-approval OT has been enabled in TA Policy settings





Managing overtime just became more convenient and efficient with the latest enhancement to the mobile app — **Employee Overtime Pre-Approval**. This new functionality is designed to streamline the overtime request and approval process directly from mobile devices, giving employees and managers greater flexibility and control anytime, anywhere.


### What’s New in Mobile App Version 2.1.0


Employees can now submit overtime requests directly through the mobile app, while managers can review and take action on requests without needing desktop access.


For employees assigned under policies with **Employee** **pre-approved overtime enabled**, a new **“Request OT”** button will appear within their work schedule.


Using this feature, employees can:


- Submit overtime requests anytime via mobile
- Provide reasons for overtime submissions
- Upload supporting documents where required
- Track request statuses directly from the app


Managers can then conveniently review, approve, reject, or amend requests directly from their pending task list.





### Flexible Overtime Request Modes for


### Employees


To support different operational and scheduling requirements, employees on shift-based schedules can choose between two overtime request methods.


#### Duration Format


The **Duration Format** allows employees to add additional overtime hours to their existing scheduled shift.


This option is ideal when:


- Employees are extending their current working hours
- Overtime occurs immediately after a scheduled shift
- Additional working time is required without creating a separate shift





#### Time Slot Format


The **Time Slot Format** enables employees to specify a custom overtime start and end time.


Once approved, this request effectively creates an **ad-hoc shift** within the schedule.


This option is useful when:


- Overtime occurs outside the original shift timing
- Employees are called in for additional work periods
- Managers need clearer visibility of separate overtime sessions





### Streamlined Manager Approval Workflow


Managers will receive overtime requests as **Pending Tasks** within the mobile app.


From there, managers can:


- Review request details
- View supporting attachments
- Approve or reject submissions
- Amend the requested overtime duration before approval


This creates a faster and more flexible approval process while maintaining proper oversight and approval governance.





### Important Request Management Rules


To ensure accurate approval tracking:


- Overtime requests can only be deleted while they remain in **Pending** status
- Once approved or rejected, requests can no longer be removed


This helps maintain a complete and transparent overtime approval history.

### Frequently Asked Questions


**Q: Who can use the Employee Overtime Pre-Approval feature?**


A: Employees assigned under overtime policies with pre-approval enabled will be able to access the “Request OT” function within the mobile app.


**Q: Can managers modify overtime requests?**


A: Yes. Managers can amend the requested overtime duration during the approval process before approving the request.


**Q: Can employees delete submitted OT requests?**


A: Employees may only delete OT requests while the request status remains **Pending**.


**Q: Which mobile app version supports this feature?**


A: The Employee Overtime Pre-Approval functionality is available starting from **Mobile App Version 2.1.0**.
