# Streamline Claims with the New 'Claims on Behalf' Personal Assistant Feature

*This article explains how to designate an employee as a Personal Assistant who can view, create, and submit claims on behalf of a manager.*

Introducing our latest feature: the Claims Personal Assistant, designed to allow you to designate an employee as a "Personal Assistant" for a manager or CEO.


This feature empowers the assigned personal assistant to view, create, and submit claims on behalf of the manager or CEO directly from the personal assistant’s Home page.


#### Key Features:


"**Claims on Behalf**" Menu: A new menu item, "Claims on Behalf," will appear on the personal assistant's Home page.


Three Simple Steps: Follow three essential steps to enable an employee to create claims on behalf of a manager or CEO.

### Step 1: Assign a Personal Assistant


- Login to BrioHR and navigate to **Settings > Personal Assistant**.
- Search for the name of the manager/CEO or the person you wish to assign actions on behalf of.
- In the "**Personal Assistant**" field, search for the employee's name you want to assign as the personal assistant.
- Select the employee's name to finalize the assignment.


**Example: Nurul is now the personal assistant of Jack.**

### Step 2: Create a User Group & Enable Personal Assistant Permissions


#### Step 2.1: Create a User Group


- Remain in the Settings page and navigate to **User Groups.**
- To create a new group from scratch, click the **+Add Group** button. For detailed instructions, refer to [How to Create a User Group](https://support.briohr.com/knowledge/how-to-create-a-user-group?hsLang=en)
- Alternatively, duplicate an existing group:

  - Find the user group you want to duplicate.
  - Click the "Duplicate" icon.
  - Rename the duplicated group.
- Click the pencil icon to edit the group's settings.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48339630933/original/-7G0QMqCckpkM4Jpxg4TE59AR_z5ztixXw.png?1717983996)


####


#### Step 2.2: Enable Personal Assistant Permissions


- Go to the **permission category: Pages Access.**
- Search for "**Personal Assistants**" and select the checkbox.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48339630968/original/WUsbi_puzm64ce-2WjHqwXDX1RblQIoiMQ.png?1717984092)


- Navigate to the **permission category: PA Modules Permission.**
- Enable the Claims Module by selecting the checkbox for "Allow submit on behalf."


**NOTE:**


**Enabling "submit on behalf" allows personal assistants to create and submit claims on behalf of the assigned manager or CEO.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48339630985/original/CnBOQlEep_YjpLDveOATY0GqbAsHQ_fn0A.png?1717984129)


---


### Step 3: Reassign the Personal Assistant to the User Group


- To reassign an employee to a different user group, refer to How to Change Assigned User Group Roles in BrioHR


**NOTE:**


**You must reassign personal assistants to a User Group where you have enabled the "Personal Assistant Modules Permission" to ensure they can access the "Claims on Behalf" menu on their Home page.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48339631148/original/SQvG3ubwjd4FkDYeAJtBvfMczbs0jwFYew.png?1717984517)


- **Personal Assistant's Point of View:**


Once set up, the "**Claims on Behalf**" menu will appear on the personal assistant's **Home **page.


For detailed instructions on how a personal assistant can create and submit claims on behalf of a manager or CEO, please refer to [How to Submit Claims on Behalf (Personal Assistant)](https://support.briohr.com/knowledge/how-to-submit-claims-on-behalf-personal-assistant?hsLang=en).
