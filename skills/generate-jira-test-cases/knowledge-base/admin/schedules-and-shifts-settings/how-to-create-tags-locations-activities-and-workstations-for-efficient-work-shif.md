# How to Create Tags, Locations, Activities, and Workstations for Efficient Work Shift Management

*Learn how to create tags, locations, activities, and workstations for efficient work shift management. A step-by-step guide for smoother scheduling and reporting.*

Each time a new shift is created, you can assign it to a specific tag, location, activity, and workstation. Pre-defining these elements for each shift makes reporting easier later.
The tag, location, activity, and workstation are user-definable.


### Let's consider a use case of a cafe owner:


Cafe Delicious operates from 10:00 AM - 10:00 PM and has two (2) shifts:


- **Shift Team A:** 8:00 AM - 5:30 PM
- **Shift Team B:** 12:30PM - 10:00 PM


For each shift, the cafe owner wants to assign a tag, location, activity, and workstation. Here is how he plans to set it up:


#### For Shift Team A:


- **Assigned tag:** Has meal allowance
- **Assigned location:** KLCC
- **Assigned activity:** Business as usual
- **Assigned workstation: **Cafe
- **Entitled break:** 1 hour 30 minutes


#### For Shift Team B:


- **Assigned tag:** Has meal allowance
- **Assigned location:** KLCC
- **Assigned activity:** Business as usual
- **Assigned workstation:** Cafe
- **Entitled break:** 1 hour 30 minutes


From the above outline, the owner will need to create the following items before creating the shifts so that they can be assigned later :


- **Tag:** Has Meal allowance
- **Location:** KLCC
- **Activity: **Business as usual
- **Workstation: **Cafe


---


Steps to Set Up Tags, Locations, Activities, and Workstations


Login to your BrioHR account


1. Go to **Settings**
2. Navigate to **Schedules & Shifts**
3. Open **Work Shifts**
4. Here, you will see sections to create tag, location, activity and workstation.


**NOTE:**
**Tag, location, activity and workstation are user-definable. You can create your own and assign them to the work shifts you create.**

### How to Create Tags, Locations, Activities, and Workstations


#### To Create a Tag:


Specific list of tag, such as "Work on Weekend", or "Has Meal Allowance". Tags can be assigned to each shift and it can be linked to shift premiums/deductions.


1. Click the **Tag **tab.
2. Name the new tag.
3. Click **Save**


**NOTE:**


**- You will see a list of created tags.**
**- If any tag is assigned to shifts, it will appear here.**
**-To edit a tag, click the pencil icon and rename it.**

### To Create a Location (for Geolocation setup):


1. Click the Location tab.
2. Click the **+Create location** button
3. Enter a **name/title** for this location. It will be for your reference (eg, KLCC)
4. Toggle **On** the **Coordinates** button.
5. Enter the location name in the **search bar**.


  1. If the location exists on the map, select it from the results.
  2. If the location does not appear, manually search for it or select it on the map.
6. Adjust the **Radius** slider to increase or decrease the radius in meters. You can also manually enter the value in the number box.
7. Click **Save.**

### To Create an Activity:


Specify the main task or responsibility the employee is expected to carry out during the shift, such as "Customer Service", or "Inventory Check". Activities can be assigned individually for each shift.


1. Click the **Activity** tab.
2. Name the new activity
3. Click **Save**


![image](https://support.briohr.com/hs-fs/hubfs/activity%20new%20UI-gif.gif?width=1911&height=894&name=activity%20new%20UI-gif.gif)

### To Create a Workstation:


Specify the workstation or physical setup to be arranged for shift, such as a desk, counter, or terminal. Workstations can be assigned individually for each shift.


1. Click the **Workstation** tab.
2. Name the new workstation.
3. Click **Save.**
