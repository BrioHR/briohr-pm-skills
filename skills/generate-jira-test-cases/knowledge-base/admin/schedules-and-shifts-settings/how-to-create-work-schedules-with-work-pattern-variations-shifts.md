# How to Create Work Schedules with Work Pattern Variations (Shifts)

*Learn how to create shifts work schedules using Work Pattern Variations in BrioHR. Step-by-step instructions for setting up Full Week and Custom patterns for various scenarios like Ramadan and festive seasons*

Work Pattern Variation is a configuration inside a work schedule that allows you to define a set of work pattern rule for a** specific period.** These rules will take precedence over the default work pattern set up in the General section.


**For each work schedule, you can create multiple sets of work pattern variations, which can consist of either 'Full Week' and/or 'Custom' patterns.**


#### Common use cases for work patten variation in work schedules include:


- During the Ramadan month, employees work Monday to Thursday (full day) and Friday (half day).
- During festive seasons (e.g., Chinese New Year), department store employees may need to work on weekends with rest days on weekdays. For example, this work pattern might last from January 1, 2025, to February 15, 2025.

### How to Set Up Work Pattern Variations


Login to BrioHR account


1. Go to **Settings.**
2. Navigate to **Schedules & Shifts.**
3. In the **Work Schedules** section, click the pencil icon of the work schedule for which you want to configure a work pattern variation.
4. On this page, there are two sections: **General** and **Work Pattern Variation**.

  1. Click on **Work Pattern Variation.**
5. To create a new work pattern variation, click on the **+Create Pattern **button.
6. A pop out window will appear. Fill in the following details:

  1. **Pattern name**
  2. **Start date**
  3. **End date**
  4. **Work Pattern Type:** Choose either **Full Week **and **Custom**


**NOTE:**
**If you would like to know how to setup general settings for work schedules, please refer to [[this guide](https://support.briohr.com/knowledge/create-work-schedule-flexible-hours-guide?hsLang=en)].**


---


#### Work Pattern: Full Week


This option allows you to define a recurring work pattern for a full 7-day week.


- A day that is set as **'Full Day' **will be 8 hours.
- A day that is set as **'Half Day'** will be 4 hours.
- A** 'Rest Day'** is consider as weekend/day off.


**NOTE:**


- **If a weekday is set as a Half Day, employees cannot apply for full-day leave on that day.**
- **Marking a day as a Rest Day prevents employees from applying for leave on that day.**


---


#### Work Pattern: Custom


This option allows you to define specific work and rest days. The pattern will repeat according to the specified start and end dates.


**NOTE:**


**If the start date falls mid-week, the work pattern will begin from that date.**


- Specify the number of workdays per week in the **Work for** field.
- Define each workday as either** 'Full Day' **(8 hours), **'Half Day'** (4 hours)
- Specify the number of rest days in the **Rest for** field.
- You can create multiple sets of work rules within a custom work pattern.
