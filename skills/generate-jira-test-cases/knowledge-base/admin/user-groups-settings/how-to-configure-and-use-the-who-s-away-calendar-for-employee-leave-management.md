# How to Configure and Use the Who's Away Calendar for Employee Leave Management

*Learn how to configure and use BrioHR's Who’s Away Calendar for efficient employee leave tracking. Step-by-step guide for Admins to set permissions and view leave data.*

**Audience & Scope**


Audience: HR Admin, Manager


Module: Leave


Country: Global


Pre-requisites: Admin User Permission & any user with Permission to view Who's Away calendar





#### Introduction


The **Who’s Away Calendar** in BrioHR is a valuable tool for HR Admins and team managers to monitor employee leave and ensure seamless workforce planning. This guide outlines how to configure user permissions and use the calendar to manage leave visibility efficiently.


###


#### Steps to Enable the User Group Permissions For The Who's Away Calendar


1.    Login to BrioHR and click into **Settings > User Group**


2.   At the **Manager User Group**, click on the **Edit **icon.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-07-18-26-6729-AM.png?width=670&height=283&name=image-png-Sep-24-2025-07-18-26-6729-AM.png)
[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48246770021/original/513-lTRpY5tMZ7wFv9YEUy-9jJsBtP6KMQ.png?1661224789)


3.   Click on "**Page Access**" and tick the following settings configurations that apply:


- **Who's Away:** Tick this checkbox to allow the user to view **Who's Away** information from the **Home **dashboard.
- **View employees within their office**: Tick this checkbox to restrict the user to view leave information only for their office.
- **View employees within their department:** Tick this checkbox to restrict the user to view leave information only for their department.
- **View everyone's:** Tick this checkbox to allow the user to view leave information of all employees from any office/department.
- **Includes leave requests that are pending approval:** Tick this checkbox to include information on leave requests pending approval. (If this setting is not enabled, the Who's Away calendar will only display approved leave requests.)


4.    Click the "**Save**" button to apply the changes


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-07-20-12-8808-AM.png?width=670&height=634&name=image-png-Sep-24-2025-07-20-12-8808-AM.png)

#### How to Sync Your BrioHR Leave Calendar with Google Calendar


Follow these simple steps to view your team’s leave schedule directly in Google Calendar:


1. Go to **Home > Who’s Away** in BrioHR

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-01-2026-05-42-19-3554-AM.png?width=670&height=344&name=image-png-Apr-01-2026-05-42-19-3554-AM.png)
2. Click on **Sync**

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-01-2026-05-42-54-9812-AM.png?width=670&height=344&name=image-png-Apr-01-2026-05-42-54-9812-AM.png)
3. Select the **year** (e.g., 2026)

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-01-2026-05-43-32-9054-AM.png?width=670&height=290&name=image-png-Apr-01-2026-05-43-32-9054-AM.png)
4. Choose the appropriate calendar URL (e.g., *Get Office Calendar URL*)

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-01-2026-05-44-41-2836-AM.png?width=670&height=364&name=image-png-Apr-01-2026-05-44-41-2836-AM.png)
5. **Copy the URL** provided

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-01-2026-05-45-06-0332-AM.png?width=670&height=368&name=image-png-Apr-01-2026-05-45-06-0332-AM.png)


      6. Next, open your **Google Calendar** and click on the '**+**' button on the **Other Calendars**


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-01-2026-06-07-29-3917-AM.png?width=254&height=468&name=image-png-Apr-01-2026-06-07-29-3917-AM.png)


      7. Choose the '**From URL**' option


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-01-2026-06-09-46-9957-AM.png?width=288&height=337&name=image-png-Apr-01-2026-06-09-46-9957-AM.png)


     8. **Paste the copied URL** to subscribe to the calendar, then click **Add Calendar**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Apr-01-2026-06-11-23-3170-AM.png?width=670&height=331&name=image-png-Apr-01-2026-06-11-23-3170-AM.png)


     9. You will now be able to view the leaves applied appearing in your calendar.


👉 Feel free to refer to this [guide](https://support.google.com/calendar/thread/292600648/how-to-import-a-calendar-from-website-url?hl=en) for detailed steps on adding the URL to Google Calendar.
