# How to Create a User Group

*Learn how to create a User Group in BrioHR with this step-by-step guide. Configure permissions and manage employees access easily.*

**Audience & Scope**


Audience: HR /Admin


Module: Admin Settings


Country: Global


Pre-requisites: Admin access in the system





User Groups in **BrioHR** allow Admin users to manage employee access, assign permissions, and streamline system usage. Creating a User Group ensures that employees have the right access level based on their roles.


This guide will walk you through the simple steps to **create a new User Group in BrioHR**.





### Step-by-Step Guide: How to Create a User Group


#### Step 1: Access Settings


- Click on the **Settings** button.
*(Note: Only Admin users with the right access can view this option.)*
- Select the **User Groups** tab from the Settings menu.


#### Step 2: Add a New Group


- Click on the **+Add Group** icon to create a new User Group.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-02-2025-01-44-50-0798-PM.png?width=670&height=255&name=image-png-Sep-02-2025-01-44-50-0798-PM.png)


#### Step 3: Enter Group Details


- In the **Add User Group** pop-up window, enter the **name** of your new User Group.


#### Step 4: Configure Permissions


- Under the **Permission** category, enable or disable specific settings to match your requirements.


**NOTE**:

Setting up User Group Permissions correctly is important as it controls the information each user is allowed to view and access within the system, **especially for Profile Sensitive and Non-Sensitive Data**. These permissions help protect employee privacy and ensure users only see information relevant to their role.


For example, if an employee is unable to view another employee’s profile or obtain their email address, it is likely because the permission for “Employee General Information” under Non-Sensitive Data has been disabled for their assigned user group.


Be sure to go through each setting and select the required permissions accordingly.


- Click **Save** to complete the action.
- To cancel, click **Cancel.**


**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-02-2025-01-47-33-9251-PM.png?width=670&height=585&name=image-png-Sep-02-2025-01-47-33-9251-PM.png)
**


#### Step 5: Verify Your New Group


- The newly created User Group will now appear in the **list of User Groups.**


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-02-2025-01-48-20-1794-PM.png?width=670&height=313&name=image-png-Sep-02-2025-01-48-20-1794-PM.png)
