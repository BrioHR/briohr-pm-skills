# How to Enable Module Access & Reports for HR/Admin, Manager & Employee (SG) in HR Lounge

*Learn how to enable or restrict module access and reports for different user groups in HR Lounge (SG).*

**Note:** *This function is only available for users with **Admin access.***


### 1. Access the Settings Page


- Click on **Settings** at the top right of the page.
- *If you do not see the button, please contact an Admin user for access.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-20-2025-04-05-57-3692-AM.png?width=1125&height=480&name=image-png-Mar-20-2025-04-05-57-3692-AM.png)

*


### 2. Navigate to User Groups


- Click on **User Groups** in the settings menu.


### 3. Select the User Group


- Click the **Edit** button next to the user group you wish to modify.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-20-2025-04-07-25-5655-AM.png?width=1246&height=606&name=image-png-Mar-20-2025-04-07-25-5655-AM.png)


### 4. Modify HR Module Permissions


- Scroll to the **HR Modules Permission** section.
- In this section, you can:

  - **Enable/Disable module access** by clicking the toggle.
  - **Set access levels** – decide if users in this group can access only the **dashboard** or both the **dashboard and configuration settings**.


### 5. Configure Report Access


- Locate the **Report Module** field on the same page.
- Select the reports you want this user group to access by ticking the checkboxes.
- Reports that are **not selected** will not be visible to users in this group.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-20-2025-04-08-38-8085-AM.png?width=1150&height=651&name=image-png-Mar-20-2025-04-08-38-8085-AM.png)


### 6. Save the Changes


- Click on the **Save** button to apply the changes.
