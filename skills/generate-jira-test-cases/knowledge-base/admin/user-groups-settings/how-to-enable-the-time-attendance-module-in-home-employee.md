# How to enable the Time Attendance Module in Home (Employee)

*This article explains how to enable the Time Attendance module for employees through User Group permissions.*

To effectively manage time attendance, it is essential to enable the Time Attendance Module in BrioHR for Employee. This guide outlines the steps to configure the necessary permissions.

Login to your BrioHR account:


1. Navigate to Settings > User Groups.


2. Locate the relevant user group (e.g., Admin) and click the pencil icon to edit.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-20-2024-02-46-39-9826-AM.png?width=688&height=305&name=image-png-Nov-20-2024-02-46-39-9826-AM.png)





3. Go to the Employee Modules Permission category.


4. Search for the Time Attendance Module and enable the toggle button.


5. Click Save to confirm the changes.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-21-2024-02-54-16-7406-AM.png?width=688&height=471&name=image-png-Nov-21-2024-02-54-16-7406-AM.png)





This setup ensures Employee can efficiently access and manage time attendance related tasks.
