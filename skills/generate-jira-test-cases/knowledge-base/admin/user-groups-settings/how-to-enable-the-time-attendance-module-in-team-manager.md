# How to enable the Time Attendance Module in Team (Manager)

*This article explains how to enable the Time Attendance module for managers through User Group permissions.*

To effectively manage time attendance, it is essential to enable the **Time Attendance Module** in BrioHR for Manager. This guide outlines the steps to configure the necessary permissions.

Login to your BrioHR account:


1. Navigate to **Settings** > **User Groups**.


2. Locate the relevant user group (e.g., Admin) and click the **pencil icon** to edit.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-20-2024-02-46-39-9826-AM.png?width=688&height=305&name=image-png-Nov-20-2024-02-46-39-9826-AM.png)





3. Ensure permissions for **Manager Modules Permission** is enabled.


    a. Go to **Pages Access**, check the box for **Team**.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-21-2024-02-32-24-3348-AM.png?width=688&height=462&name=image-png-Nov-21-2024-02-32-24-3348-AM.png)





4. Go to the **Manager Modules Permission** category.


5. Search for the **Time Attendance Module** and enable the toggle button.


6. Select the appropriate "**Team Access**" option:
    a. **Direct Reports Only**.


    b. **2 levels below (Direct reports and their direct reports)**.


    c. **Direct reports and all levels below**.


7. Click **Save** to confirm the changes.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-21-2024-02-35-51-8931-AM.png?width=688&height=481&name=image-png-Nov-21-2024-02-35-51-8931-AM.png)





This setup ensures Managers can efficiently access and manage time attendance related tasks.
