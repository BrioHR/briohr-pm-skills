# How to Enable User Group Access for HR/Admin: Claim Module & Reports

*Learn how to enable access to Claim Module and Claim Report for HR/Admin user group within BrioHR. Step-by-step guide included.*

This guide provides a step-by-step walkthrough on how to grant the **HR/Admin** user group access to the **Claim Module** and **Expense Claims Report** in **BrioHR**. By configuring the correct permissions, HR/Admin users will be able to manage, track, and act on employee claims effectively.





### Steps to Enable Access to Claim Module & Report


1.    Login to BrioHR and click into **Settings > User Group**


2.   At the **Admin User Group**, click on the **Edit **icon.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-08-07-32-8141-AM.png?width=1894&height=723&name=image-png-Sep-24-2025-08-07-32-8141-AM.png)


3.   Within the Admin User Group, go to **HR Modules Permission**.


4.    Look for the **Expense Claim Module **and **enable the toggle button** for this module.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-08-13-31-4281-AM.png?width=850&height=798&name=image-png-Sep-24-2025-08-13-31-4281-AM.png)


- **Allow dashboard access - **here is the access level for HR/Admin in the claim dashboard. This access gives rights to view all claims.


**NOTE:**
You can choose **'Allowed for managed offices'** if you want the users to only have access to a limited set of offices, or you can choose **'Allowed for all employees' **if you want users to be able to access all claims.


- **Allow module configuration -** here is the access level for HR/Admin in the Expense Claims settings.


**NOTE:**
You can choose **'Allowed for managed offices'** if you want the users to only have access to the employee level customization for employees from a limited set of offices, or you can choose **'Allowed for all employees' **if you want users to be able to access all settings, including claim type creation and configuration.


- **Perform action on behalf of others - **tick this checkbox if you allow HR/Admin to perform action on behalf of others, this action including create claim submission, approve/reject/cancel/reopen the claims.


**CAUTION:**
Please enable the permission of "perform action on behalf of others" as the users in this User Group can approve other approver's claim approval level!


- **Edit claim after submission - **tick this checkbox if you allow HR/Admin to edit/modify the claim submission by employees in HR Lounge, even after it has been submitted, and before it has been approved or reimbursed.


5.   Next, within the HR Modules Permission page, search for the **Reports Module**


6.   Ensure the access to the Report module has been enabled then tick the checkbox :


- **Allow access to expense claim report**


**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-24-2025-08-21-36-2165-AM.png?width=851&height=807&name=image-png-Sep-24-2025-08-21-36-2165-AM.png)
**


7.   Click **Save** to apply the changes.
