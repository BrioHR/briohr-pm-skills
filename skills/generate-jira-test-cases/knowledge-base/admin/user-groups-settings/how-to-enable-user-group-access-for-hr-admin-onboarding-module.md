# How to enable user group access for HR/Admin (Onboarding Module)

*This guide explains how to enable access to the Onboarding Module for user groups in BrioHR, specifically for HR/Admin roles. Follow the detailed steps to grant permissions effectively.*

Login to your BrioHR account:


1. On the Home, go to **Settings** at the top right of your account.


2. Navigate to **User Groups**


3. **Select the user group** for which you want to grant access. Click on **pencil icon** to edit and manage permissions.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-20-2024-03-11-49-7405-AM.png?width=688&height=298&name=image-png-Aug-20-2024-03-11-49-7405-AM.png)


4. Navigate to permission category: **HR Modules Permission.**


---


### To enable access to Onboarding Module


Under the category: HR Modules Permission


5. Find **Onboarding Module**. Turn ON the toggle button to give permission for this module.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-14-2024-06-26-22-8478-AM.png?width=688&height=389&name=image-png-Nov-14-2024-06-26-22-8478-AM.png)


6. Once you toggle ON the button, you can set the permission to give


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-14-2024-06-29-18-9632-AM.png?width=688&height=499&name=image-png-Nov-14-2024-06-29-18-9632-AM.png)


- **Allow to access module settings -** here is the access level for HR/Admin in the Onboarding Process settings.


- **Allow dashboard access - **here is the access level for HR/Admin in the onboarding dashboard. This access gives rights to view all new joiners list.


NOTE:
You can choose **'Allowed for managed offices'** if you want the users to only have access to a limited set of offices, or you can choose **'Allowed for all employees' **if you want users to be able to access all new joiners list.


7. Click on **Save** button to save the setting.
