# Tracking User Access Modification History

*Learn how to view the modification history of user access changes in BrioHR. Step-by-step guide for Admins to track updates in user group settings.*

In BrioHR, keeping track of **user access modifications** is essential for maintaining system security and ensuring compliance. With the **Modification History** feature, Admins can easily review changes made to user access settings, including updates to **User Groups** and permissions.


This guide explains how to check the modification history in just a few clicks.





### Steps to Check the Modification History


1. **Log in** to your BrioHR account.
2. Navigate to **Settings > User Groups**.
3. Click on the **refresh icon** located in the User Groups section.
4. A **Modification History log** will appear, showing details of recent changes made to user access settings.
