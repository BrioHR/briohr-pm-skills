# How to Upload and Preview Multiple Attachments in Your Claims

*This article explains how to upload and preview multiple attachments when adding claim requests.*

Discover the latest enhancements to our Expense Claims module. We are thrilled to introduce the new "**Upload Multiple Attachments**" feature, designed to improve your experience when adding claim requests by allowing multiple file uploads.


### What's New:


1. **PDF Preview on Mobile Apps:**
Users can now preview PDF attachments directly via our mobile apps. Simply click on the PDF file to preview it. Please ensure your app is **updated to the latest version to access this feature**.


![YKHHWYFBc0IGux7uhtBDwOMDyBXyw_0Bbg.png?1718076836](https://support.briohr.com/hs-fs/hubfs/Imported%20images/YKHHWYFBc0IGux7uhtBDwOMDyBXyw_0Bbg.png%3F1718076836.png?width=454&height=783&name=YKHHWYFBc0IGux7uhtBDwOMDyBXyw_0Bbg.png%3F1718076836.png)


**2.    Attachment Download via Web Browser:**
When adding a claim through a web browser, users can download the uploaded attachments. This allows you to verify the correct receipt before saving the claim.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48336910650/original/_5FJ-yKPXiyh17yeuvjQBmrlhwV6DtSHjw.png?1715737522)


**NOTE:**


- **Mobile App Users:**
**Please update your mobile app to the latest version to enjoy these new features.**
- **File Size and Type Restrictions:**
**The maximum file size is 10MB, and the supported file types are PNG, JPG, and PDF.**
