# How to Enable and Configure Carry Forward of Previous Year Leave Balance in the New Year

*This guide will show you how to enable the previous year carry forward to reflect in the current (new) year leave dashboard after December 31.*

### Introduction


Every year, at midnight on December 31st, the system automatically carries forward all employees' leave in a single process, provided that the "**Carry Forward**" function in the leave policy has been enabled **before **December 31.


However, upon returning to work on January 2 of the new year you discovered that the "Carry Forward" function was not enabled. You would like the unused leave balance from the previous year to be reflected on every employee's new year leave dashboard as "202X Carry Forward."


If you would like to know how an employee can apply leave of previous year in the current year, please refer to [this article](https://support.briohr.com/knowledge/how-to-apply-for-past-leave-in-the-current-year?hsLang=en).


---


This article is divided into two parts:


**Part (A): Enable and configure the Carry Forward 202X function in the previous year leave policy.**


**Part (B): Recompute the employee's Carry Forward balance to reflect accurately.**


**IMPORTANT!**


Please complete** BOTH **parts to ensure the updated carry forward is reflected correctly!


**We will use Annual leave as an example. Part (A) and Part (B) work for other leave types as well.**


**DISCLAIMER:**

We will use 2025 as an example for the previous year, and 2026 as an example for the current year.


**The year will be different for you if you are reading this in 2027 onwards.**


---


### Part (A): Enable and Configure the Carry Forward 2026 Function in the 2025 Leave Policy


#### To open a leave policy page:


1.  Go to **HR Lounge > Leave > Leave Policies**.


2.  Select the leave type you would like to enable last year's carry forward (**e.g., Annual**)


3.  Click "**View Leave Details**."


4.  You will be directed to the leave page (e.g., Annual leave page).


![open leave policieis](https://support.briohr.com/hs-fs/hubfs/open%20leave%20policieis.gif?width=670&height=306&name=open%20leave%20policieis.gif)


#### Steps to Enable Carry Forward in the Previous Year's Policy:


1.   Select the **policy **you want to edit > Click **General Configuration**.


Select "`Year`" and choose `2025`.


**NOTE:**


Please select the** correct previous year** (e.g., 2025) because we are making changes to last year's leave policy to reflect the carry-forward balance in 2026 (current year)!


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-31-2025-01-32-20-3165-AM.png?width=2000&height=667&name=image-png-Dec-31-2025-01-32-20-3165-AM.png)





2.   Search for "`Carry Forward 2026`" > **Toggle ON** the button > Set up configuration.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-17-2025-05-05-40-4482-AM.png?width=670&height=201&name=image-png-Dec-17-2025-05-05-40-4482-AM.png)





3.   Once done, click "**Save Settings**."


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48322394920/original/X__NaD-O1SntK3Ozz_xwRDNd5_miWMNtfA.png?1704369129)


**NOTE:**


If you want to edit all policies, please repeat the above steps for each policy.


---


### Part (B): Recompute the Employee's Carry Forward Balance to Reflect Accurately


1.   Go back to the leave page (e.g., Annual) > Click "**Initial Balances**."


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-17-2025-05-06-40-0954-AM.png?width=670&height=277&name=image-png-Dec-17-2025-05-06-40-0954-AM.png)


2.   Click the "**Refresh**" icon to recompute the carry-forward balance.


- Do this for all employees if you would like to recompute for everyone.
- If you want to recompute for specific individuals only, please recompute for the selected individuals.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-17-2025-05-11-57-7684-AM.png?width=670&height=309&name=image-png-Dec-17-2025-05-11-57-7684-AM.png)


The new carry-forward balance will be reflected on the employee's current year (e.g., 2026) leave dashboard.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-17-2025-05-12-22-2866-AM.png?width=670&height=240&name=image-png-Dec-17-2025-05-12-22-2866-AM.png)





---


### IMPORTANT


- The system rolls over any used leave from the previous year to the next year.
- If part of an employee's carry-forwarded leave expires on December 31st, that **expired portion will not be carried over into the new year.**
