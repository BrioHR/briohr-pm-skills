# How to Configure Minimum or Maximum Consecutive Leave Days for Employees

*This article explains how to configure minimum or maximum consecutive leave days for leave types such as blocked leave.*

This feature allows HR and Admin users to specify the minimum number of consecutive days that employees can book for leave at a time. This is particularly useful for specific leave types, such as "**Blocked Leave**."


To enable these settings, follow the steps below:


1.   Ensure you have **HR/Admin access** to the **Leave **module in the **HR Lounge**.


- **Go to Settings > User Groups > Select your user group > Edit > HR Modules Permission.**
- **Set Leave Module to Enabled.**
- **For Allow module configuration**, choose the relevant option.
- **For Allow dashboard access**, choose the relevant option.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48321384988/original/A9kjVVlkPc8guEEr3wiHJBGBDD9FBzhDGg.png?1703161235)

2.   Navigate to **HR Lounge > Leave > Leave Policies > View leave details**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48321384991/original/t5ShophNh_J8MQySHGTyaoF92PukIM0pTg.png?1703161236)


3.   Scroll down to "**Set a minimum number of days that can be booked at a time (consecutive days)**" under **LEAVE ADVANCE SETTINGS**. Select "**Yes, set a limit**" and input the number of days.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48321384985/original/2KIttZZfoSXE1cz7raZ_B8N9Mpm0tb8V3A.png?1703161235)


4.   Click **Save settings** to apply the changes.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48321384992/original/k7KaFzzvvG7T94-5Yvw3XctF_QOBQ5Yt2w.png?1703161236)


Once the settings are configured, if an employee submits a leave application for fewer days than the minimum consecutive days set, they will not be able to apply successfully.

**IMPORTANT NOTE:**


**Be mindful of the settings for "Set a limit to the period that can be booked at a time (consecutive days)".**


This setting determines the **maximum **number of consecutive days that can be booked at once.


Avoid setting the minimum number of days higher than the maximum. For example, if the maximum is 3 days and the minimum is set to 5 days, employees will be unable to apply for leave successfully.


The system will show a warning message similar to the one below when attempting to apply for 5 days of leave:
