# How to Enable Backdated Leave Requests in BrioHR

*Learn how to enable backdated leave requests for employees in BrioHR from feature "Allow Employees to Apply Leave In The Past". Follow this step-by-step guide to update leave policy settings easily*

BrioHR allows you to configure leave policies so employees can apply for backdated leave requests quickly and efficiently.


The feature can be found in the leave policy as **"Allow Employees To Apply Leave In the Past"**


---


### Steps to Enable Backdated Leave Requests


1. Go to **HR Lounge**
2. Navigate to the **Leave module**
3. Click on **Leave Policies**
4. Select the leave type you want to configure (e.g., Medical Leave) and click on **View Leave Details**.
5. On the policy page, scroll down to **Leave Advanced Settings**.
6. Locate the option **"Allow employee to apply leave in the past"**. Toggle ON to enable it.
7. Click the **Save Settings** button to save your changes.

### What happens if the feature is not enabled?


If this feature is not enabled, employees will receive an error message when attempting to submit a past-dated leave request.

### Can employees apply for past leave without approval?


Typically, all leave policies include a defined approval process. Therefore, when employees submit requests for past-dated leave, these requests will still need to go through the established approval workflow.

Generally, employees cannot submit requests for past-dated leave without going through an approval process. However, if the leave policy does not specify an approval workflow, the application will be automatically approved due to the absence of such a process.
