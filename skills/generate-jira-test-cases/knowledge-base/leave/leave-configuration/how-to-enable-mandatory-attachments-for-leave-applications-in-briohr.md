# How to Enable Mandatory Attachments for Leave Applications in BrioHR

*This article explains how to make attachments mandatory for leave applications so employees cannot submit without uploading one.*

BrioHR's exciting new feature release allows HR/Admin users to require attachments in the Leave module.


When this feature is enabled, employees will NOT be able to submit their leave application without uploading the mandatory attachment first. A warning notification will appear as follows:


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48175025666/original/9nclvzpzGQ0B2RW4w_soV51CfdUd39TZlA.jpg?1641182930)


How to Enable the Mandatory Attachment Feature


- Go to **HR Lounge** and select **Employee Leave**.
- Click on **Leave Policies**.
- Choose the leave policy you wish to modify, such as Medical Leave, and select **View leave details**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48174786556/original/xSVw3dkTOybOVXv3Xxg9otBI7aETejoXfg.png?1640931119)


- Scroll down to the **ADVANCED CONFIGURATION** field, and check the box next to the "**Mandatory attachment**" column.
- Click **Save settings **to complete the action.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48174787247/original/SKiKDmOQZ4SeHt-baPUlj4ZJqKekN0bfDw.png?1640931579)


- Once enabled, a "*" icon will appear next to the Attachment column when an employee is making a leave application, indicating that it is a mandatory field.


![9twC74A3YJi9Vll7-RnFIhMLzSAOCziVYw.png?1641183073](https://support.briohr.com/hs-fs/hubfs/Imported%20images/9twC74A3YJi9Vll7-RnFIhMLzSAOCziVYw.png%3F1641183073.png?width=439&height=76&name=9twC74A3YJi9Vll7-RnFIhMLzSAOCziVYw.png%3F1641183073.png)


**NOTE:**


**To disable this setting, simply uncheck the Mandatory attachment field under the Leave Policies settings and click Save settings to complete the action.**
