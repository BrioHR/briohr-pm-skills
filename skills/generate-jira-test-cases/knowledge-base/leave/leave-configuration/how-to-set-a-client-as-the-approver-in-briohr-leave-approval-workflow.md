# How to Set a "Client" as the Approver in BrioHR Leave Approval Workflow

*This article explains how HR/Admin can set an external client as the approver in a leave approval workflow for project-based employees.*

At BrioHR, HR/Admin can set an external "Client" as the approver for leave requests. This is useful when an employee is working on a project with an external client, and their leave requests need to be approved by that client.


**NOTE:**


**Ensure both the project and client information are updated in the Timesheet module and the employee profile > Project page.**


###


---


### Steps to Set a "Client" as the Approver:


Log in to your BrioHR account.


1. Go to **HR Lounge.**
2. Navigate to **Leave**.
3. Go to **Leave Policies.**
4. Click "**View leave details**" on the policy name where you want to set the "**Client**" as the approver.
5. Under General Configuration/Leave Approval, edit the **Approval Workflow** and select **Position - Client** as the approver.

#### FAQ:


**Does HR need to create a profile in BrioHR for the "Client" as a Leave approver?**


**Answer: No, HR doesn't need to create a profile for the client in BrioHR. The client can approve the submitted leave directly from their email.**


Steps for a Client to Approve Leave via Email. Once an employee submits their leave, the client (approver) will receive an email.


1.   Click on the blue link "**Click here to Approve/Reject.**"


![mbkqtC2Ln1xhSj0zbFMjZqDe0k2AWoZXLg.png?1719473608](https://support.briohr.com/hs-fs/hubfs/Imported%20images/mbkqtC2Ln1xhSj0zbFMjZqDe0k2AWoZXLg.png%3F1719473608.png?width=644&height=470&name=mbkqtC2Ln1xhSj0zbFMjZqDe0k2AWoZXLg.png%3F1719473608.png)


2.   The client will be directed to a new browser page titled "**Leave Approval Request**."


On this page, the client can:


- View details of the leave.
- Select the checkbox for acknowledgment.
- Click "**Approve Leave**" or "**Reject Leave**."
