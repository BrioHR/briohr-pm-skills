# How to Set a Time Limit for Leave Booking in Advance

*This article explains how to set a time limit for booking leave in advance within a leave policy's settings.*

1.   In **HR Lounge**, click on **Employee Leave**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48293578647/original/sMQNrAcxd8Uvq8BX24FD58VAfF0lNMebfQ.png?1681967069)


2.   Click on **Leave Policies**, and select the leave type you wish to modify.


3.   For example, for Annual Leave, click on **View Leave Details**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48293578673/original/wSgkzPQw7n_Mn5bwTU6Y6NR4ZQziDsiv2A.png?1681967088)


4.   Click on the policy you wish to apply the settings to, and scroll down to the **Leave Advance Settings** column. Here, you can set the **maximum and minimum time limits** for leave booking in advance.


i. In the '**Set a minimum limit of time for the leave to be booked in advance**' field, select **Yes, set a limit**. Then, input the **value **and select the **period (day/week/month)** from the dropdown.

**For example, if you set it as "7 days", it means employees must apply for leave at least seven (7) days in advance.**


**If employees try to apply for leave less than 7 days in advance, the system will not allow them to proceed.**


ii. Similarly, in the '**Set a maximum limit of time for the leave to be booked in advance**' field, select **Yes, set a limit**. Then, input the **value **and select the **period (day/week/month)** from the dropdown.


**For example, if you set it as "2 months", it means employees can apply for future leave up to two (2) months in advance.**


**If the current date is April 2023 and an employee wants to apply for leave on December 24, 2023, the system will not allow it because the application date exceeds the maximum period set.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48293579213/original/G89IRJXmcHwzvnjuWj14BAO9L8Gng4NFaQ.png?1681967397)


5.   Click **Save Settings** to complete the action and apply the settings.


**NOTE****:**


**Once these settings are applied, if an employee tries to submit a leave application that does not comply with the set time period, a warning notification will appear, prompting the employee about the required time period for leave application. The employee will not be able to proceed with the leave application.**


**If you wish to apply these settings only to specific employees, you can do so under the All Employees - Custom Configuration field by clicking on Min Application In Advance or Max Application In Advance.**
