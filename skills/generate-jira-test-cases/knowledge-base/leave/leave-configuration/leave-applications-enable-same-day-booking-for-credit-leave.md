# Leave Applications: Enable Same-Day Booking for Credit Leave

*This article explains how to enable the "Allow Booking Leave on Reference Date" function in the credit leave policy settings, allowing credit to be used on the same reference date.*

We're excited to introduce a new feature that allows employees to conveniently apply for leave on the same day as the reference day for credit leave. This functionality streamlines the process, allowing for efficient management of leave requests and an improved employee experience.


### Guide to Allow Booking Leave on Reference Date:


1. Navigate to **HR Lounge > Leave > Leave Policies.**
2. Select the relevant credit leave type and policy.
3. Enable the option to** "Allow booking leave on reference date."**


**NOTE:**


**1. Please note that this feature is applicable only for credit-based leave types.**


**2. If multiple reference dates are set, leave can only be applied starting from the last date in that range. For example, if 5–7 May are selected as reference dates, leave can only be applied from 7 May onwards.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48313536435/original/d7KVfETSBjPAWUaYIHqa5_WQVAVu2K5Dqw.png?1696921511)


**Ensure this setting is enabled BEFORE employees attempt to utilize same-day leave.**


**NOTE:**


**If changes are made to the policy after a credit request has been submitted, the HR/Admin team must delete the existing credit request. Employees will then need to resubmit their credit requests, or the HR/Admin can assist by submitting the request on their behalf.**


Once the setting is enabled, employees can seamlessly utilize the chosen reference date for their leave.


Example: An employee has a credit request on October 15th and also utilizes the credit on the same date.
