# How to Download the Leave Utilization (History) Report for All Employees in Your Company

*Managing leave records is essential for effective HR administration. A comprehensive leave utilization report allows you to track employee leave usage accurately.*

### Steps to Download the Leave Utilization Report for All Employees:


1. Click on **HR Lounge.**
2. Select** Leave.**
3. Click on **Reports,** and choose **'Download leave utilization report'.**
4. You can choose either to get the **Full Year** report, or **Monthly** report.

  1. If **Monthly** is chosen, you need to select the relevant month for the report.
5. Click on the** 'Download'** button to proceed download the report and open file in Excel format.


**NOTE:**
**- The leave utilization report will include records for all employees in the company.**
**- If an employee's leave spans two months (e.g., 25 Oct - 8 Nov 2024), in the report October AND November, it will show the same leave records twice* (refer below image)***
