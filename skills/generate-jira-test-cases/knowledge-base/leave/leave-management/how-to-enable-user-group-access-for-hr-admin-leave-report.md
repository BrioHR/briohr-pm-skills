# How to Enable User Group Access for HR/Admin (Leave + Report)

*This article provides a step-by-step guide to enable access to leave and report modules for HR or Admin users in BrioHR. Follow these simple instructions to configure permissions within user groups effectively.*

### Steps to Enable User Group Access for HR/Admin


1. **Navigate to Settings**: Log in to BrioHR and click the **Settings** icon in the top-right corner.
2. **Access User Groups**: In the left-hand panel, select **User Groups**.
3. **Edit the User Group**: Find the user group for HR/Admin and click the **pencil icon** to edit.
4. **Enable HR Module Permissions**: Enable **Reports Modules** and **Leave Modules** in the **HR Modules Permission** section.
5. **Configure Specific Permissions**: Tick the relevant options for reports and leave configurations.


### Leave Module Report Module


By completing these steps, your HR or Admin user group will have access to the necessary leave and report functionalities within BrioHR.
