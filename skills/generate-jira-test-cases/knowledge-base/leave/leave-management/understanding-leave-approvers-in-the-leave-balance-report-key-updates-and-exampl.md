# Understanding Leave Approvers in the Leave Balance Report: Key Updates and Examples

*This article explains how the Leave Balance Report displays the most recent leave approvers and how it differs from the Leave Timeline.*

The Leave Balance Report now displays the **most recent Leave Approvers**. This feature allows you to filter pending leave requests by specific approvers.


However, if changes are made to the Leave Approvers after a leave request has been submitted, the Leave Timeline will show the pending action by the approver as of the submission date.


Conversely, the Leave Balance Report will show the most recent Leave Approver for each employee.


**Example:**


1.   Employee Vanessa submits a leave application on October 26, 2022, for October 28, 2022, with approval pending from her Manager, Raj.


The system records this information with Raj as the approver effective from October 26.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48259232717/original/QG2Th0HSJR1HnHKqnq_LX3NpUR8xtimj1A.jpg?1666772562)


2.   After Vanessa’s leave request is submitted, her Leave Approver is changed to Jack.


In the Leave Balance Report, the system will display Jack as the current approver.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48259234009/original/KpU54Tv9Ohw4MwtBs-LOdfyks2NYiSyVug.jpg?1666772670)


3.   When checking Vanessa’s leave in the Timeline, it will still show Raj as the approver.


This is because Raj was the approver when the leave request was submitted.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48259234105/original/kWmJZME8jaBZOYhRoQoaGRaUcy30ommpUg.jpg?1666772696)


**It’s important to note** that the Leave Timeline records the approver at the time the leave was submitted, while the Leave Balance Report reflects the most recent Leave Approver if there have been changes.
