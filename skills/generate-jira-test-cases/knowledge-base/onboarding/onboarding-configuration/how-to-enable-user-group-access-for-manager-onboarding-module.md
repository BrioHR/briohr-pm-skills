# How to enable user group access for Manager (Onboarding Module)

*This is a step-by-step guide on how to enable access to Onboarding Module for Manager Modules Permission*

Login to your BrioHR account:


1. At Home, go to **Settings** at the top right of your account.


2. Go to **User Groups**


3. **Choose which user group** you want to give the access to. Click on **pencil icon** to edit and manage permissions.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-20-2024-03-11-49-7405-AM.png?width=688&height=298&name=image-png-Aug-20-2024-03-11-49-7405-AM.png)


4. Navigate to permission category: **Manager Modules Permission.**


---


### To enable access to Onboarding Module


Under the category: Manager Modules Permission


5. Find **Onboarding Module**. Turn ON the toggle button to give permission for this module.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-14-2024-06-57-09-6751-AM.png?width=688&height=514&name=image-png-Nov-14-2024-06-57-09-6751-AM.png)


6. At **Team Access, **choose which employees you would like managers to have access to.


7. Click on **Save** button to save the setting.
