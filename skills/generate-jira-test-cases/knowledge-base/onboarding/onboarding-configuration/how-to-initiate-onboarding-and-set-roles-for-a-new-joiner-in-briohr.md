# How to Initiate Onboarding and Set Roles for a New Joiner in BrioHR

*Ensure a structured onboarding experience by initiating the onboarding process and assigning roles to key stakeholders in BrioHR. Follow the steps below to complete the setup for new joiners.*

**Audience & Scope**


Audience: HR Admin


Module: Onboarding


Country: Global


Pre-requisites: HR Module Permission for Onboarding Module





**Step-by-Step Instructions**


#### How to Initiate Onboarding and Assign Roles


1. Log in to** brioHR**.


2. Navigate to** HR Lounge > Onboarding**


3. Click '**+ Add a New Joiner'** – Enter the details of the new employee, if the employee profile has yet to be created.


**Learn more: [How to Add a New Employee to the Onboarding Process](/knowledge/how-to-add-a-new-employee-to-the-onboarding-process?hsLang=en)**


**IMPORTANT: **


**An Employee Profile must be created before onboarding can commence. Without a profile, a new joiner will not be able to receive the email to start the onboarding process from brioHR. Make sure a valid email address for the employee profile is added, and the email is accessible by the new joiner.**


4. View the** List of New Joiners** – The dashboard will display a **List of New Joiners** who are pending onboarding initiation.


5. **Initiate the Onboarding Process** – Click **Initiate**, then select the appropriate **Onboarding Process** from the available options.


**Learn More: [How to create a new onboarding process and setup period & roles (Onboarding Module)](/knowledge/setup-onboarding-process-period-roles-in-briohr?hsLang=en) **

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-17-2025-04-47-14-0785-AM.png?width=670&height=461&name=image-png-Mar-17-2025-04-47-14-0785-AM.png)


6. **Set Roles** – Assign key stakeholders responsible for different onboarding tasks.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-17-2025-04-47-25-1327-AM.png?width=670&height=396&name=image-png-Mar-17-2025-04-47-25-1327-AM.png)


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jun-03-2026-05-39-52-6875-AM.png?width=661&height=535&name=image-png-Jun-03-2026-05-39-52-6875-AM.png)


**NOTE: **


**Multiple people can be selected for a specific role. The same employee can also be chosen for multiple roles.**





7. **Submit the Assignments** – Once roles are assigned, click **Submit** to finalize the onboarding setup. All employees assigned as a stakeholder for the new joiner will receive an email informing them of the assignment.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Mar-17-2025-04-49-54-6446-AM.png?width=670&height=671&name=image-png-Mar-17-2025-04-49-54-6446-AM.png)


8. Once the** roles are assigned** and the **onboarding period has been reached** (based on the onboarding process setup), the new joiner will receive the email with login information to start their onboarding process in brioHR.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jun-03-2026-05-47-12-2257-AM.png?width=1809&height=1071&name=image-png-Jun-03-2026-05-47-12-2257-AM.png)





**Common Issues/FAQ**


**Q1: Can I edit/change the stakeholders to a different person?**


A1: Yes, you can change the stakeholders to a different person. Click the stakeholder icon and click edit for the position you want to change.  However, do note that changing the Manager role here changes the manager position for the employee. This will affect the employees' reporting structure.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jun-03-2026-05-54-17-0031-AM.png?width=2536&height=1090&name=image-png-Jun-03-2026-05-54-17-0031-AM.png)


**Q2: If I chose the wrong onboarding process for the new joiner, can I change the process assigned? **


A2: You will have to reset the onboarding process for the employee. But please note that in doing so, all onboarding information collected will be lost. Please refer to [this article for the guide](/knowledge/how-to-reset-onboarding-for-a-new-employee?hsLang=en).
