# How to Add a New Employee to the Onboarding Process

*This article explains how HR Admins add a new joiner to the onboarding process before their start date.*

**Audience & Scope**


Audience: HR Admin


Module: Onboarding


Country: Global


Pre-requisites: HR Module Permission for the Onboarding module


---


Before you initiate the onboarding process, it's essential to add the new joiner (employee) to the onboarding dashboard. There are three methods to accomplish this:


### Method 1: Create a New Profile Directly on the Onboarding Page


Log in to your brioHR account.


- Navigate to **HR Lounge.**
- Go to the **Onboarding **section. You’ll be directed to the Onboarding Dashboard.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48314890834/original/O4mi8AwuCdhU9nsW8ooaSEBJUuiZgQwzdg.png?1698050746)


- Click on **Add New Joiner**. A pop-up form will appear.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48314890920/original/Suya44yjH1Wo5JGyDbmEnX5uSmlsCByjIg.png?1698050788)


- Fill in the required details (mark with red asterisk) in the Add New Joiner form and click **Submit **to create the new employee profile.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48314891014/original/DA3z0Lppy5C3RO-hYwdgICZlTsmttagH7A.png?1698050839)

---


### Method 2: Choose "Yes" to Add to the Onboarding Process When Creating a Profile in Employee Management or Employee Directory


- Go to **HR Lounge > Employee Management **or** People > Employee Directory**
- Click the **Add Employee** button.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48314891643/original/ZI0ZFO1G6dYWItbqGtsnQ7_x91EdDWj6UA.png?1698051211)


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jun-08-2026-06-14-10-9169-AM.png?width=1791&height=871&name=image-png-Jun-08-2026-06-14-10-9169-AM.png)


- When prompted with the message, "Does this new employee require onboarding?", click **Yes**.
- The new joiner’s name will be added directly to the Onboarding page.
[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48314891777/original/wjgzU-FFLWjGSXXNZvms-_g1Jq8wEqQ0CQ.png?1698051278)


---


### Method 3: Add an Existing Profile to the Onboarding Page


- Go to **HR Lounge > Employee Management**

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jun-08-2026-06-18-11-1244-AM.png?width=1795&height=829&name=image-png-Jun-08-2026-06-18-11-1244-AM.png)
- Find the employee you want to onboard from the **Employee List**. Type the name of the employee in the search bar if needed.
- Click the **three dots icon** and select **Start Onboarding**. This action will add the employee’s name to the Onboarding module page.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48314892782/original/C3dCJKS4viMskAln0Xi_dh1PD2tC6FeVWQ.png?1698051750)
