# How to Reset Onboarding for a New Employee

*This article explains how to reset the onboarding process for a new employee at any stage.*

**NOTE:**


**Onboarding can be reset at any stage, even if it has been completed.**


To reset the onboarding process for a new employee, follow these steps:


- In the **HR Lounge**, click on **Onboarding**.
- On the **Dashboard**, search for the employee’s name under the **New Joiner Onboarding List.**
- Click on the "..." icon and select **Reset Onboarding** from the dropdown menu.

**NOTE:**


**Once the HR Admin has reset the onboarding, all previously entered data by the employee deleted.**


**The HR Admin has to click 'Initiate', select the onboarding process, and set the roles (Set Roles) after resetting the onboarding. If this step is skipped, the new joiner will not have any onboarding tasks assigned to them.**
