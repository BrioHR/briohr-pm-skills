# How to Configure Custom Pay Items to Display in Fixed Remunerations Table

*In this guide, we’ll show you how to configure custom pay items so they appear correctly in the Fixed Remuneration table.*

In the Fixed Remuneration table, a list of remuneration types is available by default. However, additional pay items can be added by creating custom pay items.


To ensure pay items appear in the Fixed Remuneration table of a profile's compensation, the addition type of custom pay items must be selected as either **"Fixed Remuneration" **or **"Ordinary Wage."**


### Why Choosing the Correct Custom Pay Items is Important


To ensure the pay items **appear** in the Fixed Remuneration table, the addition type of custom pay items must be selected correctly.

If a custom pay item's addition type is incorrectly selected, it will not appear in the list of remuneration types in the Fixed Remuneration table.

Therefore, be sure to choose the correct addition type!

### Common Cause with Custom Pay Items Not Appearing in the Fixed Remuneration Table


The most common cause is the incorrect selection of the 'addition type' for the custom pay item. Remember:


- **Payroll Malaysia**: The addition type is **'Fixed Remuneration'**.
- **Payroll Singapore**: The addition type is **'Ordinary Wage'**.
- Custom pay item (with correct addition type) was created **in a payroll center not assigned to the employee **(different payroll center).


### I Have Employees in Different Payroll Centers. Do I Need to Create a Custom Pay Item for Each Payroll Center?


Yes.


If the custom 'Fixed Remuneration' (or 'Ordinary Wage') pay item was created under Payroll Center ABC, but the employee is assigned to Payroll Center XYZ.


You will need to create a new custom pay item with similar configuration under Payroll Center XYZ.


**NOTE:**


**Custom pay items will only appear in the Fixed Remuneration table for employees assigned to the payroll center where the custom pay item was created.**
