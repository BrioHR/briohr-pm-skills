# How to set the salary allocation percentage in bulk?

*How to Set Salary Allocation Percentage in Bulk for Payroll Cycles*

This feature helps companies that does multiple payroll cycles in a month to make the salary payouts.


First, you will need to make sure that you have set up the payroll cycles that you require for each month's payroll run.

You can set this up by going to **HR Lounge **> **Payroll **> **Settings **> **Salary Allocation & Default items** > Click "**Set salary percentage allocation**".


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-01-2024-06-26-19-1766-PM.png?width=688&height=242&name=image-png-Aug-01-2024-06-26-19-1766-PM.png)


Once you have clicked into "Set salary percentage allocation", you will see a list of employees and the available payroll cycles.


You can click the box on the top right to select employees in bulk and fill up the information at the bottom of the page: Percentage for the selected cycle.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-01-2024-06-46-55-5529-PM.png?width=688&height=329&name=image-png-Aug-01-2024-06-46-55-5529-PM.png)


In my example below, you will see that I have 2 cycles: Salary Mid Month and Salary End Month. I will be putting a 50% salary allocation moving forward, so you will be able to see how the page updates accordingly.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Aug-01-2024-07-09-17-4233-PM.png?width=688&height=331&name=image-png-Aug-01-2024-07-09-17-4233-PM.png)


Lastly, do remember to click "Save" so that the information will be saved.
