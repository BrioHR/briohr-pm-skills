# Create an Overtime Custom Payroll Item and Add It to the Overtime Multi-rates Table

*This article explains how to create a custom payroll item with a specific multiplier. The custom OT item can then be added to the OT multi-rates table to make it easier for admins and payroll managers to enter OT hours paid out with specific multipliers.*

Currently, the system default Overtime items available are:


- Hourly rates X 0.5, 1, 1.5, 2, 2.5, 3
- Normal day, rest day, public holiday rate (according to Employment Act)
- Custom amount


If you pay Overtime for your employees with a different multiplier, for example, hourly rate x 4, you will need to create a custom OT payroll item. You can add the custom OT multiplier to the multi-rates table in payroll to make it easier to enter your OT hours for payroll processing.


**Audience & Scope**


Audience: HR Admin & Payroll Manager


Module: Payroll


Country: Malaysia


Pre-requisites: HR Module Permission for Payroll Module & Module Settings





**Step-by-Step Instructions**


**PART 1: ADD NEW CUSTOM PAYROLL ITEM**


1. Go to **HR Lounge > Payroll > Settings > Payroll Items**


**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-37-51-7982-AM.png?width=670&height=361&name=image-png-May-26-2026-08-37-51-7982-AM.png)
**


2. Click the '**+ Create custom item**' button


3. Choose item type '**Addition**'


4. Enter the item name, e.g.: Overtime (rate x 4)


5. Choose '**Remuneration**' for Category


6. Select the appropriate 'Addition type' for the OT


7. For '**Overtime (OT)?**', choose **Yes**


8. Choose '**OT based on Hours**' and add your custom multiplier, e.g.: **4.0x**


9. Keep BIK as 'No'


10. Choose which statutory contributions apply for this payroll item (PCB, EPF, SOCSO, EIS, HRDF)


11. Choose the EA form field (usually B.1 (a)) and the CP22A form field


12. Click '**Save**'


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-44-04-5332-AM.png?width=670&height=451&name=image-png-May-26-2026-08-44-04-5332-AM.png)


**PART 2: ADD CUSTOM OVERTIME RATE IN MULTIRATES TABLE**


1. Run payroll for any cycle


2. In the Adjust Payroll Stage, click the **Overtime** button to open the Overtime Multi Rates table


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-45-20-2322-AM.png?width=670&height=399&name=image-png-May-26-2026-08-45-20-2322-AM.png)


3. Click '**Set table columns**'


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-46-04-7581-AM.png?width=670&height=396&name=image-png-May-26-2026-08-46-04-7581-AM.png)


4. Click '**Change column selection**'


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-46-39-1542-AM.png?width=670&height=511&name=image-png-May-26-2026-08-46-39-1542-AM.png)


5. Tick the new Overtime item you just created, then click 'Selection done'.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-48-44-7273-AM.png?width=670&height=759&name=image-png-May-26-2026-08-48-44-7273-AM.png)


6. You can reorganize the placement of the OT items in the table by dragging the 3-line icon next to the item name


7. Click 'Save'


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-51-38-9512-AM.png?width=670&height=507&name=image-png-May-26-2026-08-51-38-9512-AM.png)


8. You should see the new OT pay item included in the table.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-May-26-2026-08-52-23-4194-AM.png?width=670&height=377&name=image-png-May-26-2026-08-52-23-4194-AM.png)
