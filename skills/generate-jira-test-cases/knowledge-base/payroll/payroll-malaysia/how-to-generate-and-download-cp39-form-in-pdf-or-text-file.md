# How to Generate and Download CP39 Form in PDF or Text File

*This article explains how to generate and download the CP39 form in PDF for records or as a text file for e-Data PCB payment.*

### A. Downloading The CP39 Form In Pdf Format


**NOTE:**


**This PDF file is for auditing or internal record purposes only and cannot be used for payment via the e-Data PCB portal.**


- In the **HR Lounge**, click on **Payroll**.


![wfCinTOipik4fnD_WcDzCD70B348CfTvKw.png?1657269572](https://support.briohr.com/hs-fs/hubfs/Imported%20images/wfCinTOipik4fnD_WcDzCD70B348CfTvKw.png%3F1657269572.png?width=272&height=535&name=wfCinTOipik4fnD_WcDzCD70B348CfTvKw.png%3F1657269572.png)


- On the **Payroll Dashboard**, select the **COMPLETED payroll month**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48237484977/original/DfVqhbRNELDdTxxBi1miBoOQs4R4Lou-_g.png?1657269683)


- In the **Statutory Reporting > PCB** column, click the "**PDF**" button.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48237486309/original/4mZYUn3NZmdfH_hTfELwnA0WsqZ_dZkk2A.png?1657269952)


- In the "**Generate Form CP39**" pop-up window, enter the following information:

  1. **Amount**: This field is pre-filled by the system based on the tax amount for the selected payroll month.
  2. **Number**: Enter the Cheque/Bank Draft/Postal Order/Transaction Number.
  3. **Branch**: Enter the name of the bank branch or portal used for payment.
  4. **Date**: Select the date on which the PDF file is generated.


![Z1SpCZWEdSv55ZlBpPysT8_7OVhi1XB2MQ.png?1657274882](https://support.briohr.com/hs-fs/hubfs/Imported%20images/Z1SpCZWEdSv55ZlBpPysT8_7OVhi1XB2MQ.png%3F1657274882.png?width=611&height=355&name=Z1SpCZWEdSv55ZlBpPysT8_7OVhi1XB2MQ.png%3F1657274882.png)


**NOTE:**


**Ensure that all payroll-related information for employees and the company's registration information under Payroll > Settings is complete.**


**If any information is missing, you will not be able to generate the PDF file, and a warning prompt will appear (as shown in the screenshot below).**


**If this occurs, input the missing information and then regenerate the PDF file.**


![B-ih8D69b3i1peQhuEWxo2_sMBuepuzCCw.jpg?1657275114](https://support.briohr.com/hs-fs/hubfs/Imported%20images/B-ih8D69b3i1peQhuEWxo2_sMBuepuzCCw.jpg%3F1657275114.jpg?width=290&height=387&name=B-ih8D69b3i1peQhuEWxo2_sMBuepuzCCw.jpg%3F1657275114.jpg)


### B. Downloading The CP39 Form In Text File Format


**NOTE:**


**This text file can be used for payment by uploading it via the e-Data PCB portal.**


- In the **HR Lounge**, click on **Payroll**.


![wfCinTOipik4fnD_WcDzCD70B348CfTvKw.png?1657269572-1](https://support.briohr.com/hs-fs/hubfs/Imported%20images/wfCinTOipik4fnD_WcDzCD70B348CfTvKw.png%3F1657269572-1.png?width=272&height=535&name=wfCinTOipik4fnD_WcDzCD70B348CfTvKw.png%3F1657269572-1.png)


- On the **Payroll Dashboard**, select the **COMPLETED payroll month**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48237484977/original/DfVqhbRNELDdTxxBi1miBoOQs4R4Lou-_g.png?1657269683)


- In the **Statutory Reporting > PCB** column, click the "**Text File**" button.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48237513524/original/7cIHl4geT_ZhCXhwBTvrnj32YL7CGDuycA.png?1657275439)


- After downloading the text file, proceed to upload it to the e-Data PCB portal for payment.


**NOTE:**


**If any information is missing, you will not be able to generate the text file, and a warning prompt will appear (as shown in the screenshot below).**


**If this occurs, input the missing information and then regenerate the text file.**


![Glosgxewc0X4visD6PXu_Vx6u4PXB4FX3A.png?1657275608](https://support.briohr.com/hs-fs/hubfs/Imported%20images/Glosgxewc0X4visD6PXu_Vx6u4PXB4FX3A.png%3F1657275608.png?width=276&height=421&name=Glosgxewc0X4visD6PXu_Vx6u4PXB4FX3A.png%3F1657275608.png)
