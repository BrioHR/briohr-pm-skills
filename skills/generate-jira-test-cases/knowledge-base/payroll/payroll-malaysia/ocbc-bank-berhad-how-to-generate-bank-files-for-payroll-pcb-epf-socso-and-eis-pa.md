# OCBC Bank Berhad: How to Generate Bank Files for Payroll, PCB, EPF, SOCSO, and EIS Payments

*This article explains how to set up OCBC Bank Berhad and generate bank files for payroll, PCB, EPF, SOCSO, and EIS payments.*

### Step 1: Setting Up The Bank Account


- In the **HR Lounge**, click on **Payroll**, then **Settings. **Make sure you are in the **General tab.**


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-08-2026-04-26-03-9138-AM.png?width=1631&height=841&name=image-png-Jul-08-2026-04-26-03-9138-AM.png)


- In the General tab, scroll down to the **Bank Account** section, and select **OCBC Bank Berhad** from the "**Bank Account**" field.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48326454815/original/fvSfhx32VrnnhnxL_nqtTactuwPdxeV2kQ.png?1707383194)


- Fill in the required information in the fields (as shown in the sample screenshot) and click **Save at the bottom of the Settings page** to complete the setup.


**NOTE:**


**To successfully download the bank file(s) with all required information, ensure that all fields are completed as highlighted in the screenshot below.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48326455028/original/5dH4NaR_IlDnz3ScLAH7COMGWAsAQfVL-A.png?1707383301)


### Step 2: Downloading The Bank File


- In the **HR Lounge >** **Payroll > Dashboard**
- Select a **COMPLETED **payroll cycle for which you want to process payments.
- Find the **Bank File** section. Click the **Download **button (as shown in the sample screenshots) to download the bank file.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48326455373/original/Ivz0f9zw6ls6R3CS8LEyNrjWS2bDVWsZSQ.png?1707383457)


- In the "**Generate bank file for OCBC Bank Berhad**" pop-up window:

  - Select the bank file type;
  - Choose the employee(s) and the bank crediting date;
  - Click **Generate **to download the file.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48326455575/original/uLJH0sU1PjjL5jKo_3mzsf5_CwMOJywMiQ.png?1707383539)


- After downloading the bank file for Payroll, EPF, SOCSO, or other payments, proceed to **upload the file to the bank's portal for payment**.


**NOTE:**


**If any information is missing, you will not be able to generate the bank file. A warning prompt will appear (as shown in the screenshot).**


**In this case, input the missing information and regenerate the bank file.**


![Q3TbXCsYy_hvIUGNksN8EHIigXq5FJpBWA.png?1707383657](https://support.briohr.com/hs-fs/hubfs/Imported%20images/Q3TbXCsYy_hvIUGNksN8EHIigXq5FJpBWA.png%3F1707383657.png?width=314&height=282&name=Q3TbXCsYy_hvIUGNksN8EHIigXq5FJpBWA.png%3F1707383657.png)


### Downloading The Statutory Text File For Portal Upload


- If you need to upload statutory text files directly via the Statutory Portal, generate the text file from the Statutory Reporting category below.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48327505639/original/4bCymUc6CC2e8siQViOHS693Nqy6XXkX4A.png?1708312169)


- Once the text files are downloaded, **upload them directly to the relevant Statutory Portals (e.g., KWSP, LHDN)**.


**NOTE:**


**Ensure the files generated are from the correct category. Uploading a file from the Statutory Reporting category to the Bank Portal will result in an error due to an incorrect format.**


**You can only successfully upload files if they are downloaded from the correct category and uploaded to the appropriate portals.**
