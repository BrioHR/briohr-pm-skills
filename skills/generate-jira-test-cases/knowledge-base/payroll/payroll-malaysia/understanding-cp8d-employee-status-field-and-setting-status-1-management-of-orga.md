# Understanding CP8D Employee Status Field and Setting Status 1 (Management of Organizations) in BrioHR

*Learn what the CP8D Employee Status field means in BrioHR and how to manually set an employee's status to "Status 1: Management of the Organization".*

The employment status in the CP8D Form is mandatory and must be completed for tax reporting purposes in Malaysia.**

**In BrioHR, the system captures an employee’s employment status from two sources:


### 1) From the Employment Details in the Employee Profile


1. Open the employee profile > go to the **profile header.**
2. Click the **Edit** button
3. Locate the **Employment Type** filed. Each option corresponds to a relevant employee status in the CP8D *(refer to the table below)*

### 2) From the [CP8D Employment Status] Field


1. In the employee's profile, go to **Payroll**.
2. Navigate to **General Payroll Information** and locate the field **CP8D Employment Status**.


**NOTE:**


Selecting the option **"Follow Employment Type"** will use the employment type set in the profile header.


For example, if an employee is set as **"Full Time" **at his employment type field (from Part 1), his CP8D employment status will be reflected as **"Status 2: Permanent"**.


###


---


### How do I set an employee's employment status as "Status 1: Management of the organization"?


To set an employee’s status as **"Status 1"**, manually update the **CP8D Employment Status** field. This ensures that the employee’s CP8D status reflects **"Status 1"** instead of automatically following the employment type defined in the profile header.

### Frequently Asked Questions (FAQs)


**Q: What does "Status 1" mean in CP8D?**
A: It refers to "Management of the Organization" for tax reporting purposes.


**Q: Can CP8D status be set differently from the Employment Type in BrioHR?**
A: Yes. You can manually override the default by editing the CP8D Employment Status field.
