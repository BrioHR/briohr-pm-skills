# Delete Latest Payroll Cycle in Current Payroll Month

*This article explains how to set permissions for and how to delete the latest payroll cycle in the current payroll month. This feature is useful in case a payroll cycle was created prematurely or by accident.*

**Audience & Scope**


Audience: HR Admin & Payroll Manager


Module: Payroll


Country: Malaysia & Singapore


Pre-requisites: User group settings (HR Module Permission to Payroll Module)


**IMPORTANT: **


**If you choose to delete a payroll cycle, the action CANNOT be undone (or reversed), and the deleted data will no longer be retrievable. **


**Only delete a payroll cycle if you are sure. **


**We recommend downloading the relevant payroll reports of the cycle you are deleting as a precaution and backup. In the event you need to redo the cycle, you can refer to the extracted reports as a reference. **** **


**Step-by-Step Instructions**


**Part 1: Set user group permission to allow the delete payroll function**


1. Go to **Admin Settings > User groups**


**

**


2. Click '**Edit**' for the user group you need to allow the delete function for


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jun-10-2026-10-21-27-9479-AM.png?width=540&height=292&name=image-png-Jun-10-2026-10-21-27-9479-AM.png)


3. Click **HR Modules Permission. **Under **Payroll Module, **tick **'Allow access to delete payroll cycles'**


**

**Common Issues/FAQ**


**Q: I ran two payroll cycles and want to delete the first cycle I created. How do I do this?**


A1: The cycle has to be deleted in the sequence it was created. To delete your first cycle, your second cycle has to be deleted first.


**Q: Can I delete a payroll cycle after I have completed a payroll month?**


A2: Yes, you can still delete the latest payroll cycle once your current payroll month is completed. Once you delete the payroll cycle, the payroll month will change to 'Ongoing' status. You will have to complete the payroll month again.


**Q: I need to reopen the latest payroll cycle from my previous payroll month. How do I do this?**


A3: If you have already run cycles in your new payroll month, all the cycles in your current month have to be deleted first. This will change your 'current' payroll month to the last month. You can delete the latest cycle in your previous month once this is done.


**Q: Can I delete an ONGOING payroll cycle (not yet completed)?**


Yes — the same self-serve deletion applies to the latest cycle whether ongoing or completed, once the permission is enabled. Support no longer deletes cycles on your behalf.
