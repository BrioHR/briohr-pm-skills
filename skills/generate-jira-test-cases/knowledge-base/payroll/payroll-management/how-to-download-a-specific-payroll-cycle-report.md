# How to Download a Specific Payroll Cycle Report

*Learn how to download payroll cycle reports for months with multiple cycles.*

### Steps to Download a Specific Payroll Cycle Report


1. **Access the Payroll Module**


  - Navigate to **HR Lounge** > **Payroll**.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-03-2025-08-29-46-8136-AM.png?width=688&height=341&name=image-png-Jan-03-2025-08-29-46-8136-AM.png)
2. **Select the Payroll Month**


  - In the **Payroll Dashboard**, choose the payroll month for which you want to download the report.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-03-2025-08-31-38-6748-AM.png?width=688&height=453&name=image-png-Jan-03-2025-08-31-38-6748-AM.png)
3. **Choose the Payroll Cycle Report**


  - Click on the **dropdown arrow** to view available cycle reports.
  - Select either an **individual cycle report** or a **combined cycle report** based on your requirements.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-03-2025-08-35-32-6696-AM.png?width=688&height=305&name=image-png-Jan-03-2025-08-35-32-6696-AM.png)
4. **Download the Report**


  - Click on **Download** to export the payroll report in **Excel format**.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-03-2025-08-39-11-1984-AM.png?width=688&height=298&name=image-png-Jan-03-2025-08-39-11-1984-AM.png)
