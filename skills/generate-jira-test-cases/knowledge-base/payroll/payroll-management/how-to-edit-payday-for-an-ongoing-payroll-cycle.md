# How to Edit Payday for an Ongoing Payroll Cycle

*Learn how to edit the payday for an ongoing payroll cycle in briohr.*

**Audience & Scope**


Audience: HR Admin


Module: Payroll


Country: Global


Pre-requisites: Payroll Manager access to required payroll center





Occasionally, it's necessary to adjust the payday to process salary payments earlier or later than the originally scheduled date. Fortunately, you can modify the payday even after the payroll cycle has started, ensuring salary payments are processed on the desired date.


### Steps to Edit the Payday:


- Navigate to **HR Lounge > Payroll > Dashboard**.
- Click on the **current payroll month.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48344438007/original/xj3HnMDtnvSwGTzLnbFZ9C7VgOkcruxLQQ.png?1721721946)


- Select the **ongoing payroll cycle.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48344438128/original/vOARlg6os0vvKr5VqE66qSkoisnmAZAz7A.png?1721721996)


- Click on **Edit Cycle.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48344438263/original/_66Gke1vWDowPDQDT--QNTXMTRZXU_BGjg.png?1721722043)


- Adjust the **payday **as needed and click **Save**.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48344438392/original/a-iIiuMR_cS_xy9dajPb7kNiJm6fUEVeRA.png?1721722098)





**IMPORTANT:**


If you have run an **AdHoc** cycle, please note that for Ad-hoc payroll cycles, the payday can only be set up to the 15th of the following month.


Example: if you run an ad-hoc cycle in March, the latest payday you can select is 15 April.


**Workaround**: If you need a payday of 30 April, run the ad-hoc cycle in April instead.
