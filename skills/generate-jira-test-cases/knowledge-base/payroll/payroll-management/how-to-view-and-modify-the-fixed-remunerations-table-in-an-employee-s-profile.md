# How to View and Modify the Fixed Remunerations Table in an Employee's Profile

*This article explains how to view and modify the Fixed Remunerations table in an employee's profile once HR/Admin permissions are enabled.*

Once the **HR/Admin** user group permissions are enabled, you can access and manage the Fixed Remunerations table under an employee's **Profile > Compensation** tab. This table displays a list of all fixed remunerations currently applied to the employee.


**NOTE:**


**The Fixed Remunerations table will only display items that have a start date (effective date) in the past and an end date in the future.**


**HR/Admin** users can perform the following actions:


- **Add Fixed Remunerations**
- **Edit Fixed Remunerations**
- **Delete Fixed Remunerations**


**NOTE**


**Click [here](https://support.briohr.com/knowledge/how-to-enable-hr/admin-user-group-permission-settings-for-compensation-management?hsLang=en)to learn how to enable the HR/Admin user group permission settings.**


---


### A.  How To Add A New Fixed Remuneration


- In the employee's **Profile**, click on the **Compensation **tab.
- Scroll down to the **Fixed Remunerations** table and click on "**+ Add Remuneration**."


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48244819812/original/acCHDUjYJETfUuT0xc2Vij9aBwtcZ6pp1A.png?1660276940)


- In the **Add Remuneration** pop-up window:


**a. Effective Date:** Select the start date of the fixed remuneration from the calendar. This field is mandatory.


**b. End Date:** Select the end date from the calendar if the remuneration has a time limit. If no end date is set, the remuneration will apply indefinitely.


**c. Prorate: **Choose whether to prorate the amount if the effective date is not the 1st of the month. This field is mandatory.


**d. Remuneration Type:** **Select the type of remuneration from the dropdown menu**. This field is mandatory.


**e. Amount: **Enter the remuneration amount. The currency will align with the payroll center assigned to the employee. If no payroll center is assigned, the currency will follow the country selected.


![gN3DbPcuTHs8mkHx9_RKqCRBBl9kyVTFpw.png?1660280263](https://support.briohr.com/hs-fs/hubfs/Imported%20images/gN3DbPcuTHs8mkHx9_RKqCRBBl9kyVTFpw.png%3F1660280263.png?width=588&height=497&name=gN3DbPcuTHs8mkHx9_RKqCRBBl9kyVTFpw.png%3F1660280263.png)


**f. Double-Cycle Feature: If enabled, decide when the remuneration should be included.**

**


**g. Click "Save" to complete the action.**

The newly created remuneration will be displayed in the Fixed Remunerations table.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48244821523/original/Cy5lXVBHmw2G1AiGMU_M53gtw3FZjoFEaA.png?1660278555)

### B. How To Edit An Existing Fixed Remuneration


- Hover over the item and click "**Edit**."


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48244822058/original/oLl4N092bOis49LDOc1PzrmPaeEwHvlrMA.png?1660279017)


- In the **Edit Remuneration **pop-up window, update the necessary information. Click "**Save**" to complete the changes.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48244823850/original/TNuvZrpEHrcFSf1DqH_IvNrk1GPy0mEDVA.png?1660280505)


- You can view the **last modified** information in the corresponding column.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48244824160/original/EGeTQkycLXqevtPsbacsOzNOfSlIEYx1XQ.png?1660280704)


**NOTE:**


**You can still edit a fixed remuneration that has been used in a past payroll. However, if the employee has been moved to a different payroll center or the effective date is changed, the previous information will be overwritten. To retain both records, create a new fixed remuneration instead.**


![G8EjO3-16f-1vRYF3ESEBaSLSx7LD22wiw.png?1660290887](https://support.briohr.com/hs-fs/hubfs/Imported%20images/G8EjO3-16f-1vRYF3ESEBaSLSx7LD22wiw.png%3F1660290887.png?width=594&height=510&name=G8EjO3-16f-1vRYF3ESEBaSLSx7LD22wiw.png%3F1660290887.png)

### C. How To Delete A Fixed Remuneration


**NOTE:**


**You can delete a remuneration with a future effective date if it has not been used in a previous payroll.**


- Hover over the item and click the **Bin **icon.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48244825443/original/wJutUuCjcyAK5HM_TqYCuDB9bsyUAYpqSw.png?1660281585)


- Confirm the deletion by clicking "**Confirm Delete?**"


**NOTE:**


**Deleting a record will not affect finalized payrolls but may impact future and current payrolls.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48244825715/original/pPG4KKERFFTnyrAnE2CVXxpoQTJZf1QIlA.png?1660281803)


- A deleted remuneration will be removed from the Fixed Remunerations table.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48244826127/original/5BK3F1wac23vfwoXuIevlMLi9jyVjRQZnA.png?1660282079)


**NOTE:**


**Force-deleting a remuneration that has been used in a past payroll (by enabling editing and then deleting) can cause inconsistencies in payslips and payroll reports.**
