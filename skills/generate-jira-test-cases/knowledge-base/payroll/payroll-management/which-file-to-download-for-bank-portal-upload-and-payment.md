# Which file to download for bank portal upload and payment?

*This article explains how to download the correct bank file for payroll payment uploads. Follow these simple steps in the Payroll Dashboard to generate the required bank file and upload it to your bank portal for salary disbursements.*

### Steps to Download Bank File for Payment


1. Navigate to **HR Lounge** and select **Payroll**.
2. On the **Dashboard**, click on the desired payroll month (e.g., **Dec 24**) for which you want to generate the bank file.
3. Click on the **Download** button under **Bank File**.
4. If necessary, select specific employees. By default, **all employees** are selected.
5. Click on the **Generate** button to download the bank file.
6. Upload the generated file to your **bank portal** to proceed with salary payment.
