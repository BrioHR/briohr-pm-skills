# How to Complete the Payroll Month (Singapore/ SG)

*This guide provides a step-by-step process to complete the payroll month in BrioHR, ensuring all payroll tasks are finalized and ready for the next cycle. Learn how to close the current payroll month accurately or use the shortcut to save time.*

### Steps to Complete the Payroll Month


#### 1. Login to BrioHR


- Use your credentials to log in to your **BrioHR account**.


#### 2. Navigate to the Payroll Module


- Click on **HR Lounge** from the main menu.
- Go to the **Payroll** section to access the payroll dashboard.




![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-12-58-01-1745-AM.png?width=688&height=299&name=image-png-Dec-23-2024-12-58-01-1745-AM.png)


#### 3. Access the Ongoing Payroll Month


- From the payroll dashboard, click on your **ONGOING payroll month**.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-12-59-51-9727-AM.png?width=688&height=326&name=image-png-Dec-23-2024-12-59-51-9727-AM.png)


**4. Proceed with Payroll Completion**


- Click the **Continue** button to proceed.
- Click the **Continue** button again to move forward.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-02-21-56-0813-AM.png?width=688&height=535&name=image-png-Dec-23-2024-02-21-56-0813-AM.png)

**5. ****Confirm Submission**

- A confirmation message will appear.
- Click the **Confirm Submission button** to finalize the submission.


**6.** **Confirm Submission**

- A confirmation message will appear.
- Click the **Confirm Submission button** to finalize the submission.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-02-25-22-1349-AM.png?width=593&height=329&name=image-png-Dec-23-2024-02-25-22-1349-AM.png)

**7.  Click the Complete button**

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-02-28-02-5984-AM.png?width=688&height=501&name=image-png-Dec-23-2024-02-28-02-5984-AM.png)

**8. System will prompt an option to chose, as below:**

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-02-32-34-2501-AM.png?width=633&height=307&name=image-png-Dec-23-2024-02-32-34-2501-AM.png)


**9. Select Completion Type
**


- **Complete this cycle only**: Choose this option if there are more payroll cycles to run within the same month.
- **Complete the payroll month**: Choose this option if all payroll tasks for the month are finalized and you want to start the next month’s payroll.


**SHORTCUT TO COMPLETE PAYROLL MONTH**


**1. Use Payroll Dashboard**


- From the payroll dashboard, click the **Complete Payroll Month button**.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-02-41-45-6158-AM.png?width=688&height=337&name=image-png-Dec-23-2024-02-41-45-6158-AM.png)


**2. Finalize Completion.**


- Click the **Complete button**.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-02-42-49-4812-AM.png?width=637&height=262&name=image-png-Dec-23-2024-02-42-49-4812-AM.png)


**3. Now the payroll month is labelled as Completed.**


- The payroll month will now be marked as **Completed**.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Dec-23-2024-02-44-14-4731-AM.png?width=676&height=312&name=image-png-Dec-23-2024-02-44-14-4731-AM.png)
