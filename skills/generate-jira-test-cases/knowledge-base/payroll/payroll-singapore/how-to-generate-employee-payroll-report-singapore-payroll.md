# How to Generate Employee Payroll Report (Singapore Payroll)

*This article explains how to generate and export individual employee payroll reports in BrioHR for Singapore payroll in Excel format for easy access and analysis.*

### Steps to Generate Employee Payroll Report


#### 1. Login to Your BrioHR Account


- Use your credentials to access your BrioHR dashboard.


#### 2. Navigate to Reports


- Click on **HR Lounge** in the menu.
- Go to the **Reports** section to view reporting options


![a](https://support.briohr.com/hs-fs/hubfs/a.jpg?width=688&height=304&name=a.jpg)


#### 3. Create a New Payroll Report


- In the **Employee Payroll** box, click on the **Create button** to start generating a new report.


![b](https://support.briohr.com/hs-fs/hubfs/b.jpg?width=688&height=358&name=b.jpg)


#### 4. Select the Employee Name


- From the dropdown menu, select the name of the **employee** for whom you want to generate the payroll report.


#### 5. Choose Payroll Month Range


- Define the range of **payroll months** you want to include in the report.


![c](https://support.briohr.com/hs-fs/hubfs/c.jpg?width=688&height=294&name=c.jpg)


#### 6. Export the Payroll Report


- Once the report is generated, export it to an **Excel file** for further processing or record-keeping.


![d](https://support.briohr.com/hs-fs/hubfs/d.jpg?width=688&height=289&name=d.jpg)
