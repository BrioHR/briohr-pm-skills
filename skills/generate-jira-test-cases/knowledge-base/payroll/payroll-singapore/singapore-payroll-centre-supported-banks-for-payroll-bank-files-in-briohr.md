# Singapore Payroll Centre: Supported Banks for Payroll Bank Files in BrioHR

*Learn which banks support payroll bank files in BrioHR for Singapore Payroll Centre. Ensure correct bank setup for smooth payroll processing.*

**Audience & Scope**


Audience: HR Admin & Payroll Manager


Module: Payroll


Country: Singapore


Pre-requisites: Access to HR Lounge > Payroll > Module & Module Settings


---


After completing a monthly payroll run, you can generate a bank file directly from BrioHR and upload it to your bank's portal for salary crediting payments.


Each company bank selected in the Payroll Center Settings will generate a specific bank file format. Therefore, it is essential to ensure that:


- The **correct company bank** is selected, and
- The **bank file version** matches your bank's requirements


This ensures successful uploads and prevents payment rejections.


**Learn More:** [How to Set Up a Company Bank Account in Payroll Center Settings](https://support.briohr.com/knowledge/how-to-set-up-company-payroll-general-settings-in-malaysia?hsLang=en#bank-account)


To download the bank files for salary payroll payment, you can download after a payroll cycle has been completed.


**Learn More:** [How to Download a Bank File for Bank Portal Upload and Payment](/knowledge/payroll-singapore-how-to-generate-bank-file?hsLang=en)


---


### CPF Text File for Payment Process


CPF payments do not use a standard bank text file. Instead, CPF has its own dedicated text file format, which you can download from the system and upload directly to the CPF portal for payment processing.


**Learn More:**
[How to Access the Central Provident Fund (CPF) Text File After Completing Payroll](/knowledge/payroll-singapore-how-to-access-the-statutory-report-cpf-after-completing-payroll?hsLang=en)


---


### Banks Supporting Salary Payroll Bank Files


BrioHR supports salary payroll bank file generation for selected banks in Singapore. Once the payroll is finalized, you can generate the bank file in the format required by the selected bank for employee salary payment.


**IMPORTANT:**

The bank file format varies depending on the bank and its version. Always verify that the configured bank matches the bank used for salary disbursement.


| Bank Name | Version | Payroll File Format |
| --- | --- | --- |
| CIMB Bank |  | TXT |
| Citibank |  | TXT |
| DBS Bank |  | CSV |
| HSBC (Corporate) |  | TXT |
| OCBC Bank | GIRO | TXT |
| OCBC Bank | FAST | TXT |
| United Overseas Bank Limited (UOB) |  | TXT |
