# Rehire a Resigned Employee

*This article explains how to rehire a former employee by creating a new profile, and how to resolve the duplicate email error.*

** Audience & Scope**

- **Audience:** HR Admin
- **Module:** Employee Profile
- **Country:** Global (statutory example: Malaysia)
- **Prerequisites:** Access to employee profiles; Admin Settings access for the email step
- **Feature available on:** Web
- **When to use this article:** HR Admin is rehiring a former employee and wonders whether to reactivate or merge the old profile, or the system rejects the new profile because the email already exists.


**Step-by-Step Instructions**

1. **Create a new employee profile** for the new employment period — this keeps the two employment records separate.
2. **Alternative**: you can also **restore (reactivate) the old profile** instead of creating a new one — both methods are valid.
-** Create a new profile** keeps the two employment periods as separate records (recommended when you need the history intact).
- **Restore the old profile** keeps everything in one profile, but note: a profile holds only **one join date and one employment end date** — restoring and updating the dates for the new employment **erases the previous ones**. Record the previous employment dates elsewhere before restoring.
3. Key in the new profile fresh — data cannot be merged or transferred from the inactive profile.
4. If the new profile is rejected because the email is already in use, go to **Admin Settings** > **Users** and change the email address on the old profile to another address, then create the new profile again.


**Common Issues / FAQ**

- **Q:** Can I merge or transfer data from the old profile to the new one?
**A:** No — BrioHR has no merge feature. The new profile is keyed in fresh.
- **Q:** Will statutory reports cover both employment periods?
**A:** Yes — reports such as CP8D (Malaysia) combine both profiles via the employee's MyKad or Passport number.
- **Q:** The system says the email address is already in use — what do I do?
**A:** Change the email address on the old profile under **Admin Settings** > **Users**, then register the new profile with the employee's email.
