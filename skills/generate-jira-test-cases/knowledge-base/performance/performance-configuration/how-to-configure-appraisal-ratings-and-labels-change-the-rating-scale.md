# How to Configure Appraisal Ratings & Labels (Change the Rating Scale)

*This article explains how to change the appraisal rating scale (e.g. from 5 stars to 10 stars), configure the rating labels, and how scores map to each rating.*

The **Appraisal Ratings **feature allows you to customize the labels for each appraisal rating score assigned to employees. For instance, if an appraisal score is 1.5, you can set it to align with the label for either a 1 or a 2 rating, based on your preference.


**CAUTION!**
**"Rating Rounding" is for adjusting the Rating Labels only, not the scores!**


To enable **Appraisal Ratings**, follow these steps:
1. Go to the **HR Lounge** and select **Performance**.
2. Navigate to **Cycle Overview**.
3. Expand **Step 4: Determine the appraisal's key milestones**.
4. Under **Appraisal Ratings Configuration**, choose the **Rating Rounding** option.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-08-2024-01-17-04-8690-AM.png?width=670&height=323&name=image-png-Nov-08-2024-01-17-04-8690-AM.png)


**Tip:**


**Rating labeling helps you assign scores to specific rating labels or ranges. This feature ensures that scores are matched with the appropriate rating level, offering clarity and consistency in evaluations.**


**
Rating Labelling Options:**


1. **Label Up**:


Rounds up the label to the next higher rating if it falls between two ranges (e.g., a score of 1.5 would round to a 2-star rating and show the “Below Expectations” label). See the screenshot below for more details on the ranges.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-07-2024-09-11-18-5176-AM.png?width=670&height=427&name=image-png-Nov-07-2024-09-11-18-5176-AM.png)


As shown in the example screenshot below, when the overall rating is 1.50, it will correspond to the "**Below Expectations**" label.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-11-2024-06-00-52-3934-AM.png?width=670&height=225&name=image-png-Nov-11-2024-06-00-52-3934-AM.png)


2. **Label Nearest**:


Rounds to the nearest label when a score falls between two ratings (e.g., a score of 1.5 rounds to the closest label, which is a 2-star rating, showing the “Below Expectations” label). See the screenshot below for more details.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-07-2024-09-10-49-2505-AM.png?width=670&height=442&name=image-png-Nov-07-2024-09-10-49-2505-AM.png)
As shown in the example screenshot below, when the overall rating is 1.50, it will correspond to the "**Below Expectations**" label.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-11-2024-06-00-52-3934-AM.png?width=670&height=225&name=image-png-Nov-11-2024-06-00-52-3934-AM.png)


3. **Label Down**:


Rounds down to the lower label when a score falls between two ratings (e.g., a score of 1.8 would round to a 1-star rating, showing the “Does Not Meet Expectations” label). See the screenshot below for more details.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-07-2024-09-16-46-3153-AM.png?width=670&height=440&name=image-png-Nov-07-2024-09-16-46-3153-AM.png)


As shown in the example screenshot below, when the overall rating is 1.80, it will correspond to the "**Does Not Meet Expectations**" label.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-11-2024-06-02-35-8285-AM.png?width=670&height=216&name=image-png-Nov-11-2024-06-02-35-8285-AM.png)


4. **Custom Range Labeling**:


Allows you to define custom ranges for each rating label. For example, a range of 1.00–1.69 could align with the 1-star “Does Not Meet Expectations” label, while 1.70–2.99 could align with the 2-star “Below Expectations” label. See the screenshot below for further details.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-07-2024-09-22-28-7766-AM.png?width=670&height=436&name=image-png-Nov-07-2024-09-22-28-7766-AM.png)


As shown in the example screenshot below, when the overall rating is 1.70, it will correspond to the "**Below Expectations**" label.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-11-2024-05-58-13-8302-AM.png?width=670&height=243&name=image-png-Nov-11-2024-05-58-13-8302-AM.png)


**Note:**


You can customize the '**Number of Ratings**' and 'Label' according to your company's policies. You have the flexibility to choose **any number of ratings you prefer**, with **no set limit** — for example, you can change a 5-star rating scale to a 10-star scale.


**The examples provided above are based on a 5-rating scale for reference only.**


**Common Issues / FAQ** **Q:**


**Q: Can I change the rating scale while a performance cycle is running?**


**A:** Yes. Go to **HR Lounge > Performance Management** > click the **3-dot button** > **View cycle details** > click the **pencil (edit) icon** next to Cycle Detail > change the **'Appraisal Ratings Configuration'** under 'Determine the appraisal's key milestone'.
