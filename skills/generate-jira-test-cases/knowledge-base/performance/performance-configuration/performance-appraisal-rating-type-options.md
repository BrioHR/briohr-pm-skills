# Performance Appraisal - Rating Type Options

*Efficient performance appraisals play a vital role in evaluating employee contributions and driving organizational growth.*

There are two **rating type options**: **Stars and Numeric Amount** and **Numeric Amount Only**.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-03-2025-09-17-21-3125-AM.png?width=688&height=296&name=image-png-Jan-03-2025-09-17-21-3125-AM.png)
**Stars and Numeric Amount**


This rating option is ideal for organizations that prioritize clarity in performance feedback.


- **Star Ratings:** Employees or evaluators can rate performance using a star system (e.g., 1-5 stars)
- **Numeric Values:** Each star corresponds to a numeric value, ensuring detailed and measurable feedback.
- **User-Friendly Interface:** Star rating is easy to understand and implement for evaluators and employees alike.


If you are seeking a **combination of qualitative and quantitative feedback**, you may opt for the Stars and Numeric Amount rating type to support clear and actionable evaluations.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-03-2025-09-13-06-1343-AM.png?width=688&height=265&name=image-png-Jan-03-2025-09-13-06-1343-AM.png)


**Numeric Amount Only**


This option is designed for organizations that prefer precise and straightforward performance metrics. Ratings are expressed as numerical values, which can be tailored to align with predefined scales.


- **Customizable Scales:** Use scales such as 1-5, 1-10, or percentage-based systems.


If you would like to focus on **quantitative performance evaluation** and statistical analysis, you might prefer the Numeric Amount Only option to maintain precision and consistency.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jan-03-2025-09-38-42-0613-AM.png?width=688&height=269&name=image-png-Jan-03-2025-09-38-42-0613-AM.png)
