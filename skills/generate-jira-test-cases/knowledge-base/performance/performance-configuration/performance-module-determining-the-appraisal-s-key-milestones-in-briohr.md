# Performance Module: Determining the Appraisal's Key Milestones in BrioHR

*Setting up key milestones in the Performance Module is crucial for an effective appraisal process. These milestones help manage the timeline and ensure that all necessary steps are completed for a smooth appraisal cycle.*

### Steps to Determine the Appraisal's Key Milestones


1. Login to** BrioHR.**
2. Navigate to** HR Lounge > Performance.**
3. Go to **Cycle Overview.**
4. **Ensure Steps 1 to 3 are Set Up:** Make sure you have completed the initial setup steps (Step 1 to Step 3).
5. **Determine the Appraisal's Key Milestones:**


This is a crucial step in the setup process. There is a completion bar that starts at 0%, and you need to fill in all the fields in this section to ensure the completion bar reaches 100%. If this step is not fully completed, the option to start the cycle will remain greyed out.


###


### Key Milestones to Set Up:


1. **Due Date for the Definition of Individual Objectives**


  - Employees need to define their individual objectives with their managers, usually at the beginning of the cycle, and confirm this step is completed. Employees can always add new objectives later if needed.
2. **Start Date of the Appraisal Process**


  - Set the date when the performance appraisal form becomes available to employees and managers. This is when they can begin the self-appraisal and manager appraisal processes.
3. **Employee Self-Appraisal Submission Due Date**


  - Set the due date by which employees should submit their self-appraisals in BrioHR. It is mandatory to add open-ended questions that employees must answer during their self-appraisal to help them reflect on their performance over the past few months.
4. **Manager Appraisal Submission Due Date**


  - Choose the due date for managers to submit their appraisals for their employees. This date must be after the employee self-appraisal submission due date. It is required to include open-ended questions for managers to provide comprehensive feedback and general comments on the employee’s performance.
5. **Appraisal Ratings Configuration**


  - Configure the ratings for the appraisal form. You can define the number of rating levels you want and set the corresponding labels. [Learn more about Performance Appraisal Rating Rounding here.](https://briohr.freshdesk.com/support/solutions/articles/48001250221-performance-appraisal-rating-rounding)
6. **Employee Acknowledgement Due Date**


  - Set the date by which employees must confirm the reception of the manager's appraisal. This date must be after the manager's appraisal submission date.
