# Performance Module: Select Your Add-Ons: 1-on-1 and 360 Feedback

*In Step 5 of configuring the Performance Module in BrioHR, you can choose to add features like 1-on-1 Meetings and 360 Feedback to enhance your objective and competency-based appraisals.*

#### 1. 1-on-1 Meetings


Schedule regular **1-on-1 **meetings between managers and employees throughout the performance cycle. Choose a frequency (**Weekly, Monthly, or Quarterly**), and BrioHR will handle the notifications.


#### 2. Other Feedback


Allows feedback to be provided by any employee for any employee in an active cycle, offering more flexibility in the feedback process.


#### 3. 360 Feedback


Gather feedback from various sources for a comprehensive view of performance. Enable the following options:


- **Upward Feedback**: Feedback from direct reports or juniors. Option to rate competencies or provide answers to custom questions.
- **Peer Feedback**: Input from colleagues at the same level. Option to rate competencies or provide answers to custom questions.
- **Downward Feedback**: Feedback from supervisors or seniors. Option to rate competencies or provide answers to custom questions.


**Note:** Please hover your mouse over the **?** icon next to each feedback option to learn more about how each feedback type works.


#### Optional Settings:


- **Use Average 360 Ratings**: Competencies are rated based on the average feedback score.
- **Mandatory Comments**: Set comments or ratings as mandatory for feedback givers.
- **Mandatory Ratings**: Set comments or ratings as mandatory for feedback givers.


#### 4. Feedback Ratings Configuration


Define the number of rating levels and their labels for 360 feedback.


#### 5. 360 Feedback Timeline


Set start and end dates for when feedback collection should begin and be completed.


These add-ons help provide a complete view of performance and foster continuous feedback and development within the organization.
