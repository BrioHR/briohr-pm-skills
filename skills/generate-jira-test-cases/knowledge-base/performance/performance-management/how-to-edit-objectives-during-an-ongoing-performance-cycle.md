# How to Edit Objectives During an Ongoing Performance Cycle

*This article explains how to edit objectives during an ongoing performance cycle, for current or future cycles.*

**When a performance cycle is active, you can still modify the objectives. As an HR Admin, you have the flexibility to apply these modifications to either the future and current cycles or only to the current cycle.**


Follow the steps below to learn how to manage and edit objectives during an ongoing cycle.


### Managing Objectives:


- In the **HR Lounge**, click on **Performance**.


![gSIAtgfm6sjshP5hOPWHcAyoWVOcTYRPAQ.png?1658740999-1](https://support.briohr.com/hs-fs/hubfs/Imported%20images/gSIAtgfm6sjshP5hOPWHcAyoWVOcTYRPAQ.png%3F1658740999-1.png?width=265&height=531&name=gSIAtgfm6sjshP5hOPWHcAyoWVOcTYRPAQ.png%3F1658740999-1.png)


- Click on the **Objective **tab.


#### How To Edit Existing Objectives Or Add New Ones:


**The following steps illustrate how to edit an existing objective. These steps can also be used to add a new objective.**


- Locate the objective you wish to modify and click on the **Edit **icon.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48242174396/original/ljzn3wGtWblbToUu73MKwbf6BdnIeZ1QvA.png?1659326920)


- Update the objective by adding new information in the relevant fields.
(For example, changing the weight or category.)
- In the **Save Options** field, choose one of the following:

  - **DO NOT APPLY TO CURRENT CYCLE:**
Select this option to apply the modifications **only to the FUTURE cycle**, **not the CURRENT one.**
  - **APPLY TO CURRENT CYCLE:**
Choose this to apply the modifications to **both the FUTURE and CURRENT cycles.**


**NOTE:**


**Modifications applied to the current cycle will affect ongoing appraisals.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48242174849/original/c_tImFX7dsGU30ctW-nvneS_xHNvBNea8A.png?1659327233)


- Click **Update Objective** to save your changes.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48242175023/original/eRUbEx6DGb6ziUYI2fuOVs1SHYKcdgYWSA.png?1659327331)


Once the modifications are complete, you can view the **updated date and time information** for the objective.


**Before Modifications:**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48242175257/original/5QvQ6a32vUZH6Q1NT14zm_HqOzRTSmFeUQ.png?1659327495)


**After Modifications:**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48242175465/original/dGejdN7D02vGiGkxzRKhTW8wuvbfgQDkHg.png?1659327634)


If you selected "**DO NOT APPLY TO CURRENT CYCLE**" when saving your modifications, a "**briefcase**" icon will appear, indicating that the updated objective was not applied to the current cycle. However, it will be applied to the future cycle.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48242175816/original/VRUYaWaOnStUNaw6hj9h59qsLO_SxTiwhQ.png?1659327852)


If you later decide to include the updated objective in the current cycle, you can do so by clicking on the "**briefcase**" icon and then the **Apply **button to confirm your action.


**NOTE:**


**The modifications will now apply to both the current and future cycles. Any changes applied to the current cycle will affect ongoing appraisals.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48242176148/original/BP-FnaFz1iQv2R57Xw62XVWfGfoz7DpObw.png?1659328126)
