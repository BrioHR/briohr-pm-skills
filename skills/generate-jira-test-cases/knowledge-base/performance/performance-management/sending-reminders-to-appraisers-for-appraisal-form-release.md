# Sending Reminders to Appraisers for Appraisal Form Release

*Ensure timely performance evaluations by reminding appraisers to release appraisal forms. Follow these step-by-step instructions in HR Lounge to send automated reminders efficiently.*

### Steps to Send a Reminder to Appraisers


The sooner the appraisal form is completed and feedback is given, the faster development plans can be implemented. Timely performance evaluations enable immediate action on performance improvements and career growth opportunities.


#### 1. Access the Performance Module


- Navigate to **HR Lounge > Performance Module**
- Scroll down to the **Appraisal Overview** section to check each stage’s status, due date, and completion percentage.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Oct-18-2024-02-54-09-1326-AM.png?width=688&height=375&name=image-png-Oct-18-2024-02-54-09-1326-AM.png)


#### 2. Open the Release Appraisal Section


- Click **See Details** under **Release Appraisal** to view pending appraisal forms.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-14-2024-06-42-38-2692-AM.png?width=688&height=281&name=image-png-Nov-14-2024-06-42-38-2692-AM.png)


#### 3. Select Employees for Reminder


- On the **Release Appraisal** page, find employees whose appraisal forms have not been released.
- Select the employees whose appraisers need a reminder.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-14-2024-06-45-13-5435-AM.png?width=688&height=574&name=image-png-Nov-14-2024-06-45-13-5435-AM.png)


#### 4. Send a Reminder (Nudge)


- Click **Nudge** to send a reminder to the selected appraisers.
- Confirm by clicking **Nudge** again to trigger an automated email reminder.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-14-2024-06-48-28-7536-AM.png?width=688&height=581&name=image-png-Nov-14-2024-06-48-28-7536-AM.png)


#### 5. Appraiser Notification


- The appraiser will receive an email reminder prompting them to release the appraisal form.


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Nov-14-2024-06-53-59-2268-AM.png?width=688&height=333&name=image-png-Nov-14-2024-06-53-59-2268-AM.png)





*Note: You are unable to select the employee if the appraisal has not been completed*
