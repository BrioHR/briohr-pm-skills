#### Global HR Update


**Create and Assign Cost Centers on BrioHR!**


With this enhancement, Admins can now easily create and manage cost centers directly within the system. Each cost center requires a unique Cost Center ID, ensuring accurate tracking and organization across your workforce.


**👉 [Learn how to create cost centers here](/knowledge/create-and-assign-cost-centers-as-an-admin?hsLang=en)**


Assigning cost centers is now more flexible than ever. You can:


- Select a cost center when adding a new employee
- Update cost centers for existing employees via their Employee Profile
- Assign cost centers in bulk using the Bulk Import/Export feature


This feature is designed to help you streamline employee categorization, improve reporting accuracy, and simplify internal cost tracking.
