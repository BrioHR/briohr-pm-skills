### Ad-hoc Performance Cycle


- [How to Create an Ad-Hoc Performance Appraisal Cycle in BrioHR](/knowledge/how-to-create-an-ad-hoc-performance-appraisal-cycle-in-briohr?hsLang=en)


  - #### What is the Ad-Hoc Appraisal Cycle?


The Ad-Hoc Appraisal Cycle allows HR Admins to create a separate appraisal cycle for selected employees, independent of the organization's primary performance review timeline.


This ensures that employees who are not included in the standard appraisal cycle can still review timely and structured performance evaluations.


- - #### When Should You Use the Ad-Hoc Appraisal Cycle?


This feature is especially useful in the following scenarios (but not limited to):


- - - **New Joiner Probation Reviews: ***For new joiners who are not eligible for the main appraisal cycle.*


- - - **Promotion Appraisal: ***For promotion-related evaluations that are not part of the annual performance review.*


- - - **Performance Improvement Plan (PIP): ***For employees undergoing a structured performance improvement process.*
