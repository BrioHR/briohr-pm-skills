# brioHR Product Updates - June 2026, Week 1 | API Salary Data Privacy Control & Payslip Password Protection Update for SG

*Discover brioHR’s June 2026 product updates, designed to improve your HR experience. Stay informed on the latest innovations from brioHR.*

### API Integration Update


#### Salary Data Privacy Control


As part of our efforts to provide greater flexibility and support your data confidentiality (P&C) requirements, you can now choose to exclude salary information from your API data transfers.


What's changed:


- **Salary Exclusion Control:** You can now opt to omit sensitive salary details from your active data streams.
- **Full Integration Coverage:** This update can be applied across all brioHR API integrations (including Employee Details, Leave, Claims, Attendance, and Recruitment reports).
- **On-Demand Activation:** Your existing configurations will remain unchanged until you explicitly choose to update them.


**Note: **Salary details cannot be excluded from the company payroll report. The salary data exclusion control applies to all other APIs.


Next steps:


- **To exclude salary data:** Contact our support team via live chat or email us at **support@briohr.com**, and let us know which integration you would like to adjust.
- **To set up a new integration:** No further action is required! If you are interested in enabling API integrations for your team, please refer to the guides below.

### Singapore HR Update


#### Payroll: Payslip Password Protection


We would like to inform you that the update to the email password protection for payslips (SG) has now been implemented.


As part of our efforts to align with Singapore compliance requirements, the **NRIC** option has been removed as a payslip email password protection method. **Date of Birth** is now the default and only password protection setting available for Singapore payslip emails.


**What's changed:**


- The NRIC password option is no longer available.
- Date of Birth is now automatically applied as the password protection method for all Singapore payslip emails.
- Existing Singapore payslip password protection settings have been updated accordingly.


No further action is required from your side!
