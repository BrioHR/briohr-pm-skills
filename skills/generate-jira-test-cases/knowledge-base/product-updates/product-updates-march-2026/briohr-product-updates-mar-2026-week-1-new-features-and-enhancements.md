### Default Overtime Payroll Item Type


To support clearer payroll categorisation, default Overtime payroll items can be organised under the relevant type directly in your Payroll Settings.


You can define whether your **default Overtime payroll items** are treated as **Fixed Remuneration** or **Additional Remuneration**. This configuration is essential for aligning with your organization's specific tax processing standards.


#### What you need to know


We have implemented this setting to provide more granular control over payroll item types:


- **For Existing Accounts:** Your settings have been maintained as **Additional Remuneration**. No changes will occur unless you manually update them.
- **For New Accounts/Payroll Centers (Effective 6th March 2026): **Default Overtime Payroll Item Type for all newly created payroll centers will have the Fixed Remuneration type set as default.


#### How to Verify or Update Your Settings


If you wish to review or adjust this configuration, please follow these steps:


1. Navigate to **HR Lounge > Payroll Module**.
2. Go to **Settings > General** tab.
3. Scroll to the **Calculation** section to find **"Set default Overtime item as."**
4. Select your preferred type and click **Save**.


>
>
> **Note:** This setting is specific to each payroll center. If you have multiple centers, please ensure each one is configured according to your requirements. Changes will apply to future and ongoing cycles (refresh any open payroll cycles to see the update).
>
>

#### Quick FAQ


- **"What if I use Custom Payroll Items?"** If you use custom OT items instead of BrioHR defaults, this specific configuration won't change them.
- **"How do I check my current status?"** Head to **Payroll > Settings > Payroll Items** and search for "Overtime." The **Type** column will show whether they are currently classified as Fixed or Additional Remuneration.
