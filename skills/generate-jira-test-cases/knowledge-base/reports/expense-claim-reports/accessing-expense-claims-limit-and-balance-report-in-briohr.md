# Accessing Expense Claims Limit & Balance Report in brioHR

*View employees' expense claim limits, used amounts, and remaining balances with the new Expense Claims Balance Report. Generate reports by effective date and export them in CSV, Excel, or PDF formats.*

**Audience & Scope**


Audience: Admin


Module: Expense Claims


Country: Global


Pre-requisites: Access to Expense Claim Balance report enabled in User Group





Gain better visibility into your employees' expense claim entitlements with the new **Expense Claims Balance Report**.


This report provides a comprehensive overview of each employee's **claim limit, amount used, and remaining balance** based on their assigned claim policies, making it easier to monitor claim utilisation and available balances.





### What does this report include?


The **Expense Claims Balance Report** calculates employee claim balances based on the selected effective date and displays:


- Claim limit
- Amount used
- Remaining balance
- Breakdown by:

  - Year
  - Month
  - Transaction


 **Note:**


Claim balances are calculated based on the **transaction date**, not the **claim submission date**.





### Report permissions


Access to this report is controlled through User Group permissions.


To grant access:


1. Go to **Settings** > **User Groups**.
2. Select the relevant user group.
3. Navigate to **HR Modules Permission** > **Reports Module**.
4. Enable - **Allow access to Expense Claims Balance Report**.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-07-2026-12-33-01-7567-AM.png?width=1050&height=671&name=image-png-Jul-07-2026-12-33-01-7567-AM.png)


**IMPORTANT:**


Only users with this permission enabled will be able to access and generate the report.





### How to generate the report


1. Navigate to **Analytics >** **Reports**.
2. Select **Expense Claims Balances**.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-07-2026-12-35-04-3574-AM.png?width=1652&height=600&name=image-png-Jul-07-2026-12-35-04-3574-AM.png)
3. Choose the **Expense Claims Balance Effective Date**.

  - Select the **year** and **date** you would like the balances to be calculated as of.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-07-2026-12-37-26-2040-AM.png?width=1596&height=902&name=image-png-Jul-07-2026-12-37-26-2040-AM.png)
4. Select the department, claim policy and claim types to include.

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-07-2026-12-38-15-5338-AM.png?width=1596&height=902&name=image-png-Jul-07-2026-12-38-15-5338-AM.png)
5. Click into **Fields & Filters**, select required fields then click '**Apply Changes**'

![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-07-2026-12-39-26-7899-AM.png?width=1752&height=851&name=image-png-Jul-07-2026-12-39-26-7899-AM.png)
6. Once the report is complete, proceed to export the report





**NOTE :** All available claim types are selected by default.





### Export options


The report can be exported in the following formats for further analysis or record-keeping:


- CSV
- Excel (.xlsx)
- PDF


![image](https://support.briohr.com/hs-fs/hubfs/image-png-Jul-07-2026-12-41-24-8862-AM.png?width=1622&height=877&name=image-png-Jul-07-2026-12-41-24-8862-AM.png)


#### Benefits


The Expense Claims Balance Report helps you:


- Monitor employees' available claim balances at a glance.
- Track claim usage against assigned claim policies.
- Generate accurate balance reports based on transaction dates.
- Export data for auditing, reporting, and reconciliation purposes.
