# How to Create a Custom Report Format in BrioHR

*This article explains how to create a custom report format from the Report Builder in the Reports section.*

Log in to your BrioHR account.


- Navigate to the **HR Lounge**.
- Access the **Reports **section.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48336912281/original/nqUKWCZPAKoqju5_IfmUyIZkv927kO-cXQ.png?1715740286)


You will be directed to the Report Dashboard page.


- Go to the **Report Builder**. Here, you'll see all the types of reports you have access to.
- Click the "**Create**" button to customize your report format (e.g., Leave Balances report).


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48158268860/original/I606WzcMg1vJ6VPumTWWTImgxBV_anjP4A.png?1636681599)


On this page, you can customize the following:


1. Date options.
2. Leave types options.
3. Fields and filters to customize the items included in the report.
4. An overview of how your report will look.


- Select the date for which you want the leave balances to be calculated.

  - Choose the leave types to include in the report (e.g., Annual, Medical).
- Click the "**Fields & Filters**" button to customize the items included in the report.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48158268869/original/vHi7b6NVijqteNGl9OGTC8nAaiGmChA2pA.png?1636681611)


- A Fields & Filters template will appear.
- Select which items you want to include in the report by ticking or unticking the checkboxes. Use the "**+ Add Filter**" option if necessary.
- Click "**Apply Changes**" to save your selections.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48158268889/original/kUQFcLWtsjRZqdwsAk4Icjimkf8Ft2PI6Q.png?1636681629)


- An overview of how your report will look will be displayed. Click "**Expand**" to view it in **fullscreen** if needed.
- Click "**Save As**" to save your customized report format.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48158983083/original/v1ZpXFR9CKkvwHPb-m_RRVipqsIWiDGCuA.png?1636943556)


- A "Save Report as Template" pop-up will appear. Enter a name for your report.
- Click "**Save**."


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48158268939/original/8fDKKeNffsVVu2YZ5PVjOqr_UdYizR6YjA.png?1636681668)


- The saved report will appear under the **Generated Reports** section. If you have multiple reports, click on the one you wish to display.
- Click "**Export Report**" to download the selected report. You can choose to download it in CSV or Excel format.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48158268976/original/QSJLe_xoOBsX_t46sQLjc1bktKX4jucf_Q.png?1636681695)
