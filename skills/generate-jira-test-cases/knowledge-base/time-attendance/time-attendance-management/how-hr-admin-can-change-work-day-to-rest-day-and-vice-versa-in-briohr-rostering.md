# How HR Admin Can Change Work Day to Rest Day (and Vice Versa) in BrioHR Rostering

*Learn how HR Admin can modify employee schedules in BrioHR Rostering by changing work days to rest days and vice versa for shift-based and flexible hours.*

### Introduction


BrioHR's Rostering feature gives HR Admins full flexibility to adjust employee schedules - including changing **work days to rest days**, or **rest days to work days.**


For example:

If an employee normally works Monday to Friday but is required to work on a weekend, you can replace their rest days with other weekdays. This ensures accurate attendance tracking and prevents unnecessary overtime calculations.


Similarly, if you need to change a rest day into a work day, it will be treated as a **normal working day rate** (without the overtime rest day rate).


If you would like to **assign a shift on rest days (for Overtime Rest Day calculation)**, refer to these articles:


- [How to Assign Shifts on Rest Day in BrioHR Time Attendance Rostering](https://support.briohr.com/knowledge/how-to-assign-shifts-on-rest-days-in-briohr-time-attendance-rostering?hsLang=en)
- [How Managers Can Assign Shifts on Rest Day in BrioHR Time Attendance Rostering](https://support.briohr.com/knowledge/managers-assign-shifts-on-rest-day-in-rostering?hsLang=en)


**NOTE:**


brioHR also has a **Day Off** option, other than Rest Day. All the steps you learn from this article can also be applied to Day Off.


If employees work on their Day Off, they can be paid an overtime rate for a Day Off/Off Day (processed from Time Attendance Timesheet to Payroll).


A Day Off in the schedule also impacts the employee's leave calendar. Employees will not be able to take leave on their Day Off.


**LEARN MORE: [Create Schedules with Day Off](/knowledge/create-schedules-with-day-off?hsLang=en)**

### Step-by-Step Guide: Changing Work Day to Rest Day


#### Step 1 - Access the Rostering Page


1. Navigate to **HR Lounge > Time Attendance**


2. Select** Rostering.**


**
![image](https://support.briohr.com/hs-fs/hubfs/image-png-Sep-18-2025-08-32-05-7872-AM.png?width=670&height=300&name=image-png-Sep-18-2025-08-32-05-7872-AM.png)
**


#### Step 2 - Update Day Types for the Employee


You view the rostering in either **'Month view'** or '**Week view'.**


#### A) For Shift-Based Employees


1. Filter by criteria, or search by the employee's name.


2. Locate the work day to be changed.


3. Click the **pencil icon** to edit.


4. Go to **REST & OFF** > Select **Rest Day**.


Once selected, the day will become a **Rest Day,** and the employee will not required to clock in.


**CAUTION:**

Do **not **add a rest day on top of an existing shift. Doing so will cause the system to treat it as** work on a rest day**, triggering **overtime rest day rate calculations**.


[Embedded content](https://www.loom.com/embed/e7112ca1f7d1405782db05974cd54a92?sid=44e67275-2904-4bc5-b147-c5cb5dd8dedb)


####


#### B) For Flexible Hours Employees


1. Filter by criteria, or search by the employee's name


2. Locate the work day to be changed.


3. Click the **pencil icon** to edit.


4. Go to **REST & OFF** > Select **Replace as a Rest Day.**


Once done, the day will become a rest day, and the employee will not need to clock in.


[Embedded content](https://www.loom.com/embed/b6275f3b23fc4f63b8b7b9121a19633c?sid=aac122f9-ada0-4c85-bfc1-6a0c67ab024b)


####


#### Step 3 - Publish the Rostering


- If the roster is **unpublished,** publish it to make the changes visible to employees.
- If the roster is **already published**, the changes will apply immediately.


Learn More: [How HR/Admin Manage Rostering of All Employees](https://support.briohr.com/knowledge/how-hr/admin-manage-rostering-of-all-employees?hsLang=en).

### Step-by-Step Guide: Changing Rest Day to Work Day


#### Step 1 - Update Day Types for the Employee


As with the previous steps, you can view in **Month View **or **Week View.**


#### A) For Shift-Based Employees


1. Filter by criteria, or search by the employee's name


2. Locate the rest day to be changed.


3. Click the** pencil icon** to edit


4. Go to** WORK** > Select **Replace as Work - Full Day (8h)**, or **Replace as Work - Half Day (4h)**


5. The day schedule will now appear empty.


- Click **plus (+) icon **and choose** either ****+Create New Shift,** or **+Choose from existing shifts**.


6. A shift period will then be assigned to the work day. The employee can clock in as usual on this day


**IMPORTANT NOTE:**


- You must first replace the rest day with a **work day** before adding a shift.
- Do **NOT** add a shift on top of a rest day - the system will treat it as **work on a rest day**, triggering overtime rest day rates.


[Embedded content](https://www.loom.com/embed/699e1957415f4bcd86597b7be0ab4805?sid=bdd3a6cf-0b49-45c2-ae69-0f36a6265c11)


####


#### B) For Flexible Hours-Basis Employees


1. Filter by criteria, or search by the employee's name


2. Locate the rest day to be changed.


3. Click the** pencil icon** to edit


4. Go to** WORK** > Select **Replace as Work - Full Day (8h)**, or **Replace as Work - Half Day (4h)**


Once done, the rest day is converted into a normal working day.

####


#### Step 2 - Publish the Rostering


- If the roster is **unpublished,** publish it to make the changes visible to employees.
- If the roster is **already published**, the changes will apply immediately.

### Frequently Asked Questions (FAQs)


**1. Can I change a rest day to work day for multiple employees at once?
**No. Currently, you cannot bulk update the day type for multiple employees. You’ll need to update each employee’s day type individually on the Rostering page.**

2. What happens if I add a shift without changing the day type first?
**If an employee follows a shift-based schedule, the system will treat the shift as work on a rest day and calculate overtime (rest day) rates automatically.**

3. Do I need to republish the roster every time I make a change?
**If the roster is **already published**, any changes you make will apply instantly.
If it’s **unpublished**, you’ll need to **publish it** to make the updates visible to employees.


**4. Can managers change work days and rest days too?
**Yes, the managers can manage their direct reports' rostering from Team > Time Attendance.
