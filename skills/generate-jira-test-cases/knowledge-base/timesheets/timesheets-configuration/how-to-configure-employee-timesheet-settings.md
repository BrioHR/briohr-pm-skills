# How to Configure Employee Timesheet Settings

*This article explains how to configure employee timesheet settings before enabling the Timesheet module.*

Before enabling the Timesheet Module for all employees, ensure that the module's settings are properly configured.


The Timesheet settings involve two (2) key components:


**Part A**: Company Settings


**Part B**: Employee Timesheet Settings


This article will focus on **Part B: Employee Timesheet Settings**. For details on Part A, click [here](https://support.briohr.com/knowledge/how-to-configure-timesheet-company-settings?hsLang=en).
