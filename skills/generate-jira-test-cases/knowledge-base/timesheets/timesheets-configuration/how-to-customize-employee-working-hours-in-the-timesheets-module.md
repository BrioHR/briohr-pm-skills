# How to Customize Employee Working Hours in the Timesheets Module

*This article explains how to customize employee working hours in the Timesheets module, without affecting payroll overtime.*

**NOTE: **


This article shows how to customize working hours in the **Timesheets module only**. It **does not affect overtime calculation in Payroll**. To change the Overtime (OT) calculation basis for payroll, go to HR Lounge > Payroll > Settings > General > Calculation.


Read the article below for more information:


- [Payroll Malaysia: Complete Guide to Setting Up Company Payroll Information](/knowledge/how-to-set-up-company-payroll-general-settings-in-malaysia?hsLang=en)
- [Payroll Singapore: How to Set Up Company Payroll General Settings](/knowledge/payroll-singapore-how-to-setup-company-payroll-general-settings?hsLang=en)


You can now customize the working hours for an employee in the Timesheets module by following these steps:


Navigate to HR Lounge > Timesheets > Settings.


- Click on **Employee Timesheet Settings.**


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48175045576/original/NVcz6JoC0LO61U-UwU83QlMQGQRqlvR4LA.png?1641195822)


- Under **Approval Workflow & Work Hours**, locate the **Select Customization** section and click on **Work Hours**.
- Enter the desired **number of working hours** in the **Create Custom Work Hours** field.
- Check the box next to the **employee's name** for whom you want to apply these hours.
- Click on **+ Apply Work Hours** to save the changes.


[](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/48175028135/original/VViaX7qh6RTHAbq8ryBzvtWDFRY6DzLuRA.png?1641185795)


By doing so, if an employee tracks hours exceeding the set working hours, the system will automatically calculate overtime.
