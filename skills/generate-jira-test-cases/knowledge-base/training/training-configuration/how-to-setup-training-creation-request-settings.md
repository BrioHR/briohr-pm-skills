# How to Setup Training Creation Request Settings

*Are you looking for a clear guide on how to set up Training Creation Request settings in BrioHR? This step-by-step tutorial will help you configure the settings, enabling employees to submit and manage training requests.*

### Why Configure the Training Creation Request Settings?


You have the option to allow or restrict employees from selecting the **Budget Center** and/or **Training Category** when submitting training creation requests.


By enabling the selection of a **Budget Center** and **Training Category**, employees can choose which budget center the new training is assigned to and categorize it accordingly.


From the employee’s perspective, it looks like the following:

### Step-by-Step Guide to Setting Up Training Creation Request Settings


Login to your BrioHR account


1. Click on **HR Lounge**
2. Select the** Training **tab
3. Navigate to **Settings**
4. Select the **Training Creation Request** section
5. There are 2 options you can enable for Training Creation Request:


  1. **Select Budget Center:** Enabling this setting allows Trainees to view and select the Budget Center for their Training Request.
  2. **Select Training Category: **Enabling this setting allows Trainees to view and select the Training Category for their Training Request.
6. Click **Save**
